Haga que su AI CLI clone y ejecute ForgeaX

La instalación más nativa de IA: no escriba los comandos usted mismo: entregue el repositorio a su agente de codificación CLI y déjelo clonar, instalar, iniciar e informar la URL local.

✅ Código abierto (Apache-2.0). El siguiente flujo funciona con cualquier CLI de codificación AI.

lo que necesitas

  • Una CLI de codificación de IA que puede ejecutar comandos de shell, p.Código Claude,Códice,Cursor, o el propio ForgeaXforjarCLI;
  • gityBollo(el tiempo de ejecución del proyecto) instalado;
  • una clave API del modelo AI (para Forge dentro del estudio).

Una instrucción para su CLI

Abre tu CLI en una carpeta vacía y dale esto:

Clona https://github.com/ForgeaX-Games/forgeax-studio (con --recurse-submodules), ingresa el cd, ejecuta el script de instalación para configurar las dependencias, luego ejecuta el script de inicio para iniciarlo y dime la URL local que puedo abrir.

La CLI ejecuta los pasos de clonación/instalación/inicio por sí misma y le solicita cualquier cosa que necesite a lo largo del camino (como la clave API). Cuando termine, obtendrá una URL local: ábrala en el navegador y estará en el estudio.

Equivalente manual (opcional)

Si prefieres hacerlo tú mismo, el equivalente es aproximadamente:

git clone --recurse-submódulos \
  https://github.com/ForgeaX-Games/forgeax-studio
cd forgeax-studio
configuración de bun fx # departamentos de instalación (+ agregar clave API)
bun fx start # inicia el estudio

Estosbollo fxLos comandos son multiplataforma: los mismos en macOS, Linux y Windows, sin necesidad de Git-Bash en Windows. Luego abra la URL local que imprime.

A continuación, dirígete aInicio rápidoy cuéntale a Forge tu primer juego.

¿Por qué es esta la instalación más sencilla? Porque, en primer lugar, ForgeaX está diseñado para la IA; incluso "configurarse solo" es algo que estamos felices de entregarle a un agente.
