A diario2026-07-04

Correcciones de generación 3D + i18n de workbench + terminal TUI del agente

Los workbenches wb-gen3d y wb-ai-asset recibieron correcciones críticas del pipeline 3D; los tres workbenches de creación (personaje, activo AI, generación 3D) están ahora completamente internacionalizados; una nueva TUI (Terminal UI) proporciona una interfaz de agente controlada por teclado; las API Keys de Settings se simplifican a solo LiteLLM; CLI gana auto-inject slug y códigos de error estructurados; y dos nuevos paquetes de escenas de juego se envían (escenas editables de Slagdeep Hollow, modelo de piso de Rogue Encampment).

Correcciones del pipeline de generación 3D

Los workbenches wb-gen3d (generación de modelos 3D) y wb-ai-asset (creación de activos IA) recibieron correcciones críticas en sus pipelines de salida 3D. Anteriormente, ciertos modelos generados podían fallar al renderizarse correctamente en el viewport debido a problemas de asignación de materiales. Ahora está resuelto — los activos 3D generados se muestran con texturas PBR correctas inmediatamente tras su creación.

Internacionalización completa de workbenches

Los tres workbenches de creación — wb-character, wb-ai-asset y wb-gen3d — están ahora completamente internacionalizados en todos los idiomas soportados. Etiquetas de panel, tooltips, mensajes de estado y estados de error están todos traducidos.

TUI: Interfaz de agente por terminal

Una nueva TUI (Terminal UI) ha sido validada para el runtime del agente core (aceptación F1/F2/F3). Proporciona una interfaz controlada por teclado para interactuar con el agente directamente desde una terminal.

API Keys de Settings simplificadas

La sección de API Keys en Settings se ha simplificado a configuración solo-LiteLLM. En lugar de gestionar claves individuales para cada proveedor, ahora se configura un único endpoint proxy LiteLLM que enruta a todos los modelos.

Mejoras de CLI

El CLI ahora auto-inyecta el slug del proyecto en las llamadas de herramientas, eliminando errores comunes de "proyecto no encontrado". Además, los errores de handlers ahora devuelven códigos de error estructurados.

Nuevos paquetes de escenas de juego

Dos nuevos paquetes de contenido: Slagdeep Hollow (escenas editables + posición de inicio launcher den) y Rogue Encampment (modelo de piso para juegos estilo dungeon-crawler).
