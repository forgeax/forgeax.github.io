Actualización2026-07-10

Runtime Tier 2 + limpieza del editor + APIs de assets/componentes de Gateway + plugins de assets integrados

La versión v0.3.15 del 10 de julio incorpora un editor de reino único, jerarquía coherente entre Edit y Play, mejoras visuales de Hellforge, importación de assets array-TRS y renderizado más estable al redimensionar Play.

Editor y runtime

  • El editor ahora usa un layout Dock compartido y gestionado por el host, con un runtime de reino único más limpio.
  • Edit y Play comparten el comportamiento de jerarquía, incluido el cambio de padre conservando la posición mundial y una ruta Play de solo lectura.
  • Las APIs de assets y componentes Tier 2 se unificaron mediante Gateway.

Visuales y assets

  • Hellforge incorpora skybox HDR, postprocesado en runtime y partículas ambientales.
  • La importación GLB/FBX migró al esquema de transformaciones array-TRS y mejoró el manejo de artefactos WASM de FBX.
  • El redimensionamiento de Play reconstruye de forma segura los bindings de postprocesado y evita enviar texturas HDR destruidas.
