AI CLI をクローンして ForgeaX を起動します

最も AI ネイティブなインストール: 自分でコマンドを入力するのではなく、リポジトリをコーディング CLI エージェントに渡し、エージェントにクローンを作成、インストール、起動させ、ローカル URL をレポートさせます。

✅ オープンソース (Apache-2.0)。以下のフローは、任意の AI コーディング CLI で機能します。

必要なもの

  • シェル コマンドを実行できる AI コーディング CLI — 例:クロード・コード、コーデックス、カーソル、または ForgeaX 独自のフォーギアスCLI;
  • gitそしてバン(プロジェクトのランタイム) がインストールされています。
  • AI モデル API キー (スタジオ内の Forge 用)。

CLI への 1 つの命令

空のフォルダーで CLI を開き、次のように指定します。

https://github.com/ForgeaX-Games/forgeax-studio (--recurse-submodules 付き) のクローンを作成し、そこに移動し、インストール スクリプトを実行して依存関係を設定し、開始スクリプトを実行して起動し、開くことができるローカル URL を教えてください。

CLI はクローン作成、インストール、起動のステップ自体を実行し、途中で必要なもの (API キーなど) を要求します。完了すると、ローカル URL が取得されます。ブラウザで開くと、スタジオに入ることができます。

マニュアル相当品（オプション）

自分でやりたい場合は、おおよそ次のようになります。

git clone --recurse-submodules \
  https://github.com/ForgeaX-Games/forgeax-studio
cd forgeax-スタジオ
bun fx setup # deps をインストール (+ API キーを追加)
bun fx start # スタジオを起動する

これらバンFXコマンドはクロスプラットフォームです。macOS、Linux、Windows で同じであり、Windows では Git-Bash は必要ありません。次に、出力されたローカル URL を開きます。

次に向かうのは、クイックスタートそしてあなたの最初のゲームを Forge に伝えてください。

これが最もスムーズなインストールであるのはなぜですか? ForgeaX はそもそも AI 用に構築されているため、「セットアップ自体」さえエージェントに喜んで任せることができます。
