チュートリアル

文章からプレイ可能なゲームまで、段階的に進めていきます。今後も続きます。

初心者

AI CLI をクローンして起動します

リポジトリを Claude Code / Codex / Cursor / forgeax CLI に渡し、クローンを作成し、インストールして起動します。
初心者

クイックスタート · 初めてのゲーム

スタジオについて学び、Forge に最初のリクエストを出し、計画、コーディング、実行をライブで観察します。
すぐ

キャラクターにモーションやスキルを追加する

キャラクターをインポートし、アニメーション クリップを接続し、火の玉の呪文を追加します。

作成する

ワークベンチでアートを生成する

文章からゲーム対応アセットまで、キャラクター、アニメーション、3D、VFX、UI、音楽などの作成ワークベンチをご紹介します。
作成する

インタラクティブなフィルムゲームを作成する

Spark またはスクリプト → アンカー → ストーリーボード → ビデオ → プレイテストを経て、誰でも再生できる Web ページを出荷します。
すぐ

マルチレベル ゲームを構築する

レベルの切り替え、シーンの再利用、数値のバランス。
