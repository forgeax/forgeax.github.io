プロジェクトを開くとレンダリングされるだけで、エージェントは長期記憶を取得します

この日、v0.2.0 が出荷され、いくつかの信頼関係を強化しました。開いたプロジェクトはすべて忠実にレンダリングされ、隠された「優先モード」はありません。各エージェントは一貫したアイデンティティと、セッション全体にわたってあなたを覚えている長期記憶を獲得しました。どこからでもマテリアルをチャットにドラッグすることがサポートされています。デスクトップ開発は Windows にも拡張されました。そしてエンジンは、一度完全に枯れてしまったブルームを修復しながら、2D GPU インスタンス化とスポットライト シャドウを追加しました。

「信頼」を軸に磨き上げた第2弾公開

この日、v0.2.0 が出荷されました。これは、オープンソース化後の 2 番目の公開リリースであり、ホームページの「新機能」のハイライトが更新されました。バージョン番号は、数字を増やす以上の意味を持ちます。これは、長期間にわたって蓄積された改善点を、参照、ダウンロード、信頼できるノードにパッケージ化します。そして、この日このリリースに関して行われたほぼすべてのことは、信頼という 1 つのキーワードを示しています。プロジェクトを開いて忠実にレンダリングすると、結果は信頼できるものになります。エージェントは安定したアイデンティティを持ち、あなたを覚えているため、協力者は信頼できるものになります。繰り返しの説明なしでマテリアルを AI に直接ドラッグできるため、インタラクションが信頼できるものになります。 Windows 開発が機能し、ブルームが死ななくなったことにより、プラットフォームはより多くの環境で信頼できるものになります。公の場に足を踏み入れ、ますます多くの人に真剣に試してもらっている製品が最も築く必要があるのは、まさにこの信頼です。「言ったことを実行し、記憶し、どこでも信頼できる」ということです。この日はその信頼を現場ごとに確固たるものにした。

プロジェクトを開くと、そのプロジェクトがレンダリングされるだけです

この日は概念的なぎこちなさを修正しましたが、実際に修正したのは一種の「予測不可能性」でした。 Play は最初に、「特定の特別な形式として扱うことを好む」という推測によってレンダリング方法を決定していました。これは、場合によっては、同じプロジェクトを開くと、それ自体ではなく、プロジェクトが「推測」したものを提供するヒューリスティックです。問題は、推測が正しいかどうかではなく、結果が予測不能になることでした。何かをクリックしても、何が表示されるか完全に確信が持てませんでした。この日は、これを最も直接的で単純な動作に変更しました。どのプロジェクトを開いても、隠された「優先モード」が介在することなく、そのプロジェクトとして忠実にレンダリングされます。これに応じて、エディターは、エディターのライブラリにハードコーディングされるのではなく、外部ホストによって提供されるゲームのパスを使用して、単一のコマンドで特定のディスク上のゲームを開いて実行できます (エディターがよりクリーンになり、純粋なツールとして再利用可能になります)。 「開けばすぐに手に入る」というのは明白に聞こえますが、「何かを開けば間違いなく手に入る、驚くことはありません」を真に達成するツールこそが予測可能性の基礎であり、予測可能性は信頼の前提条件です。

一貫したエージェント ID + あなたを覚えている長期記憶

この日、コラボチームはより「人間らしく」、より「持続的」になった。一方では、すべてのエージェントが一貫したアイデンティティのプレゼンテーションを採用しました。つまり、「中国語の役割と英語の名前」という名前が付けられ、ペルソナが記入されているため、あなたが直面するのはもはや一連の機能モジュールではなく、それぞれが名前、性格、役割を持つ仲間のチームです。その一方で、そしてより重要なことに、彼らは長期記憶を獲得しました。ワークベンチ内の各エージェントには、構造化された「長期記憶」タブと閲覧可能な日記が与えられました。システムは各ターンの終わりに、覚えておく価値のある内容を自動的に抽出します。そして、一緒に時間を過ごすにつれて、あなたの好み、習慣、取り組んでいることを徐々に学習する「グローバル ユーザー プロファイル」が維持されます。なぜ記憶がそれほど重要なのでしょうか?記憶力のないアシスタントは毎回白紙のページからスタートするため、同じ背景や好みを繰り返し説明する必要があり、コラボレーションは永遠に「初対面」に留まります。長期記憶により、これらのエージェントはあなたと過去の決定や教訓を覚えているため、コラボレーションがより簡単になり、長く続くほど調和がとれます。 「ゲームを作るための AI チームとの長期的なコラボレーション」を中心とするプラットフォームにとって、AI に「記憶」させることは、「ツール」から「コンパニオン」への重要な飛躍です。

どこからでもチャットにドラッグ + アセットパイプラインの改善

この日も対話がさらにスムーズになり、さまざまなサーフェス間でチャットに直接ドラッグできるようになりました。アセット ブラウザーまたはさまざまなパネルからアイテムのバッチをチャット ボックスに取り込むことができ、そこでそれらは一緒に AI に渡される「参照錠剤」のキューとして並びます。これにより、非常にありがちな不器用さが解消されます。以前は、AI に「シーン内のこれらのモデル、このテクスチャ、そのオブジェクトを使用させる」には、それぞれを言葉で説明する必要があり、面倒で間違いが発生しやすかったのです。選択してドラッグすると、AI がその意味を正確に認識します。アセット パイプラインも改善を続けました。サポートの削除、チャットへのドラッグ、およびマテリアルのインポート時の衝突 (以前は一部のリソースの不可解な読み込みを妨げていた衝突) を解決するために、アセットのバッチの内部識別子が再生成されました。 「AIに見せる」ことを「言葉で説明する」から「手でドラッグする」にアップグレードすることは、小さなインタラクションのように見えますが、人間とAIの間で具体的な材料を渡す際の摩擦を大幅に軽減します。摩擦が減り、コラボレーションがスムーズになります。

Windows デスクトップ開発 + エンジンの修正

この日、デスクトップ開発が Windows に拡張されました。Windows 固有のリンクの問題が修正され、Windows 上で (Git Bash 経由で) デスクトップ開発を実行できるようになりました。そのため、Windows ユーザーは、Web バージョンだけでなくデスクトップ アプリをローカルで開発およびデバッグできるようになりました。これにより、Windows 互換性への最近の持続的な投資が継続され、デスクトップ市場の大部分を占める Windows ユーザーが「Web バージョンのみ」から「デスクトップ開発も」に移行します。このエンジンは 2 つの実際の問題を修正しました。ブルーム (明るい領域から柔らかい光を滲ませるエフェクト) は、3 つのバグが重なったために完全に機能しなくなっていましたが、現在は適切に修復され、雰囲気が戻っています。また、大きなモデルで一般的な大きな頂点インデックス (より多くの頂点をアドレス指定できる形式) は、以前は解析時に完全に拒否されていましたが、現在では正しく保持されるため、複雑で大きなメッシュがエラーなしでインポートされます。スタートアップ パスにもオプトインが追加されました。古いエンジン ビルド出力が検出されたときに、それを自動再ビルドすることができます (予期せず再ビルドがトリガーされるのを避けるために、デフォルトでは依然として処理を求めるプロンプトが表示されます)。これらはすべて、より多くの環境、より多くのマテリアル、より複雑なシーンにわたってプラットフォームが安定して動作するのに役立ちます。

エンジン: 2D GPU インスタンス化 + スポットライト シャドウ

この日は2D演出と照明でエンジンがそれぞれ一歩前進した。パフォーマンスに関しては、「チャンクレベルの GPU インスタンス化」がスプライトとタイルマップに適用されました。2D ゲームには、タイルの画面、弾丸のシート、多くの同一の小さなタイルなど、大規模な繰り返し要素が含まれることが多く、事前に 1 つずつ描画され、カウントが増加するにつれて速度が低下します。同じチャンク内の同一の要素をバケットにマージし、GPU によって 1 パスで描画できるようになりました。これにより、ドローコールが大幅に削減され、大規模な 2D パフォーマンスが質的に変化します。照明に関しては、スポット ライト シャドウが追加されました。スポット ライトは、懐中電灯やステージ スポット ライトのような指向性のある円錐形の光源であり、影を正しく投影できるようになり、「影を引きずりながら暗闇を通過するビーム」のような効果の基礎的なサポートを提供します。スプライト レンダリング パイプラインも統合され、以前はスプライト専用に記述されていた特別なパスが汎用レンダリング パスに折り畳まれ、個別に管理するフォークが 1 つ減りました。これらのいくつかは 2D の実行を高速化し、いくつかは光と影をより豊かにし、いくつかはエンジンをよりシンプルにし、一緒に 2D ラインの別のレイヤーをよりしっかりと固めます。

この日が意味するもの

バージョン番号 v0.2.0 は、オープンソース化後の最初の統合の成果を示しています。そして、その日最も感動的なセリフは実際にはエージェントの長期記憶であり、これによって「AI とのコラボレーション」に初めて時間の次元が与えられます。あなたを覚えている仲間と、毎回あなたを見知らぬ人として扱うツールは、2 つのまったく異なる関係です。前者は使えば使うほど理解が深まりますが、後者は永久にそのまま残ります。 「何かを開くとレンダリングされる」という予測可能性、「ドラッグするだけ」という低摩擦、「Windows も開発できる」という広範な対応、そしてエンジンのスポットごとの修正と高速化が相まって、この日はプラットフォーム全体が「信頼して長期的に使用する価値がある」に向けてさらに大きな一歩を踏み出しました。ユーザーに長期間寄り添いたいと心から願うツールは、言われたことを実行し、どこでも信頼できること、そしてユーザーのことを覚えていて理解することの両方が必要ですが、今日はその両方を同時に推し進めました。
