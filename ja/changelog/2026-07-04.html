更新2026-07-04

3D生成修正＋ワークベンチi18n＋TUIエージェントターミナル

wb-gen3dとwb-ai-assetワークベンチに重要な3Dパイプライン修正が入りました。3つのクリエイションワークベンチ（キャラクター、AIアセット、3D生成）が完全に国際化されました。新しいTUI（ターミナルUI）がキーボード駆動のエージェントインターフェースを提供します。Settings API KeysがLiteLLMのみに簡素化されました。CLIにauto-inject slugと構造化エラーコードが追加されました。2つの新しいゲームシーンパック（Slagdeep Hollow編集可能シーン、Rogue Encampmentフロアモデル）が出荷されました。

3D生成パイプライン修正

wb-gen3d（3Dモデル生成）とwb-ai-asset（AIアセット作成）ワークベンチの3D出力パイプラインに重要な修正が入りました。以前は、マテリアル割り当ての問題により、生成されたモデルがビューポートで正しくレンダリングされないことがありました。修正済み——生成された3DアセットはPBRテクスチャ付きで即座に正しく表示されます。

ワークベンチ完全国際化

3つのクリエイションワークベンチ（wb-character、wb-ai-asset、wb-gen3d）がすべてのサポート言語で完全に国際化されました。パネルラベル、ツールチップ、ステータスメッセージ、エラー状態がすべて翻訳されています。

TUI：ターミナルエージェントインターフェース

コアエージェントランタイム用の新しいターミナルUI（TUI）がF1/F2/F3受入テストを通過しました。ターミナルから直接エージェントと対話するためのキーボード駆動インターフェースを提供します。

Settings API Keys簡素化

SettingsのAPI Keysセクションが LiteLLMのみの設定に簡素化されました。各プロバイダー個別のキー管理の代わりに、単一のLiteLLMプロキシエンドポイントを設定するだけですべてのモデルにルーティングされます。

CLI改善

CLIがプロジェクトslugをツールコールに自動注入するようになり、「プロジェクトが見つかりません」エラーが解消されました。また、ハンドラーエラーが構造化エラーコードを返すようになりました。

新しいゲームシーンパック

2つの新しいゲームコンテンツパック：Slagdeep Hollow（編集可能なシーンパック＋ランチャーデンスタート位置）とRogue Encampment（ダンジョンクローラー向けフロアモデル）が追加されました。
