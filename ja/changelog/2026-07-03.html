更新2026-07-03

Windows Playモード安定化＋開発者向けLLMデバッグプロキシ

エディターのSocketスタック修正により、WindowsのPlayモードが安定しました。新しいFORGEAX_DEBUG_PROXY環境変数により、開発者はすべてのLLM APIトラフィックをリアルタイムでキャプチャし検査できます。Windowsデスクトップアプリのパッケージングが修正されました。リールゲームのランタイムアーキテクチャがエンジンレベルのゲームランタイムサブクラスとして設計されました。

Windows Playモード：ついに安定

WindowsのPlayモードは、エディターのSocketスタックの問題により断続的に失敗していました。基盤となるWebSocketエクスポートがデスクトップビルドパスから欠落しており、エンジンプレビューiframeがエディターホストとの接続を失っていました。これが修正され、WindowsのPlayモードはmacOSと同様に安定して動作するようになりました。

開発者向けLLMデバッグプロキシ

新しいオプトイン環境変数 FORGEAX_DEBUG_PROXY が追加されました。設定すると、すべての送信LLM API呼び出し（Anthropic、OpenAI、Geminiなど）をキャプチャし、リクエスト/レスポンスのペアをログに記録するローカルHTTPプロキシが起動します。エージェントの動作をデバッグするのに非常に有用です。.env に設定するだけで、プロキシは bun fx start と共に自動的に起動します。

Windowsデスクトップアプリのパッケージング修正

Windows用のTauri 2デスクトップビルドは、interfaceパッケージの依存関係エクスポートの欠落により失敗していました。修正済み — bun fx build app でWindowsで動作する .exe インストーラーが正常に生成されるようになりました。

リールゲームランタイムアーキテクチャ

リールゲーム（インタラクティブフィルム）ランタイムの設計仕様が策定され、エンジン内のファーストクラスのゲームランタイムサブクラスとして位置づけられました。実装は今後のリリースで行われます。
