インライン 3D と画像プレビュー + @ メンション錠剤

この日は、「マルチエージェント コラボレーション」を背景から目に見える形にしました。エージェントに @ @ して直接話しかけることができ、機能の健全性がインターフェイス全体に表示され、チャットでインラインでアセット プレビューが表示され、参照薬として表示されます。このエンジンは、統合メッシュ レンダラー、統合キャプチャ、コンソールの依存関係の反転、およびレンダリング チュートリアルのサンプルの完全なセットを統合した大きなバッチを作成しました。

コラボレーションを可視化してクリック可能にする

以前は、プラットフォームは「バックグラウンドで長時間実行される複数のエージェント + イベント バス」の機能を構築していましたが、そのすべては依然としてシステム内に隠されていました。この日のスルーラインでは、その機能がインターフェイスの最前面に完全にプッシュされていました。バス上のエージェント間のトラフィックを確認できるだけでなく、特定のエージェントを名前で確認したり、適切な場所にあるアセットをプレビューしたり、参照薬としてオブジェクトを会話に持ち込んだりすることができます。言い換えれば、この日追加されたのは孤立した機能ではなく、「エージェントのチームが協力する」ということを一般の人が実際に操作できるものにするインタラクションレイヤーだ。バックエンドの複雑さが、読んでクリックできるインターフェイス要素に変換されると、マルチエージェントは「技術的に実行される」状態から「快適に使用できる」状態になります。

@ エージェントと直接会話する

この日、マルチエージェントのコラボレーションは重要な一歩を踏み出しました。会話内で特定のエージェントを名前で @ できるため、リードと会話するだけで他のエージェントにメッセージを中継するのではなく、エージェントがそのメッセージを拾って返信することができます。コンパニオン エージェント ハブ パネルが稼働し、現在の「チーム」にどのメンバーがいるのか、そして各メンバーが何に忙しいのかが一目でわかるようになりました。これによって変わるのは、コラボレーションの「指揮スタイル」です。以前はプロジェクト マネージャーとしか話せなかったのが、マネージャーを通り越して、アートを担当するメンバーやレベルを担当するメンバーに直接話しかけることができるようになりました。 「AI のチームを率いる 1 人の人物」という中心的なシナリオでは、名前付きコミュニケーションが「ブロードキャスト」から「正確な指示」への分水嶺となり、最終的には適切なメンバーに正しいことを言うことができるようになります。

バスのステータスが UI 全体に分散: 機能の健全性がどこにでもあります

前日のインターフェイスへのバスの配線を基に、この日は「システムにどの機能が存在し、それぞれがどの程度健全であるか」を UI の隅々まで広げました。上部のバーには、ツール、スキル、エージェントなどのカテゴリのステータス ランプの行が追加され、それぞれの数と状態が表示されます。チャット パネル、サイドバー、バス管理パネルにも同様に、この「小さなランプ + カウント + クリック可能なディープリンク」プレゼンテーションが点在しており、ワンクリックで一致する詳細にジャンプします。その価値は、「システムに現在何があるか、どのように動作しているか」を周囲の情報に変えることです。調べに行く必要はありません。インターフェイスを見ればそれがわかります。プラグインによって拡張可能な、より多くの機能を備えたシステムにとって、この遍在する健全性の視覚化は、「どのような状態にあるのか」を常に把握するための鍵となります。

インラインアセットプレビュー + チャットでのリファレンスピル

この日はまた、「資産」が可視化され、会話の中で参照できるようになりました。チャットでは添付ファイルをその場でプレビューできます。画像を貼り付けてサムネイルを取得します。モデル ファイルをドロップすると、実行中のゲームに最初に接続してどのように見えるかを確認することなく、小さな表示可能なプレビューとしてレンダリングされます。キャラクターやテクスチャについて議論するとき、双方は自分自身のことを想像するのではなく、同じ具体的なものを見ます。コンパニオンの「リファレンス ピル」を使用すると、コンポーザに @ と入力してエージェントまたはリソースをクリック可能なタグに変換できます。最近使用したものを記憶し、ホバーするとツールチップが表示され、挿入後にクリックして戻ることができます。これらを組み合わせると、「会話にアセットを持ち込む」こと (長いパスをコピーして言葉で説明することを意味していました) が、直接のドラッグ アンド クリック アクションに変わります。

エンジン: 統合メッシュ レンダラー + マテリアル ハンドル + デフォルト値フォールバック

この日、エンジンはレンダリング層とコンポーネント層で重要な統合を行いました。レンダリングでは、「マテリアル ハンドル」によってマテリアルを参照する単一のメッシュ レンダラーに統合されました。つまり、オブジェクトの描画方法は「メッシュとマテリアルを指すハンドル」によって統一的に記述され、明確かつオブジェクト間で 1 つのマテリアルを簡単に再利用できます。コンポーネントでは、「エンティティの作成」と「コンポーネントの追加」により、デフォルト値のフォールバック チェーンが得られます。フィールドを明示的に設定しない場合、システムは、エラーや空白のままにするのではなく、階層化されたルールをたどって適切なデフォルトを見つけます。これは、ゲーム コンテンツの作成が「気になる部分だけを書き、残りは賢明なデフォルトのままにする」ことができ、定型文やエラーの表面を大幅に削減できることを意味します。このような収束は新しい機能ではありませんが、より多くの人 (および AI) がエンジンを使用しても、エンジンが「驚きが少なく、予測可能」であり続けるための鍵となります。

エンジン: 統合キャプチャ + コンソール依存関係の反転 + チュートリアルの例

この日、エンジンはまた、「重複」と「結合」のいくつかの箇所をクリーンアップしました。 1 つ目は、かつて複数の例に分散していた「スクリーンショット」ロジック (それぞれが独自のコピー) が、標準のレンダラー機能に統合されました。1 つの実装がどこでも使用できるため、重複が削減され、視覚的な検証がより一貫したものになります。 2 つ目: 「コンソール」デバッグ チャネルは依存関係が逆転しました。具体的な内部モジュールに直接依存するのではなく、抽象インターフェイスを通じて動作し、それらを切り離します。コンソールがより独立して進化し、プラグインが統一された方法でプラグインできるようになります。 3 つ目は、プログレッシブ レンダリング チュートリアルのサンプルの完全なセット (最も基本的な三角形とテクスチャから入力処理まで) が提供され、画像、テクスチャ、入力などの一般的な機能がエンジン自体に組み込まれました。これらの例は、エンジンの機能の生きたドキュメントであると同時に、初心者 (および AI) がエンジンの使い方を学ぶための最良の入り口でもあります。

この日が意味するもの

この日の 2 つのライン — インターフェイスでのマルチエージェントのコラボレーションを完全に「明らかに」することと、エンジンでのレンダリングとコンポーネントを大幅に「収束」すること — は無関係に見えますが、内部では 1 つの追求を共有しています。それは、急速に複雑化するシステムを人々にわかりやすく保つことです。インターフェイス側では、@-メンション、機能健全性ランプ、アセット プレビュー、リファレンス ピルが連携して、「AI チームの指揮」を抽象的なものから具体的に操作可能なものに変えます。エンジン側では、統合レンダラー、統合キャプチャ、依存関係の反転、およびチュートリアルのサンプルが連携して、機能が膨れ上がるにつれて低レベルが複雑になるのを防ぎます。長期的に進化できるシステムは、機能の外側への成長と内側への秩序の維持の両方が必要ですが、この日はまさにその両方が同時に行われました。
