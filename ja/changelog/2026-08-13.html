ForgeaX Studio v0.3.27：セットアップの安定化、プレビューの拡充、独立した Game Runtime パッケージ

v0.3.27 では初回セットアップの信頼性を高め、Windows のマーケットプレイスリンクを修正し、Studio にマテリアル・メッシュ・VFX プレビューを追加し、ゲームホストが独立公開されたランタイムパッケージを利用できるようにしました。

よりスムーズな初回セットアップ

Studio はセットアップ時に、各拡張機能が宣言したパッケージマネージャーとロックファイルに従うようになりました。Windows では Marketplace プラグインのディレクトリを利用可能なディレクトリリンクへ正規化し、シンボリックリンクのプレースホルダーを作業ディレクトリに使えないことによる子プロセスの失敗を防ぎます。

ホストにプレビューとアセットを統合

マテリアル、メッシュ、VFX のプレビュービューポートは editor facade 経由で登録され、Studio ホストから同じプレビュー機能を利用できます。アセットのインポートと catalog ベースのファイル操作も一貫したパスマッピングを使い、エディター上のパスとディスク上のファイルを揃えます。

Game Runtime を独立して公開

Game Runtime パッケージと SDK 宣言は独立したリリース対象としてビルドされます。ゲームホストは Studio 全体をビルドせずにランタイムを利用できます。

ForgeaX Studio v0.3.27 のリリースをご覧ください。
