它怎么加载 · 你怎么扩展How it loads · how you extend it

运行时加载Loaded at runtime

CLI 启动时按需挂载插件;agent 的人格只在被派发那一刻加载,共享部分同时附加给编排者与执行者。The CLI mounts plugins on demand; an agent's persona loads only when dispatched, with shared pieces attached to both orchestrator and worker.

你能做什么What you can do

在「面板管理 / admin」里启用、排序工作台,切换 AI 后端;也能用「插件作者」从空白写出第一个可加载插件。In the admin panel, enable and reorder workbenches and switch backends; or use the plugin-author wizard to write your first plugin.
