1시작하기 전에

ForgeaX는 무엇이며 어떤 게임을 만드는가

ForgeaX는 AI 기반 게임 개발 스튜디오입니다. 게임을 일반 언어로 설명합니다. AI 리드라는 사람이노 계획하고, 디자인하고, 실행 중인 게임 코드 자체에 기록합니다., 결과를 브라우저에 핫 리로드합니다. 말하는 내용이 바로 플레이되는 내용입니다.

아래에는 두 개의 사내 재단이 있습니다.AI의 관점에 맞게 재설계된 엔진(보다AI 기반 엔진이 필요한 이유) 그리고올바른 결과에 기능을 수렴하는 개발 루프(보다AI가 기능을 올바르게 가져오는 방법).

어울린다2D / 2.5D / 3D웹 게임. 플레이 가능한 FPS, 디아블로 스타일 ARPG, 2단계 서바이벌 및 슈팅 게임 데모가 이미 존재합니다.유리 진열장); 엔진은 PBR/IBL/SSAO 렌더링, 2D/3D 물리, 골격 애니메이션 및 듀얼 RHI를 다룹니다(하단의 "엔진 기능" 참조).유리 진열장).

모든 것이 브라우저(WebGPU), 웹, 데스크톱에서 하나의 스택으로 실행됩니다. Apache License 2.0에 따른 오픈 소스(특허).

2핵심 개념

"프로젝트"는 게임이다

ForgeaX에서는"프로젝트"와 "게임"은 같은 것입니다— 게임은 하나이다게임/<슬러그>/접는 사람. 실제 게임 폴더는 일반적으로 다음과 같습니다.

  • forge.json — 게임 매니페스트. 최소 3개 필드:ID,이름, 그리고기입(입력 코드를 가리킵니다. 예:src/main.ts).
  • FORGE.md — 게임 자체의 읽어보기/게임 플레이 개요(컨트롤, 메커니즘, 스토리 비트).
  • src/ — 게임 코드. 게다가main.ts항목은 일반적으로 관심사에 따라 모듈로 분할됩니다(예:player.ts,적/,효과.ts,setup.ts).
  • design/ · assets/ — 디자인 문서 및 예술/오디오 자산.
  • package.json · tsconfig.json — 표준 TS 프로젝트 파일.

그만큼main.ts항목은 다음에서 엔진 기능을 가져옵니다.@forgeax/엔진 런타임/엔진 EC/엔진 앱그리고 수출게임입장— 엔진이 게임을 로드하는 계약입니다. 전체 기능 세트에 대해서는 "엔진 기능"을 참조하십시오.유리 진열장.

여러 게임 = 여러 프로젝트, 상단 표시줄 프로젝트 전환기에서 전환됩니다. 장면/레벨 구성 방법은 다음을 참조하세요.장면 및 편집기.

Forge와 하위 에이전트 팀

포지(주요원)게임 코드를 직접 작성하는 유일한 프로그램입니다.games/<슬러그>/src/main.ts, 미리보기핫 리로드, 실행 결과를 보고 다음 단계를 결정합니다. 해당 편집 → 보기 → 편집 루프는 미리보기를 볼 수 있는 사람, 즉 Forge(Forge 참조)에게 있어야 합니다.채팅으로 구축).

하위 에이전트(예: Iori 게임플레이, Suzu 디자인, Kotone 내러티브, Iro 아트, Tsumugi 빌드) 계획/디자인/자산 만들기/문서 작성 및절대 만지지 마세요소스/— 실시간 미리보기 피드백이 없으므로 그들이 작성한 코드는 이를 조정할 수 없습니다. 전체 출연진은 다음에서 확인하세요.시장그리고10장 · 에이전트 팀.

파견 작동 방식:Forge는 하나의 도구 호출로 하위 에이전트를 파견합니다(예:하위 에이전트(type="iori", task="…")); 서버의/api/하위 에이전트스트림은 실시간으로 출력을 기본 대화로 다시 연결합니다. 이는 메시지 스트림에 표시되는 내장된 하위 에이전트 카드입니다. 하위 에이전트의 디자인 문서는 워크벤치의 자체 섹션 아래에 보관됩니다(참조:장면 및 편집기).

세션이란 무엇입니까?

에이세션에이전트의 메모리입니다.추가 전용이벤트 스트림(각각은 사용자 메시지/보조 메시지/생각/도구 호출/도구 결과)입니다. Forge(메인)와 각 하위 에이전트는 각각 자신의 것을 유지합니다.

UI는 이벤트를 메인 스레드와 하위 에이전트로 내보낸 사람에 따라 이벤트를 분할하여 각 하위 에이전트의 슬라이스를 내장된 카드로 렌더링합니다. 따라서 한 화면에서 Forge의 메인 스레드와 Forge가 파견한 하위 에이전트가 실제로 수행한 작업을 모두 볼 수 있습니다.

상단 표시줄 세션 전환기를 사용하여 지난 세션을 검토하고 전환하세요.세션을 전환해도 아무것도 다시 시작되지 않습니다.— UI는 다른 에이전트의 이벤트 스트림을 읽습니다.

오른쪽 기본 영역은 두 가지 보기 사이를 전환합니다.

  • 시사— 게임은 FPS 판독 및 재생/일시 중지/다시 로드 제어 기능을 갖춘 iframe에서 실시간으로 실행됩니다. Forge가 코드를 작성하면 여기에서 즉시 핫 리로드됩니다(참조:채팅으로 구축).
  • 작업대— 파일 브라우저 + 편집기: 텍스트 및 코드 보기/편집/저장, 마크다운 디자인 문서 렌더링, 이미지, 오디오, 비디오 및 3D 모델 미리보기. 또한 파일 활동 및 "편집 중인 사람" 잠금을 표시하므로 사용자와 AI가 방해 없이 동일한 파일을 편집할 수 있습니다.

파일이 열려 있지 않으면 워크벤치에 모든 생성 워크벤치(캐릭터/애니메이션/3D/장면/UI/음악...)에 대한 항목이 표시됩니다. — 참조창작 도구그리고시장. 자산을 만드는 방법은 다음을 참조하세요.자산.

장면 편집, 변경 사항이 실시간으로 다시 흐름

장면 편집기는 레벨의 내용을장면 데이터 파일게임 폴더(장면.팩.json) —단일 진실 소스해당 레벨에서는 디스크에 있는 것이 게임에서 실행되는 것입니다.

개체를 배치하고 편집 모드를 종료하면 변경 사항은 다음과 같습니다.디스크에 플러시되고 실행 중인 게임이 이를 다시 읽습니다., 미리보기에 편집 내용이 즉시 반영됩니다(편집→재생 왕복). 반대로, Forge가 채팅을 통해 코드를 변경하면 동일한 핫 리로드 경로를 따릅니다(참조:채팅으로 구축그리고실행 및 미리보기).

레벨과 개체를 구성하세요

게임은여러 장면/레벨, 각각의 장면 데이터는 필요에 따라 전환 및 재사용됩니다. "Cow Survivor" 데모는 주간 목초지와 야간 묘지 사이를 전환합니다(참조:유리 진열장).

정리하는 방법:사물장면 데이터에 살고 있는 동안예술/오디오 자산게임 폴더에 라이브(프로젝트 레이아웃핵심 개념, 자산 생성자산). 장면별로 분할하면 성장하는 게임을 유지 관리할 수 있습니다.

5자산: 예술/애니메이션/오디오

캐릭터 초상화 및 전환

사용캐릭터 에디터(wb 문자) 캐릭터 컨셉 디자인: 한 줄의 브리핑을 작성하고,초상화 + 턴어라운드. 게임용 캐릭터를 얻기 위해 그림 기술이 필요하지 않습니다.

출력(캐릭터 매니페스트 + 초상화/턴어라운드)은 게임 내 캐릭터별로 저장되며다운스트림 입력으로 애니메이션 워크벤치에 바로 피드— 따라서 "캐릭터 디자인 → 움직이게 만들기"는 하나의 연속 파이프라인입니다(다음 항목 참조).

각 작업대는 패널과 도구 세트로 구성됩니다. 당신이 직접 그리고 AI가 파견하여 동일한 아티팩트를 편집합니다. 전체 목록은시장그리고작업대 튜토리얼.

캐릭터를 움직이게 만들기(2D/3D)

2D:애니메이션 작업대(wb-anim) 캐릭터 초상화를 템플릿으로 사용하여 걷기, 공격, 4방향 모션, 짧은 클립까지 변환합니다.얼굴 드리프트 없이, 따라서 이동 후에도 동일한 문자를 유지합니다.

3D:엔진이 기본적으로 지원골격 애니메이션— 유휴 / 걷기 / 달리기 / 시전 / 죽음 사이의 부드러운 크로스페이드를 사용하여 FBX에서 조작된 스킨 모델과 애니메이션 클립을 가져옵니다. 이 파이프라인은 실제이며 배송됩니다. 쇼케이스에 등장하는 어둠의 판타지 마녀가 움직이는 방식입니다. 참조뼈대 애니메이션의 이정표그리고쇼케이스 (헬포지).

3D 모델, VFX, UI, 음악

캐릭터 외에도 전체 파이프라인에 걸쳐 작업대가 있습니다.

3D 모델

블록 문자 편집기(wb-lowpoly-obj, 엔진 중립 수출.glb), 노드 그래프 로우 폴리(wb-3d-저폴리), 텍스트/이미지/멀티뷰-3D(wb-gen3d, 공급자에 구애받지 않음). 자세히9장 · 3D 모델링 및 생성.

VFX/장면/UI/아이템

스킬 VFX(wb-스킬), 장면 생성 및 2D 장면 자산(WB 장면 생성기/wb-2d-장면-자산 생성기), UI 워크숍(wb-ui, 클릭 가능한 프로토타입) 및 항목 아이콘(wb-항목, 아트 + 데이터가 하나의 테이블에 있음). 자세히9장 · 장면/UI/아이템.

음악 / 외모 / 서사

음악 및 SFX(wb-bgm, BGM 타임라인), 컬러 그레이딩(WB 모양, 팔레트 + LUT + 포스트프로세스) 및 내러티브(wb-서사, 117개 장르 × 9개 템플릿). 자세히9장 · 서사 / 음악 / 외모 / 밸런스.

품목별 적용 범위는 다음과 같습니다.9장 · 생성 도구,작업대 튜토리얼, 그리고시장.

여기에서 바로 실행하세요(실제 예시)

이 페이지에서 실시간으로 실행되는 실제 ForgeaX 엔진 예제(WebGPU - Chrome/Edge 권장) 더 많은 실행 가능한 데모예그리고계략.

전체 화면 열기 ↗

웹 및 데스크톱 앱 모드

동일한 코드베이스는 세 가지 형식으로 실행됩니다.

  • 웹 개발—롤빵 FX 시작세 가지 서비스(서버/UI/엔진)를 부팅합니다. 열려 있는http://localhost:18920브라우저에서 실시간으로 핫 리로드를 편집합니다. macOS/Linux/Windows에서 작동합니다. 설치 위치시작하기 전에.
  • 데스크탑 개발—Bun FX 시작 앱동일한 라이브 소스와 HMR을 사용하여 동일한 개발 서버를 로드하는 기본 창을 엽니다. 먼저 자동 설치를 실행하고 스택을 시작한 후 창을 닫으면 스택이 중지됩니다. macOS/Linux/Windows에서 사용 가능합니다.
  • 데스크톱 .app(패키지)—Bun FX 빌드 앱독립적인 제품을 생산합니다..앱/.dmg자체 사이드카를 사용하여 두 번 클릭하면 실행됩니다(포트 18810/15273, 의도적으로 개발자의 18900/15173에서 오프셋되어 둘 다 공존할 수 있음). 그 열쇠는~/ForgeaxProjects/.env, 첫 실행 오버레이 포함. 포장은게시 및 공유.

3개의 포트는 모두 재정의 가능합니다..env~을 통해FORGEAX_{서버,인터페이스,엔진}_PORT. ⚠️ 데스크톱 창은 시스템 WebView를 사용하므로 3D는 Chrome보다 약간 약한 WebKit의 WebGPU에서 실행됩니다.최상의 영상을 보려면 브라우저를 사용하세요.

핫 리로드: 변경하면서 확인하세요.

저장하면 적용됩니다. 수동 새로 고침이 필요하지 않습니다.

  • 편집하다게임 코드(게임/<슬러그>/src/…) → 엔진이 모듈을 제자리에 핫스왑하고 미리보기가 즉시 업데이트됩니다(Forge의 편집도 이 기능을 사용합니다.채팅으로 구축).
  • 변경 사항장면 편집기디스크에 플러시하고 실행 중인 게임으로 다시 흐름(참조장면 및 편집기).
일반적인 문제 해결
  • 빈 미리보기/엔진 오류— 엔진이 제작되지 않았습니다. 재실행롤빵 FX 설정.
  • SSL 오류가 발생했습니다.:18920— 다음을 통해 액세스http://localhost(WebGPU는 여전히 localhost에서 작동합니다).
  • 사용 중인 포트— 사용 중인 포트에서 오류가 발생합니다(다른 포트는 자동으로 선택되지 않습니다). 달리다롤빵 FX 중지그 다음에롤빵 FX 시작또는 다음에서 포트를 변경하세요..env.
  • 채팅에 API 키가 없다고 말합니다- 세트ANTHROPIC_API_KEY~에.env(처음 실행 시 데스크톱 앱에 메시지가 표시됨) 키 설정이 완료되었습니다고급의.
  • 데스크탑에서는 3D가 약해 보입니다.— 시스템 WebView의 WebGPU 제한 사항 최상의 렌더링을 위해 Chrome 브라우저 빌드를 사용하세요.

7게시 및 공유

데스크톱 앱으로 패키지

Bun FX 빌드 앱스튜디오 전체를 게임과 함께 하나의 패키지로 패키징합니다.독립형 데스크탑 번들(맥OS.앱/.dmg): 잘린 런타임, 서버, Studio UI, 마켓플레이스 및 게임 콘텐츠가 모두 내부에 있으므로제로 설정으로 두 번 클릭으로 실행됩니다.사용자를 위해.

자체 포트(18810 / 15273)에 내장된 사이드카에서 실행되므로 개발 스택과 충돌하지 않습니다(참조:실행 및 미리보기). 패키징은 macOS에서 실행되어야 합니다. 포장된.앱더블클릭하면 열립니다.

게임 프로젝트를 공유하세요

게임은 하나다독립된게임/<슬러그>/접는 사람(forge.json+소스/+ 디자인 문서 + 자산, 참조핵심 개념). 해당 폴더를 공유하거나 커밋하면 다른 사람이 자신의 스튜디오에서 해당 폴더를 열어 계속 플레이하거나 구축할 수 있습니다. 데모 라이브러리에는 여러 게임(fps, hellforge, cow-survivor, Shoot-opt)이 나란히 저장되어 있습니다.유리 진열장.

현재로서는 플레이어에게 게임을 전달하는 가장 신뢰할 수 있는 방법은데스크탑 패키지위에; 보다 원활한 "원클릭 웹 게시/온라인 플레이"는 아직 작업 중입니다.

나만의 워크벤치 플러그인 작성

ForgeaX의 거의 모든 기능은런타임 로드 플러그인(개요는시장), 직접 추가할 수 있습니다.

오늘 가장 빠른 경로:기존 워크벤치 플러그인을 복사하고 조정합니다., 와 함께플러그인 작성자(wb-플러그인-작성자) 돕는다; 더욱 풍부한 인앱 비주얼 편집기(파일 트리 + 코드 편집기, 저장 → 자동 다시 로드)가 곧 출시됩니다. 빌드한 후에는 다음에서 활성화하고 순서를 변경하세요.관리자 패널— 플러그인은 런타임 시 CLI에 의해 마운트됩니다. 작업대의 종류를 확인하세요.창작 도구.

상담원 페르소나 맞춤설정

사용페르소나 편집자(wb-에이전트-페르소나): 목록에서 에이전트를 선택하고 텍스트 영역에서 페르소나를 편집한 다음저장 → 핫 리로드, 재시작 없음. 코드를 건드리지 않고도 에이전트에게 다른 캐릭터나 음성을 제공할 수 있습니다.

주 상담원과 하위 상담원이 누구인지, 기본 페르소나는 어디서 나오는지 알아보려면 다음을 참조하세요.핵심 개념그리고에이전트 팀; 전체 출연진은시장.

3D 소품/기계 자산 구축노드 프로그래밍("블록 연결"): 프로세스를 노드 그래프로 모델링하고, 하나의 매개변수를 변경하고, 전체 세트를 재생성합니다. 일괄, 재사용 가능, 파라메트릭 하드 표면 자산에 적합합니다.

wb-gen3d · 3D 생성

3D 자산세대 진입점: 생성 서비스를 선택하여 입력(텍스트/이미지/멀티뷰)을 주고,내구성, 게임 준비3D 자산 매니페스트. 여러 최고의 발전기에 연결되어 있어 가장 좋은 것을 선택할 수 있습니다. 단일 공급업체에 종속되지 않습니다.

장면/UI/아이템
wb-scene-generator · 장면 생성기

전체 게임 장면을 조립합니다.노드 프로그래밍: 구성, 배치 및 텍스처링을 그래프로 배치합니다. 전체 장면을 재생성하려면 언제든지 다시 실행하세요. 장면/레벨 구성 방법은 다음을 참조하세요.장면 및 편집기.

wb-2d-scene-asset-generator · 2D 장면 자산

또한 노드 프로그래밍일괄 생성장면의 작은 것(소품, 텍스처, 장식, UI 비트)자동 이름 지정 및 제출그래야 자산이 엉망이 되지 않습니다.

wb-ui · UI 워크숍

다음으로 설정된 전체 인터페이스를 생성합니다.장르, 화면 흐름, 시각적 스타일— UI 청사진, 구성 요소 자산 및클릭 가능한 대화형 프로토타입(단순한 이미지가 아님). 메뉴, 버튼, 체력 바를 한 번에.

wb-items · 아이템 / 아이콘

게임을 만들어 보세요아이템과 아이콘— 데이터가 첨부된 무기, 물약, 동전의 픽셀 아트.하나의 테이블에 예술과 데이터(항목.json) 사용자와 AI가 함께 편집하므로 서로 떨어지지 않습니다.

서사/음악/외모/밸런스
wb-narrative · 서사 워크숍

AI 기반 내러티브 파이프라인: 스파크부터 전체 스토리 및 세계까지. 그것은 커버117개 장르 × 9개 파이프라인 템플릿계층/모드 라우팅 및 동적 플래너를 통해 AI는 장르에 적합한 접근 방식과 단계를 선택합니다.

wb-bgm · 음악/BGM

게임의 관리음악과 음향 효과: 세션 전반에 걸쳐 재생되는 내용을 배치하는 BGM 타임라인과 음향 효과 명명 규칙 — 전체 점수가 하나의 목록으로 배열됩니다.

wb-look · 색상/룩디벨롭

게임 전체를 통일하다색상 분위기— 팔레트 + LUT + 전체 게임에 대한 필터와 같은 후처리 스택: 따뜻한 황혼, 추운 밤, 한 번의 클릭으로 전환되므로 시각적인 느낌이 한 번에 스냅됩니다.

wb-balance · 균형

숫자가 다음과 같은지 자동 테스트합니다.균형 잡힌: 전투 재시뮬레이션을 구동합니다(잔액-레심) N번 이상의 시행 및 대시보드승률 + 95% 신뢰 구간, 그런 다음 수동으로 조정하여 반복합니다. 데이터가 튜닝을 판단하도록 합니다. 그 재시뮬레이션도도구시장에서.

시스템 및 저작 도구
wb-code · 암호

찾아보기 및뛰어넘다소스/파일바로 작업대에요.채팅 스레드 전반에서 코딩 에이전트와 협력— AI가 지휘봉을 떨어뜨리지 않고 하나의 프로젝트에서 어디를 편집하는지 읽습니다.

wb-observatory · 전망대

처럼블랙박스: 모든 에이전트/하위 에이전트 차례, 도구 호출 및 시스템 프롬프트 조각의 실시간 + 오프라인 재생입니다. 뭔가 고장나면 할 수 있어요어떤 단계 또는 어떤 메시지가 표시되는지 정확히 파악발생하며 컨텍스트/스킬/가드레일/캐시 관리에 도움이 됩니다. 세션 및 재생 개념은 다음과 같습니다.핵심 개념.

wb-agent-persona · 페르소나 편집자

목록에서 에이전트를 선택하고 텍스트 영역에서 페르소나를 편집한 다음저장 → 핫 리로드, 재시작 없음. 코드를 건드리지 않고도 에이전트에게 새로운 캐릭터나 음성을 제공할 수 있습니다. 출연진은에이전트 팀; 방법은 에 있습니다고급의.

wb-plugin-author · 플러그인 작성자

하자코더가 아닌 사람자신만의 워크벤치 플러그인을 구축해 보세요. 오늘의 경로는 "기존 항목 복사 + 조정 + 작업 기록"입니다. 더욱 풍부한 인앱 비주얼 편집기(파일 트리 + 코드 편집기, 저장 → 자동 다시 로드)가 곧 출시됩니다. 전반적인 사용법은고급 · 나만의 플러그인 작성.

admin · 제어판

스튜디오의마스터 콘솔, 4개 섹션: 워크벤치 활성화/재주문, 모델 바인딩, 각 AI 백엔드의 인증 및 상태 확인, 플러그인 수 확인. 설정 패널과 동기화 상태를 유지합니다. 모든 플러그인과 모델 상태가 한 화면에 표시됩니다.

네 가지 디자인 기둥
Iori · 核心玩法师— 게임 플레이 기둥

"庵"(산 바위)의 이름을 따서 명명되었습니다. Forge가 그를 파견하면 그는 게임의 "뿌리"를 보호합니다.하중을 견디는 게임플레이의 기둥(메카닉+수치골격) 함부로 흔들리지 말아야 할 것을 하나의 간결한 기둥 문서에 담았습니다. 그는 아키텍처를 작성하거나, 매개변수를 조정하거나, 질문을 다시 하지 않습니다(Forge가 이러한 문제를 미리 처리했습니다). 기둥이 세워지면 Suzu가 인수합니다.

Suzu · 体验设计师— 속도 및 경험

"鈴"(바람 소리 — 리듬)의 이름을 따서 명명되었습니다. Iori가 기둥을 설정한 후 Suzu는 각 기둥의 모듈을 구체적인 경험으로 확장합니다.플레이어 속도, HUD, 온보딩. 그녀는 플레이하는 느낌을 정의한 다음 자산/스토리가 필요한 부분을 Iro/Kotone에게 전달합니다.

Kotone · 剧情师— 내러티브 (요청 시)

"琴音"(현을 통해 전달되는 이야기)의 이름을 따서 명명되었습니다.모든 게임에 내러티브 디자이너가 필요한 것은 아닙니다.— 타워 방어는 결코 그녀를 부르지 않을 것입니다; 게임에 캐릭터/대화/분기/내레이션이 필요할 때만 Forge는 그녀를 불러와 세계, 캐릭터 소개 및 대사를 제작합니다.

Iro · 美术师— 시각적 자산(요청 시)

"color"(눈이 인지하는 모든 것)의 이름을 따서 명명되었습니다. Suzu가 모듈의 경험을 구성하고 나면 Forge는 시각적 자산(캐릭터/장면/UI/VFX)이 필요한 경우에만 Iro를 파견합니다. 해당 자산이 실제로 어떻게 만들어지는지: 참조자산그리고창작 도구.

이들 전문가계획과 디자인만 하고 게임 코드는 건드리지 않습니다.(Forge는 코드를 작성합니다.핵심 개념); 그 결과는 작업대에 저장됩니다(참조:장면 및 편집기), 예술 자산은 다음과 같이 생산됩니다.자산.

코딩 및 검토 팀
cc-coder · 通用编码— 사양 → 코드

Iori의 게임플레이 핵심, Suzu의 UX 흐름 및 Kotone의 내러티브 개요를 가져와 실행 가능한 TS/React 등으로 전환합니다. 서로 다른 패키지에서 여러 인스턴스를 병렬로 실행할 수 있습니다. 참고: 게임의 메인 코드는 여전히 Forge 자체에서 미리보기와 함께 폐쇄 루프로 작성됩니다(참조핵심 개념); cc-coder는 일반/주변 코드에 더 적합합니다.

Tsumugi · 工程师— 빌드/툴체인

"紡"(시스템에 스레드를 엮는 것)의 이름을 따서 명명되었습니다. Iori/Suzu/Iro가 디자인과 자산을 준비하고 나면 Tsumugi는 이를 빌드, 툴체인, 배포 등 작업용 빌드에 결합합니다.

Yevi · 审查— 기술 부채 사냥꾼

깊은 물처럼 잔잔하고 우아하게 침착한 관찰자로서 항상 한발 앞서 있습니다. 그녀는 코드가 가장 약한 곳이 어디인지, 3주 전에 어떤 문제가 곧 표면화되는지 알고 있습니다. 정확하고 예리한 표현으로 측정되고 부드러운 톤.

Companion personas— 같은 스킬, 다른 성격

다음과 같은 선택적 문자 집합비슷한 코딩 기술이지만 개성이 뚜렷함— 일부는 측정되고, 일부는 장난스럽고, 일부는 꼼꼼합니다. 그들은 같은 능력을 가지고 있습니다. 유일한 차이점은 그들과 함께 일하는 느낌입니다. 개인정보는 언제든지 편집 가능합니다.페르소나 편집자(보다고급의); 전체 출연진은시장.

세트도 있어요예술/자산 전문 에이전트(2D 캐릭터/애니메이션, 3D 로우 폴리/VFX, 대화형 영화 감독 등), 각각 일치하는 제작 워크벤치에 연결됩니다(참조:창작 도구).

교체 가능한 기본 페르소나

각 CLI 백엔드는 즉시 사용 가능한 페르소나와 함께 제공됩니다.클로드(클로드 코드),사본,커서, 그리고ForgeaX(자체 제작 forgeax 네이티브).백엔드를 전환하면 기본 페르소나가 교체됩니다. 설정이 필요하지 않습니다.; 어떤 커널을 선택하든 기본 페르소나가 함께 제공됩니다.

백엔드를 전환하고 페르소나를 편집하는 방법은고급의; 전체 에이전트 캐스팅과 로드 가능한 페르소나는시장.
