플러그인

ForgeaX에서는 거의 모든 기능이로드 가능한 플러그인입니다. 종류별로 둘러보고 활성화하거나 재정렬하고, 직접 만들 수도 있습니다.

아린 · 프로듀서

디자인/코드/아트/오디오까지 코디하는 만능 프로듀서.

레이아 · 릴 디렉터

대화형 FMV 디렉터 — 프롬프트, QTE 속도, 분기 및 결말.

이오리 · 게임 플레이

핵심 메커니즘 - 게임플레이 기둥과 숫자 뼈대.

스즈 · 체험

플레이어 속도, HUD 및 온보딩.

코토네 · 내러티브

세계, 캐릭터 소개 및 대화.

이로 · 예술

초상화, 스프라이트, VFX 및 UI 방향.

cc-코더 · 코더

일반 코딩 — 사양을 실행 코드로 변환합니다. 선택적 동반자 페르소나.

떡 린 사쿠라 카에데 구모

츠무기 · 빌드

빌드, CI, 툴체인 및 배포.

예비·리뷰어

기술 검토 — 기술 부채를 식별하고 청산합니다.

2D Character Designer

캐릭터 에디터

한줄 브리핑 → 세로 + 턴어라운드.

2D Animator

생기

정지된 캐릭터를 걷고, 공격하고, 골격 동작으로 전환합니다.

3D VFX Artist

스킬 / VFX

화염, 베기, 오라 — 시전 순간에 자동으로 부착됩니다.

General Coder

블록 문자 편집기

블록과 같은 조작된 3D 캐릭터를 만들고 표준 3D를 내보냅니다.

Lowpoly Modeler

로우 폴리 생성기

노드 그래프 3D 소품; 매개변수를 변경하고 세트를 재생성합니다.

3D Character Artist

3D 생성

여러 생성기를 통해 텍스트나 이미지를 3D 모델로 바로 변환할 수 있습니다.

2D Scene Asset Artist

2D 장면 자산

배치 소품, 텍스처, 장식 및 UI 비트가 자동으로 정리됩니다.

Scene Composer

장면 생성기

전체 장면을 다시 실행 가능한 그래프로 조합합니다.

Game UI Designer

UI 워크벤치

귀하의 게임 유형에 맞는 클릭 가능한 UI 프로토타입입니다.

Narrative Writer

내러티브 워크벤치

스파크부터 전체 스토리와 세계까지.

Reel Director

인터랙티브 영화

스파크나 스크립트를 탭하고 선택하는 대화형 영화 게임으로 바꿔보세요.

아이템 / 아이콘

무기, 물약, 동전 - 아트와 데이터가 하나의 테이블에 있습니다.

색상 / 모양

한 번의 클릭으로 전체 게임의 색상 분위기를 통합합니다.

음악 / BGM

BGM 및 SFX를 관리하고 점수를 순서화합니다.

균형

암호

전망대
