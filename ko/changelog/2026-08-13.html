ForgeaX Studio v0.3.27: 더 안정적인 설정, 풍부해진 프리뷰, 독립 Game Runtime 패키지

v0.3.27은 최초 설정을 더 안정적으로 만들고 Windows 마켓플레이스 링크를 수정했으며, Studio에 머티리얼·메시·VFX 프리뷰를 추가하고 게임 호스트가 독립적으로 배포된 런타임 패키지를 사용할 수 있게 합니다.

더 원활해진 최초 설정

이제 Studio는 설정 과정에서 각 확장 기능이 선언한 패키지 관리자와 lockfile을 따릅니다. Windows에서는 Marketplace 플러그인 디렉터리를 사용할 수 있는 디렉터리 링크로 정규화하여, 심볼릭 링크 placeholder를 작업 디렉터리로 사용할 수 없어 자식 프로세스 플러그인이 실패하는 문제를 막습니다.

호스트에 프리뷰와 에셋을 연결

머티리얼, 메시, VFX 프리뷰 뷰포트가 editor facade를 통해 등록되므로 Studio 호스트에서 동일한 프리뷰 기능을 사용할 수 있습니다. 에셋 가져오기와 catalog 기반 파일 작업도 하나의 표준 경로 매핑을 사용하여 에디터 경로와 디스크 파일을 일치시킵니다.

Game Runtime 독립 배포

Game Runtime 패키지와 SDK 선언을 독립적인 릴리스 표면으로 빌드합니다. 게임 호스트는 전체 Studio 빌드 없이 런타임을 사용할 수 있습니다.

ForgeaX Studio v0.3.27 릴리스를 확인하세요.
