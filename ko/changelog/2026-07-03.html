Windows Play 모드 안정화 + 개발자 LLM 디버그 프록시

편집기 소켓 스택 수정으로 Windows의 Play 모드가 안정되었습니다. 새로운 FORGEAX_DEBUG_PROXY 환경 변수를 통해 개발자는 모든 LLM API 트래픽을 실시간으로 캡처하고 검사할 수 있습니다. Windows 데스크톱 앱 패키징이 수정되었습니다. 릴 게임 런타임 아키텍처가 엔진 레벨 게임 런타임 서브클래스로 설계되었습니다.

Windows Play 모드: 드디어 안정

Windows의 Play 모드는 편집기의 Socket 스택 문제로 간헐적으로 실패했습니다. 기본 WebSocket 내보내기가 데스크톱 빌드 경로에서 누락되어 엔진 미리보기 iframe이 편집기 호스트와의 연결이 끊어졌습니다. 이 문제가 수정되어 Windows의 Play 모드가 macOS만큼 안정적으로 작동합니다.

개발자용 LLM 디버그 프록시

새로운 옵트인 환경 변수 FORGEAX_DEBUG_PROXY가 추가되었습니다. 설정하면 모든 아웃바운드 LLM API 호출(Anthropic, OpenAI, Gemini 등)을 캡처하고 요청/응답 쌍을 기록하는 로컬 HTTP 프록시가 시작됩니다. .env에 설정하면 bun fx start와 함께 자동으로 시작됩니다.

Windows 데스크톱 앱 패키징 수정

Windows용 Tauri 2 데스크톱 빌드가 인터페이스 패키지의 종속성 내보내기 누락으로 실패했습니다. 수정됨 — bun fx build app이 이제 Windows에서 정상적으로 .exe 설치 프로그램을 생성합니다.

릴 게임 런타임 아키텍처

릴 게임(인터랙티브 필름) 런타임의 설계 사양이 확정되어 엔진 내 일급 게임 런타임 서브클래스로 위치합니다. 구현은 향후 릴리스에서 이어집니다.
