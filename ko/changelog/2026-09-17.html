접을 수 있는 역할 협업 영역에서 작업 인계, 진행 상황, 처리 대기 항목을 확인하고 역할별 대화로 이동할 수 있습니다. 병렬 위임을 별도 카드로 표시하며 원래 작업 정보를 유지하고 할 일 목록과 구분합니다.

권한 확인, 대화, 장면 편집 업데이트

  • 접을 수 있는 역할 협업 영역에서 작업 인계, 진행 상황, 처리 대기 항목을 확인하고 역할별 대화로 이동할 수 있습니다.
  • 병렬 위임을 별도 카드로 표시하며 원래 작업 정보를 유지하고 할 일 목록과 구분합니다.
  • 동시 질문을 함께 표시하되 요청별 식별자를 유지하여 답변이 다른 작업에 전달되지 않도록 합니다.
  • 연결 실패, 검증 실패, 중단을 구분하고 원래 오류를 유지하면서 이후 작업 상태를 표시합니다.
  • 대화의 로컬 파일 참조는 잘못된 브라우저 주소 대신 경로 복사를 제공하며 일반 웹 링크는 유지됩니다.
  • 여러 텍스트 파일을 명시적으로 읽는 도구를 추가하고 파일별 결과와 오류를 유지하며 출력 크기를 제한합니다.
  • Escape는 열린 오버레이를 먼저 닫고 Play를 암묵적으로 종료하지 않아 게임의 일시 정지와 메뉴 처리를 유지합니다.
  • 동일 출처 창 사이에서 설정 변경을 새로 고치고 창이 다시 포커스를 받을 때 캐시를 재검증합니다.
  • 모델 목록 요청 실패 시 제공자별 최근 성공 목록을 유지하되 명시적 빈 응답은 삭제된 모델을 복원하지 않습니다.
  • 피드백 전달 상태를 기존 카드를 숨기지 않고 갱신하며 실패 시 캐시를 유지하고 패널을 닫으면 폴링을 중지합니다.
  • 커널 권한 변경은 전체 설정 대신 선택한 커널만 갱신하여 동시 저장 시 다른 커널 설정 덮어쓰기를 방지합니다.
  • 3D 라이브러리 후보 조회, 선택한 소스 다운로드 및 검증, 일반 편집기 가져오기 전 준비 기능을 추가했습니다.
  • 유효한 에셋 식별자를 유지하는 메타데이터 복구를 추가하고 경로 이탈과 잘못된 기존 메타데이터를 거부합니다.
  • Play 실패 시 뷰포트에서 읽기 쉬운 원인과 복구 안내가 포함된 닫을 수 있는 알림을 볼 수 있습니다.
  • 에셋 재구축 실패 시 마지막 사용 가능한 상태를 유지하고 취소나 세션 종료 후 늦은 복구 결과를 반영하지 않습니다.
  • 오디오 검증을 준비, 게임 통합, 실제 실행 단계로 구분하며 정적 검사 통과를 실제 재생 성공으로 보지 않습니다.
  • 직접 전달하는 재생 호출을 인식하고 가려진 변수나 무관한 동명 함수를 실제 재생으로 오인하지 않습니다.
  • 일회성 커널 호출에서는 입력을 닫고 지속 통신에서는 파이프 입력을 유지할 수 있습니다.
  • 확장 로딩, 페이지와 패널 기여, 네이티브 메뉴, 문맥 기반 키 라우팅을 위한 앱 호스트 인터페이스를 확장했습니다.
  • 네이티브 문맥 압축의 시작, 완료, 실패, 취소를 추적하며 수동 압축은 실제 완료를 기다리고 중복 이벤트를 제거합니다.
  • 히스토리 재생에서 처리된 사용자 입력의 중복을 피하고 원래 세션 증거를 유지하면서 도구 출력 미리보기를 제한합니다.
