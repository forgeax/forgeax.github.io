3D 생성 수정 + 워크벤치 i18n + TUI 에이전트 터미널

wb-gen3d와 wb-ai-asset 워크벤치에 중요한 3D 파이프라인 수정이 적용되었습니다. 세 개의 창작 워크벤치(캐릭터, AI 에셋, 3D 생성)가 완전히 국제화되었습니다. 새로운 TUI(터미널 UI)가 키보드 기반 에이전트 인터페이스를 제공합니다. Settings API Keys가 LiteLLM 전용으로 간소화되었습니다. CLI에 auto-inject slug와 구조화된 에러 코드가 추가되었습니다. 두 개의 새 게임 씬 팩(Slagdeep Hollow 편집 가능 씬, Rogue Encampment 바닥 모델)이 출시되었습니다.

3D 생성 파이프라인 수정

wb-gen3d(3D 모델 생성)와 wb-ai-asset(AI 에셋 생성) 워크벤치의 3D 출력 파이프라인에 중요한 수정이 적용되었습니다. 이전에는 머티리얼 할당 문제로 생성된 모델이 뷰포트에서 올바르게 렌더링되지 않을 수 있었습니다. 수정 완료 — 생성된 3D 에셋이 올바른 PBR 텍스처로 즉시 표시됩니다.

워크벤치 완전 국제화

세 개의 창작 워크벤치(wb-character, wb-ai-asset, wb-gen3d)가 모든 지원 언어에서 완전히 국제화되었습니다. 패널 레이블, 툴팁, 상태 메시지, 에러 상태가 모두 번역되었습니다.

TUI: 터미널 에이전트 인터페이스

코어 에이전트 런타임을 위한 새로운 터미널 UI(TUI)가 F1/F2/F3 인수 테스트를 통과했습니다. 터미널에서 직접 에이전트와 상호작용할 수 있는 키보드 기반 인터페이스를 제공합니다.

Settings API Keys 간소화

Settings의 API Keys 섹션이 LiteLLM 전용 구성으로 간소화되었습니다. 각 공급자별 개별 키 관리 대신 단일 LiteLLM 프록시 엔드포인트만 설정하면 모든 모델로 라우팅됩니다.

CLI 개선

CLI가 프로젝트 slug를 도구 호출에 자동 주입하여 "프로젝트를 찾을 수 없음" 에러를 해소합니다. 또한 핸들러 에러가 구조화된 에러 코드를 반환합니다.

새로운 게임 씬 팩

두 개의 새 게임 콘텐츠 팩: Slagdeep Hollow(편집 가능한 씬 팩 + 런처 덴 시작 위치)와 Rogue Encampment(던전 크롤러 스타일 바닥 모델)가 추가되었습니다.
