뷰포트 Gizmo 개선 + Composer 이미지 붙여넣기 + Agent 페르소나 i18n + iOS 내보내기

뷰포트와 Inspector에 6가지 수정이 적용되었습니다: Focus 버튼이 고정 오버헤드 앵글로 프레임 선택을 트리거, 스케일 Gizmo가 엔티티 로컬 축을 따라 방향 지정, 숫자 필드가 소수점 4자리로 반올림, 마우스 이벤트가 canvas 범위로 제한, Group 노드가 자식 중심에 배치, 리페어런트 시 월드 위치 보존. 제품 측면에서 Composer가 이미지 붙여넣기를 지원하고, Agent 페르소나가 이중 언어를 지원하며, iOS Xcode 프로젝트 내보내기에 WKWebView 디버그 빌드가 추가되었습니다.

뷰포트 Gizmo 개선 — 하루에 6가지 수정

에디터 뷰포트에 집중적인 수정이 적용되었습니다:

  • Focus 버튼: 고정 오버헤드 앵글로 적절한 frameSelection을 트리거하여 원클릭으로 엔티티를 뷰포트 중앙에 배치합니다.
  • 스케일 Gizmo 로컬 축: 스케일 Gizmo가 월드 축 대신 엔티티의 로컬 좌표축을 따라 방향이 지정됩니다.
  • Inspector 숫자 반올림: Inspector 숫자 필드가 소수점 4자리로 반올림되어 표시 떨림이 해소되었습니다.
  • Canvas 제한 입력: 마우스 이벤트가 canvas 범위로 제한되어 뷰포트 외부의 클릭이 의도하지 않은 씬 상호작용을 트리거하지 않습니다.
  • Group 중심 배치: 그룹 생성 시 그룹 노드가 자식의 기하학적 중심에 배치되며 Gizmo 새로고침이 지연됩니다.
  • 리페어런트 월드 위치 보존: Hierarchy에서 엔티티를 새 부모로 드래그하면 월드 공간 위치가 보존됩니다.

Composer 이미지 붙여넣기

Composer 채팅 입력에 이미지를 직접 붙여넣을 수 있습니다. 스크린샷, 클립보드 이미지, 파일을 메시지에 첨부할 수 있습니다.

Agent 페르소나 이중 언어 지원

모든 내장 Agent 페르소나가 영어와 중국어 모두의 페르소나 텍스트와 장기 기억을 제공합니다.

iOS 내보내기: WKWebView 디버그 빌드

iOS Xcode 프로젝트 내보내기가 디버그 빌드에서 WKWebView.isInspectable = true를 설정하여 Safari Web Inspector로 라이브 디버깅이 가능합니다.
