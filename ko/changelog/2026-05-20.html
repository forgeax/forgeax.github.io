채팅이 새 백엔드에 다시 연결 + 설정에서 모델 및 키 관리

백엔드는 전날 채팅 인터페이스에 다시 연결되었습니다. 모든 흐름에서 세션 생성, 전환 및 삭제, 기록이 전체 재생되고 프로세스가 시스템 라인(수신/발신/경고/오류)을 구별합니다. 시각적 관리를 위해 모델과 키가 설정 패널로 이동되었습니다. 질감이 있는 다중 조명 조명으로 채워진 엔진과 고정된 1인칭 카메라 로밍.

"다시 작성됨"에서 "다시 연결됨"으로

전날 백엔드를 해체하고 계층화되고 충돌 복구가 가능한 새 아키텍처에 다시 넣었지만 재작성을 완료하는 것은 작업의 절반에 불과합니다. 새로운 기반은 실제로 인터페이스에 다시 연결하고 전체 체인을 실행하여 착륙한 것으로 간주해야 합니다. 오늘의 작업은 "다시 연결"이었습니다. 즉, 채팅 인터페이스를 새로운 백엔드 런타임에 연결하고 일상적인 세션 작업(생성, 전환, 삭제, 재생)을 모두 새로운 아키텍처에서 수행하고 모델과 키 관리를 인터페이스로 이동하는 것이었습니다. 즉, 전날은 "새로운 기초가 서 있다"는 것을 증명했습니다. 이날 "새로운 기반이 사용 가능하다"는 사실이 입증됐다. 대대적인 재작성에서 가장 위험한 순간은 재작성 자체가 아니라 깨진 유리를 곳곳에 남기지 않고 상위 레이어를 원활하게 다시 연결할 수 있는지 여부인데, 오늘은 그 장애물을 정확히 제거했습니다.

채팅이 더 원활한 세션으로 새 백엔드에 다시 연결됩니다.

오늘은 채팅 인터페이스가 새로운 백엔드 런타임에 연결되었고 일상적인 세션 작업이 질서정연하고 원활해졌습니다. 이제 세션을 생성하면 여러 개가 각자의 작업을 수행하는 대신 하나의 일관된 진입점이 있습니다. 세션을 전환하면 해당 탭이 자동으로 열리므로 주의가 콘텐츠를 따라갑니다. 삭제는 한 단계입니다. 세션을 다시 열면 컨텍스트가 그대로 유지된 상태로 지속 가능한 레코드에서 이전 앞뒤로 전체 내용이 재생됩니다. 또한 이 프로세스는 시스템 메시지를 수신/발신/경고/오류로 분류합니다. 따라서 실행이 잘못되면 얽힌 출력 덩어리를 쳐다보는 대신 어떤 단계에 멈춰 있고 어떤 종류인지 한눈에 알 수 있습니다. 이는 "세션"이 일일 단위로 가져야 할 기본 사항이며, 오늘은 이를 새로운 아키텍처에서 확실하게 전달했습니다.

세션과 기록은 깔끔한 인터페이스를 통해 전달됩니다.

"다시 연결"하는 동안 백엔드는 세션 및 기록 기능을 하나의 깔끔한 인터페이스 세트로 통합했습니다. 세션 생성 및 삭제는 표준 생성/삭제 엔드포인트를 거치며 기본 에이전트가 자동으로 준비됩니다. 최상위 수준에서 에이전트를 생성하거나 한 번에 종속 항목과 함께 삭제하는 경우 각각에는 명확한 해당 명령이 있습니다. 기록은 라이브 스트림에 모든 것을 채우는 대신 전용 가져오기 인터페이스를 통해 요청 시 읽혀집니다. 기본 에이전트 목록은 이제 모든 에이전트 변경 이벤트가 글로벌 로그에 기록되는 "상태 없는 디스크 검사 + 파일 변경 사항 감시"를 통해 유지 관리됩니다. 이러한 기능을 명확한 단일 책임 인터페이스로 통합한다는 것은 상위 계층(인터페이스, 명령줄, 심지어 미래의 다른 클라이언트까지)이 각각 자체적으로 작성하는 대신 모두 동일한 규칙에 따라 작동할 수 있음을 의미합니다. 바로 전날의 계층화된 아키텍처가 배당금을 지불하기 시작하는 곳입니다.

설정에서 바로 모델과 키를 관리하세요

오늘은 빈도가 높지만 이전에는 번거로웠던 두 가지 항목("어떤 모델, 어떤 키")을 인터페이스로 옮겼습니다. 이제 모델 선택기는 사용 가능한 모델의 실제 목록을 읽으므로, 오래된 하드코딩된 목록이 아니라 실제로 적용되는 모델을 선택합니다. 그리고 각 상담원이 개별적으로 사용하는 모델을 할당하여 다양한 역할이 다양한 계층을 사용할 수 있도록 할 수 있습니다. 키 입력은 값 표시와 숨기기 사이를 전환할 수 있는 눈 토글이 있는 영구 설정 패널로 이동했습니다. 확인하기 편리하지만 영원히 눈에 띄지 않는 상태로 두지는 않습니다. 사용자의 경우 이는 키를 채우거나 모델을 전환할 때 더 이상 명령줄로 이동하거나 구성 파일을 파헤칠 필요가 없음을 의미합니다. 항상 인터페이스에 속했던 일이 이제 실제로 그곳에서 발생합니다. 이러한 작업에 대한 기준을 낮추는 것은 비전문 개발자가 시작할 수 있도록 하는 핵심 부분입니다.

엔진: 텍스처 조명 + 한 장면의 여러 조명

오늘도 엔진의 조명은 실용성을 향해 계속 채워졌습니다. 하나는 "텍스처 기반 조명"입니다. 텍스처를 사용하여 표면의 서로 다른 부분이 빛에 얼마나 강하게 반응하는지 제어합니다. 예를 들어 금속 인레이를 주변 나무보다 밝게 만들거나 마모된 부분을 더 어둡게 만들어 전체 표면을 하나의 균일한 재료로 처리하는 대신 재료 디테일을 크게 풍부하게 합니다. 다른 하나는 "한 장면의 다중 조명"입니다. 포인트 캐스터와 스팟 캐스터를 결합하여 여러 조명을 동시에 밝힐 수 있습니다. 함께 이러한 조명은 "단 하나의 램프"에서 "실제 장면처럼 깊이를 만들기 위해 여러 조명을 배열"하는 것으로 이동합니다. 분위기 있고 촉각적인 이미지를 원하는 사람에게 이것은 "조명"과 "멋진" 사이의 가장 중요한 확장입니다.

엔진: 1인칭 카메라 로밍 고정 + 질감 있는 장면

이날은 1인칭 카메라 로밍도 수정되었습니다. WASD 동작은 고전적인 작은 함정에 뿌리를 두고 작동하지 않았습니다. 즉, 키보드 이벤트가 "물리적 키 위치"를 읽는지 아니면 "문자"를 읽는지 여부가 정렬되지 않아서 누르기가 아무 작업도 수행하지 않았습니다. 일단 수정되면 WASD를 사용하여 장면 주위를 돌아다니며 보기를 돌릴 수 있습니다. 이는 "방황할 수 있는 장면"의 가장 기본적인 상호 작용입니다. 이와 함께 텍스처 장면이 엔드 투 엔드로 실행되도록 제작되었으며 외부 자산 주소 처리가 수정되어 텍스처가 배포 경로 전체에서 올바르게 발견되었습니다. 여러 개의 빛과 질감이 빛나고 있는 장면 속으로 자유롭게 걸어들어가 주변을 둘러볼 수 있게 된 오늘은 '방황할 수 있는 세상 만들기'를 한 단계 더 발전시켰습니다.

오늘의 의미

오늘은 전날의 "다시 쓰기"를 진정으로 "사용 가능한" 것으로 바꾸어 놓았습니다. 백엔드의 새로운 기반은 세션, 모델, 키 등 일상적인 작업을 통해 인터페이스에 다시 연결되어 새 아키텍처에서 원활하게 실행되고 깔끔한 인터페이스로 수렴되었습니다. 엔진은 조명과 카메라를 동시에 발전시켜 이미지에 더 깊이를 더하고 장면을 더 걷기 쉽게 만듭니다. 한편으로는 대대적인 하급 수술을 상층부까지 원활하게 재연결시키는 일, 아무런 후유증 없이 원활하게 연결되는 일, 다른 한편으로는 사용자가 직접 느끼는 경험을 꾸준히 추가합니다. 두 가지를 병행하는 것은 감히 철저한 리팩토링을 수행하면서도 매일 사용자를 위해 제품을 조금 더 좋게 만드는 것을 잊지 않은 팀을 보여줍니다. 대대적인 재작성 직후 당일 인터페이스를 다시 연결하고 모델 및 키 관리와 같은 직접적인 경험을 작성할 수 있다는 것 자체가 "재작성이 제대로 이루어졌다"는 최고의 증거입니다.
