당신의개인의게임 스튜디오.

ForgeaX는 AI 기반 게임 개발 스튜디오입니다. AI가 엔진 코드를 작성하고 브라우저에서 실시간으로 핫 리로드되는 동안 아이디어를 플레이 가능한 게임으로 바꿔보세요. 더 특이한 점은 다음과 같습니다.엔진과 플랫폼 자체는 자체 실행 개발 루프에서 거의 전적으로 AI에 의해 한 줄씩 작성됩니다.— 그리고 일일 자체 빌드는변경 내역, AI를 위한 일종의 장기 개발 메모리입니다.

오픈 소스

소규모 팀이 더 큰 게임을 만들 수 있도록 하세요.

다양한 창작 방법

채팅, 시각적 편집기, 나중에 이미지/비디오 입력 등 원하는 방식으로 아이디어를 표현하세요.

설계상 에이전트

에이전트는 엔진 코드를 계획, 설계 및 작성합니다. 요구 사항을 설정하고 검토합니다.

실시간 핫 리로드

모든 변경 사항은 즉시 미리보기에 표시됩니다. 말하는 내용이 바로 플레이되는 내용입니다.

실제 ECS 엔진

브라우저 스튜디오에서 듀얼 RHI 렌더링을 갖춘 진정한 엔터티-컴포넌트-시스템 엔진입니다.

AI 기반 게임플레이

AI로 게임을 만드는 것뿐만 아니라 지능형 NPC, 생성 콘텐츠, 대화형 AI 경험 등 플레이 자체에 AI를 구축합니다.

스스로 진화하는 개발 루프

ForgeaX 폐쇄 루프는 요구 사항 → 빌드 → 자체 피드백을 통해 학습하고 시간이 지남에 따라 꾸준히 성장하는 파이프라인을 확인합니다.

브라우저에서 실행

WebGPU 기반, 웹과 데스크탑이 하나의 스택에 있으며 1분 안에 실행됩니다.

오픈 소스

Apache 2.0 — 무료로 포크하고, 사용하고, 배송하고, 상업적으로 구축할 수 있습니다.

당신만의 AI 에이전트를 사용하세요

두뇌는 ForgeaX에, 엔진은 당신에게
1

ForgeaX가 두뇌를 제공

자체 개발한 오케스트레이션 커널과 페르소나 Forge: 멀티 에이전트 팀이 계획, 위임, 엔진 코드 작성, 결과 보고를 담당합니다.

2

로컬 CLI가 엔진을 제공

이미 요금을 내고 있는 코딩 에이전트(또는 일반 API 키)를 추론 백엔드로 연결하세요. AI에 두 번 결제할 필요가 없습니다.

3

한 곳에서 언제든 전환

패널에서 프로바이더를 고르기만 하면 엔진이 교체됩니다. 페르소나와 워크플로는 그대로, 코드를 다시 쓸 필요가 없습니다.

선택할 수 있는 7가지 추론 엔진
forgeax cli자체 완결형 forgeax-cli — 바로 사용할 수 있는 권장 CLI입니다.
Claude Code당신의 Claude Pro / Max 구독 또는 Anthropic API 키를 사용하세요. OpenAI Codex당신의 ChatGPT Plus / Pro 요금제에 로그인하거나 OpenAI API 키를 사용하세요. CursorCursor Agent CLI를 통해 당신의 Cursor Pro 구독을 연결하세요. Kimi CodeKimi 멤버십 또는 Moonshot AI API 키를 사용하세요. DeepSeek Harness로컬 dsh CLI를 DeepSeek API Base URL과 키로 사용하세요. 개발자 프리뷰이며 모델과 프로필은 dsh가 관리합니다. CodeBuddyCodeBuddy Code CLI로 구동 — 로그인을 자체 관리하며 바로 연결됩니다.

벤더 종속 없음 —— 편한 AI를 언제든 자유롭게 전환하세요.
