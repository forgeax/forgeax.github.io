AI CLI 복제 및 ForgeaX 실행

가장 AI 기반 설치: 명령을 직접 입력하지 마세요. 리포지토리를 코딩 CLI 에이전트에 전달하고 로컬 URL을 복제, 설치, 실행 및 보고하도록 하세요.

✅ 오픈 소스(Apache-2.0). 아래 흐름은 모든 AI 코딩 CLI에서 작동합니다.

필요한 것

  • 쉘 명령을 실행할 수 있는 AI 코딩 CLI — 예:클로드 코드,사본,커서, 또는 ForgeaX 자체forgeaxCLI;
  • 자식그리고혈액 요소 질소(프로젝트 런타임)이 설치되었습니다.
  • AI 모델 API 키(스튜디오 내부 Forge용)

CLI에 대한 단일 지침

빈 폴더에서 CLI를 열고 다음을 제공합니다.

https://github.com/ForgeaX-Games/forgeax-studio(--recurse-submodules 포함)를 복제하고 여기에 CD를 넣고 설치 스크립트를 실행하여 종속성을 설정한 다음 시작 스크립트를 실행하여 실행하고 열 수 있는 로컬 URL을 알려주세요.

CLI는 복제/설치/실행 단계 자체를 실행하여 도중에 필요한 모든 항목(예: API 키)을 요청합니다. 완료되면 로컬 URL을 얻게 됩니다. 브라우저에서 이를 열면 스튜디오에 있게 됩니다.

수동 등가물(선택 사항)

직접 수행하려는 경우 대략 다음과 같습니다.

git clone --recurse-submodules \
  https://github.com/ForgeaX-Games/forgeax-studio
CD forgeax-스튜디오
bun fx setup # 설치 deps (+ API 키 추가)
bun fx start # 스튜디오 시작

이것들롤빵 FX명령은 크로스 플랫폼입니다. macOS, Linux 및 Windows에서 동일하며 Windows에서는 Git-Bash가 필요하지 않습니다. 그런 다음 인쇄된 로컬 URL을 엽니다.
