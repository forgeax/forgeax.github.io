작업대를 사용하여 예술 작품 만들기

채팅 외에도 ForgeaX에는 "작업대" 세트가 있습니다. 각 작업대에는 문장을 게임에 바로 사용할 수 있는 자산으로 바꾸는 도구 그룹과 패널이 포함되어 있습니다. 당신은 손으로, AI는 파견으로 동일한 아티팩트를 편집합니다.

✅ 오픈 소스(Apache-2.0). 다음은 워크벤치 시스템의 개요입니다. 복제 및 설치에 대해서는 다음을 참조하세요.문서.

캐릭터 · 애니메이션 · VFX

  • 캐릭터 에디터— 한 줄의 브리핑을 작성하고 초상화와 회신을 받으세요.
  • 생기— 얼굴 드리프트 없이 정지된 캐릭터를 걷기, 공격, 4방향, 골격 모션(짧은 클립이라도)으로 전환합니다.
  • 스킬 / VFX— 불, 베기, 오라와 같은 효과를 시전하는 순간에 자동으로 추가됩니다.

3D 모델링 및 생성

  • 블록 문자 편집기— 스냅 블록과 ​​같은 조작된 3D 캐릭터를 만들고 표준 3D 파일을 내보냅니다.
  • 로우 폴리 생성기— 노드 그래프를 사용하여 3D 소품을 구축합니다. 하나의 매개변수를 변경하고 세트를 재생성합니다.
  • 3D 생성— 텍스트 또는 이미지가 3D 모델로 바로 변환되고 여러 최고 생성기에 연결되어 가장 좋은 것을 선택합니다.

장면 · UI · 아이템

  • 장면 생성기— 언제든지 다시 실행할 수 있는 그래프로 전체 게임 장면을 구성합니다.
  • 2D 장면 자산 생성기— 일괄 소품, 텍스처, 장식 및 UI 비트가 자동으로 명명되고 제출됩니다.
  • UI 워크벤치— 게임 유형에 맞는 UI 세트 — 단순한 이미지가 아닌 클릭 가능한 프로토타입입니다.
  • 아이템 / 아이콘— 무기, 물약, 동전을 하나의 테이블에 데이터, 아트, 숫자와 함께 아이콘으로 표시합니다.

서사 · 음악 · 외모 · 숫자

  • 내러티브 워크벤치— AI가 적절한 접근 방식을 선택하여 스파크부터 전체 스토리 및 세계까지.
  • 음악 / BGM— 배경 음악과 음향 효과를 관리하고 전체 세션의 악보를 순서대로 지정합니다.
  • 색상 / 모양— 모든 것에 대한 필터처럼 한 번의 클릭으로 전체 게임의 색상 분위기를 통합합니다.
  • 균형— AI가 수천 번의 경기를 치르고 신뢰 구간과 함께 승률을 보고하도록 합니다. 데이터가 튜닝을 판단하게 하세요.

시스템 및 저작 도구

  • 암호— 코드를 찾아보고, 파일 사이를 이동하고, 코딩 AI와 함께 편집하세요.
  • 전망대— AI가 수행한 모든 단계를 블랙박스처럼 재생하여 문제가 발생한 위치를 찾아냅니다.
  • 플러그인 작성자— 코더가 아닌 사람들도 자신만의 워크벤치 플러그인을 만들 수 있습니다.
  • 관리자— 스튜디오 제어판: 작업대 전환, 모델 바인딩, 온라인 상태인 AI 확인.
그림을 그리거나 모델을 만들거나 작곡을 할 수 없나요? 괜찮습니다. 설명하면 워크벤치가 게임에 바로 적용되는 자산을 생성합니다.
