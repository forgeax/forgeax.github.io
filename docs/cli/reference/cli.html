CLI 命令参考 ​

用法 ​

text
forgeax -p "<prompt>"     一次性 print 模式
forgeax                   REPL / TUI
forgeax --demo -p "hi"    演示（无需 API key）
forgeax mcp-serve         反向 MCP server（stdio）
forgeax --serve --sock <path>   AgentKernel sidecar（进阶）

命令别名：全局 bin 同时提供 forgeax 与 forgeax-cli（同一入口）。

Flags ​

Flag说明
-p, --print <prompt>跑一轮后退出
--output-format <fmt>text（默认）| json | stream-json
--model <id>模型 id
--demo内置 echo provider，无网络
--memory <dir>auto-memory 目录（默认 ./.forgeax/memory）
--no-memory关闭 auto-memory
--skills <dir,...>skill 根目录（否则自动发现）
--commands <dir,...>markdown command 目录
--mcp <config.json>MCP 配置；否则自动发现 mcp.json
--mcp-token <s=ENV|ENV>MCP bearer 的 env 名（按 server 或通配）
--plugins <dir,...>plugin 源目录
--hooks <config.json>PreToolUse 等 hooks
--search-url <url>web_search 后端
--thinking [budget]扩展思考（可选 token budget）
--resume <id>持久化并续接会话
--session-id <id>指定会话 id（新或已有；与 resume 对齐）
-c, --continue续本目录最近会话
--sessions-dir <dir>会话 WAL 根（默认 ./.forgeax/sessions）
--yes⚠ 自动批准全部权限提示（root 拒绝）
--permission-mode <m>default | acceptEdits | plan | bypassPermissions
--no-tui强制 readline
--sandbox / --no-sandboxOS Bash 沙箱
--servesidecar 模式（需 --sock 或 FORGEAX_CORE_SOCK）
--sock <path>serve 用 unix socket
-h, --help帮助
-v, --version版本

子命令 ​

mcp-serve ​

bash
forgeax mcp-serve [--allow-writes] [与主 CLI 兼容的发现类 flag…]

不接受 --permission-mode（该形态不创建交互 agent）。

环境变量（摘要） ​

见 设置与环境变量。最常用：

  • ANTHROPIC_API_KEY / ANTHROPIC_BASE_URL
  • OPENAI_API_KEY / OPENAI_BASE_URL + FORGEAX_PROVIDER_API=openai-compat
  • FORGEAX_MODEL
  • FORGEAX_CONFIG_DIR

退出与自动化 ​

  • print 模式适合 CI：配合 --output-format json 解析
  • 管道：stdin 非 TTY 时读入内容（有超时兜底，避免继承的空管道永久挂起）
  • 权限：CI 中优先窄 allow 规则，慎用 --yes
