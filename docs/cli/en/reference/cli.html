CLI reference ​

Usage ​

text
forgeax -p "<prompt>"     one-shot print mode
forgeax                   REPL / TUI
forgeax --demo -p "hi"    demo (no API key)
forgeax mcp-serve         reverse MCP server (stdio)
forgeax --serve --sock <path>   AgentKernel sidecar (advanced)

Bin aliases: both forgeax and forgeax-cli point at the same entry.

FlagDescription

--output-format <fmt>text (default) | json | stream-json

Subcommands ​

mcp-serve ​

bash
forgeax mcp-serve [--allow-writes] [discovery-compatible flags…]

Does not accept --permission-mode (this shape does not create an interactive agent).

Environment variables (summary) ​

See Settings & environment variables. Most used:

  • ANTHROPIC_API_KEY / ANTHROPIC_BASE_URL
  • OPENAI_API_KEY / OPENAI_BASE_URL + FORGEAX_PROVIDER_API=openai-compat
  • FORGEAX_MODEL
  • FORGEAX_CONFIG_DIR

Exit & automation ​

  • Print mode suits CI: pair with --output-format json
  • Pipes: when stdin is not a TTY, content is read (with a timeout so inherited empty pipes do not hang forever)
  • Permissions: prefer narrow allow rules in CI; use --yes sparingly
