入门约 3 分钟

让你的 AI CLI 克隆并启动 ForgeaX

最 AI 原生的装法：不用自己敲命令 —— 把仓库地址交给你的编程 CLI 智能体，让它自己 clone、装依赖、启动，再把本地地址告诉你。

✅ 已开源（Apache-2.0）。下面的流程对任意 AI 编程 CLI 都适用。

你需要什么

  • 一个能跑 shell 命令的 AI 编程 CLI —— 例如 Claude Code、Codex、Cursor，或 ForgeaX 自带的 forgeax CLI；
  • 已安装 git 和 Bun（项目运行时）；
  • 一个 AI 模型的 API key（供工作室里的 Forge 使用）。

一句话交给 CLI

在一个空目录里打开你的 CLI，把下面这段话发给它：

克隆 https://github.com/ForgeaX-Games/forgeax-studio
（带上子模块 --recurse-submodules），
进入目录后运行 install 脚本装好依赖，
再运行 start 脚本启动它，
最后把可以打开的本地地址告诉我。

CLI 会自己执行 clone、安装、启动这几步，过程里需要的选择（比如填 API key）它会问你。完成后你会拿到一个本地地址，在浏览器打开就是工作室。

手动等价命令（可选）

如果你想自己来，等价的命令大致是：

git clone --recurse-submodules \
  https://github.com/ForgeaX-Games/forgeax-studio
cd forgeax-studio
bun fx setup     # 装依赖（+ 填 API key）
bun fx start     # 启动

这套 bun fx 命令是跨平台的 —— macOS、Linux、Windows 通用，Windows 上无需 Git-Bash。启动后按提示在浏览器打开本地地址即可。
