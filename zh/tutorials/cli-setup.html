把 ForgeaX Game 安装到 Codex 等 AI 客户端

ForgeaX Game 会把你已经在用的 AI 编程客户端变成游戏开发客户端：绑定项目、安装引擎知识、启动匹配的 Runtime，并返回真实 Play 地址。

这是当前主要产品路径。 做游戏不需要克隆 ForgeaX Studio，不需要先启动源码工作区，也不需要先学会某个编辑器。

这个插件会给客户端增加什么

  • 理解当前项目 — 通过 forgeax://status 暴露活动游戏、项目根目录、服务状态与下一步。
  • 掌握准确引擎知识 — 把版本匹配的 Skills、类型声明、模板和引擎源码安装到项目。
  • 一次调用启动预览 — 构建或复用选定 Runtime，并把真实 Play 地址与日志位置交给智能体。
  • 校验版本身份 — 同时报告 Runtime 和 Engine SDK commit，避免智能体对着错误 API 开发。

1 · 只需一次，把客户端接进来

只需要 Node.js 18 或更高版本。为你使用的客户端运行安装命令：

npx -y @forgeax/game install --ide codex

# 一次配置多个客户端
npx -y @forgeax/game install --ide codex,claude,cursor

写配置之前，安装器会启动将要保存的真实 MCP 命令，完成 initialize → tools/list → resources/list 握手。它会合并已有配置；被修改的文件旁会生成 .bak.latest 备份。

其他客户端 id 包括 zcode、opencode、windsurf、vscode、trae、codebuddy 与 workbuddy。省略 --ide 会配置全部已支持客户端。

2 · 初始化一个游戏项目

新建或进入一个空目录，然后让软件包创建项目和活动游戏：

mkdir neon-runner && cd neon-runner
npx -y @forgeax/game init --game neon-runner

init 会创建 ForgeaX 项目、选中游戏，并从与托管 Runtime 相同的 Engine pin 生成 .forgeax/engine-sdk/。游戏位于 .forgeax/games/neon-runner/。

3 · 用你的 AI 客户端打开这个目录

在项目目录里启动一个新会话，直接描述结果，不需要列出引擎 API：

第一条需求

使用 ForgeaX Game 检查当前项目，然后做一个可玩的霓虹收集小游戏。
玩家用 WASD 移动，收集 8 个能量碎片，界面显示进度，集齐后胜利。
请在经过验证的 ForgeaX Runtime 中运行，打开 Play 地址测试操作，
发现问题就继续修复，直到可玩行为得到验证。

安装好的 Skill 会要求智能体先读取项目状态，再查引擎 Skills 与声明，只编辑活动游戏，调用运行工具，并在浏览器里验证结果。

健康的安装应该是什么样

  • 客户端能看到 ForgeaX MCP 服务，并能读取 forgeax://status（或调用 forgeax_status_lite）。
  • 项目存在活动游戏，目录为 .forgeax/games/<slug>/。
  • Engine SDK 与 Runtime 身份一致，启动结果会同时报告两者。
  • 智能体可以调用 forgeax_run_current_game，并获得可访问的 Play 地址和日志路径。

常用维护命令

命令什么时候用
forgeax-game doctor检查 Node、客户端配置、项目绑定和服务层级。
npx -y @forgeax/game update让已有项目刷新发布命令、客户端入口和项目路由规则。
forgeax-game use <slug>项目里有多个游戏，需要切换活动游戏。
forgeax-game devkit install游戏开发或引擎 Skills 缺失，需要重新安装。
ForgeaX Game 不会取代你的编程智能体。它为智能体补上完成游戏工作所需的引擎上下文、运行时身份与验证表面。
