你的个人游戏工作室。

ForgeaX 是一个 AI 原生的游戏开发工作室 —— 把你的想法变成可玩的游戏，AI 替你编写引擎代码、实时热重载跑在浏览器里。更不寻常的是：连这套引擎与平台本身，也几乎完全由 AI 在一个自主开发循环里一行行写成；它一天天自建自己的过程，就记在更新日志里，像一份 AI 的长期开发记忆。

多种创作方式

对话、可视化编辑器，未来还支持图片 / 视频输入 —— 用你最顺手的方式表达想法。

Agent 驱动

AI agent 替你规划、设计、编写引擎代码，你只做需求与验收。

实时热重载

改动一落地，右侧预览立刻可见 —— 所见即所玩。

真正的 ECS 引擎

自研实体-组件-系统引擎 + 双 RHI 渲染，封装进浏览器工作室。

AI 原生玩法

不止用 AI 做游戏 —— 还支持把 AI 做进玩法本身：智能 NPC、生成式内容、可交互的 AI 体验。

自进化开发闭环

ForgeaX closed loop —— 需求 → 实现 → 验证的闭环流程，吃自己的反馈持续进化，越跑越稳。

浏览器原生

WebGPU 驱动，网页 / 桌面同栈，装好依赖一分钟起跑。

开源

Apache 2.0 —— 自由 fork、使用、商用与二次发布。

用你自己的 AI Agent

大脑在 ForgeaX，引擎归你
1

ForgeaX 提供大脑

自研编排内核 + 人格 Forge：多 agent 团队负责规划、委派、写引擎代码并汇报结果。

2

本地 CLI 提供引擎

把你已经在付费的编程 agent（或一个普通 API key）接成推理后端，不必再为 AI 付第二份钱。

3

一处切换，随时更换

在面板选一个 provider 就换掉引擎，人格与工作流原样不变，无需重写任何代码。

七个可选的推理引擎
forgeax cli自包含的 forgeax-cli，开箱即用的推荐 CLI。
Claude Code用你的 Claude Pro / Max 订阅，或一个 Anthropic API key。 OpenAI Codex登录你的 ChatGPT Plus / Pro 计划，或用 OpenAI API key。 Cursor通过 Cursor Agent CLI 连接你的 Cursor Pro 订阅。 Kimi Code使用 Kimi 会员权益，或 Moonshot AI API Key。 DeepSeek Harness使用本地 dsh CLI，配置 DeepSeek API Base URL 和 Key。开发者预览；模型与 profile 由 dsh 管理。 CodeBuddy用 CodeBuddy Code CLI 驱动，自管登录，开箱即接。

不绑定任何厂商 —— 哪个 AI 顺手就用哪个，随时切换。
