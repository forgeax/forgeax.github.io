Forge 学会组队:多个 agent 一起干活

这天最大的变化,是 Forge 不再只能一个人埋头串着做,而是能拉起一支队伍:多个 agent 共享同一张任务看板、并行推进。同时,编辑器里单个 mesh 的场景资产能稳定落盘、重开和试玩都还在;出现了一键打包的界面雏形;你还能扫码用手机接管正在干活的 agent;聊天也不再因为某些复杂排版而卡死。此外,项目的日常命令也收敛到了一个统一入口 bun fx。

从"一个 Forge"到"一支队伍"

到目前为止,Forge 接到一个需求,基本是自己一步步串着做:规划、写代码、验证,一件接一件。这对小任务够用,但当需求一大、可以拆成好几块互不依赖的活时,串行就成了瓶颈——明明能同时进行的事,却只能排着队等。这一天引入了多 agent 的 Team 模式:Forge 可以拉起若干"队友"agent,大家共享同一张任务看板,各自认领、并行推进,再把结果汇总回来。技术上,这背后是几件事的合力:一个能真正并发执行队友的执行器、一套让队友之间互通消息的进程内"信箱"、以及一张所有人都能看、能认领、状态一致的共享任务表。它把"指挥一个 AI"升级成了"指挥一个 AI 团队"。

默认就开,带一个"队长视角"

Team 模式这一天就默认开启了(也保留了一个开关,想关随时能关回单 agent)。为了让"一群 agent 在干活"不至于变成一团看不懂的乱麻,它配了一个"队长视角":由一个协调者把活拆成任务、分派下去、盯着进度,你从这个视角能看清"现在有谁在做什么、做到哪了"。同时,系统会在合适的时候给参与的 agent 提示"你现在处于团队协作模式",让它们的行为与单打独斗时有所区别——知道要认领看板上的任务、要和队友协作,而不是各干各的、重复劳动。默认开启,意味着这不是一个藏在角落的实验功能,而是 Forge 从这天起的默认工作方式之一。

编辑器:单个 mesh 也能稳稳留在场景里

编辑器这边补上了一块关键的可靠性。此前把一个单独的 mesh(模型网格)放进场景后,它的"场景资产"没能稳定地落盘保存,结果重开工程、或点▶试玩时,这块东西可能就不见了或渲染不出来。这一天让单 mesh 的场景资产能正确写回磁盘并持久化:你摆好的东西,关掉再打开还在,切到试玩模式也照常渲染。配套还做到了:把一个 mesh 拖进来时,能恢复它原本在 glTF 模型里带的材质,而不是变成一块没贴图的灰白。对"所见即所得"的编辑体验来说,"我摆的东西会一直在"是最基本的信任——这一天把这份信任补齐了。

一键打包的界面雏形 + 用手机接管

还有两件让"把作品带走、随时盯着"更顺的事。其一,编辑器顶栏出现了打包界面的雏形:打包的目标平台、引擎根目录的选择、历史记录等选项被搬到了可见的 UI 上(且支持中英文),让"把游戏导出成可分发的成品"这件事从命令行往图形界面靠拢了一步。其二,新增了"扫码用手机接管"的能力:扫一下二维码,就能在手机上和正在干活的 agent 双向收发消息——人离开电脑,也能随时看一眼进度、追加一句指令。这两件事方向一致:让创作不被钉死在一个固定的地方——既能把成品轻松带出去,也能把对它的掌控握在手机上。

更稳:聊天不再卡死 + 真实进程级测试

可靠性也没落下。聊天界面修掉了一个会让它在解析某些复杂 Markdown 排版时陷入死循环、最终吃光内存卡死的问题——往后再贴进奇怪格式的内容,也不会把对话窗口拖垮。底层还补上了一批"真实进程级"的端到端测试:不再只是在理想环境里跑跑,而是真的把程序当成完整进程拉起来,覆盖断点恢复、上下文整理、后台常驻、命令行界面等关键路径。测试这东西平时看不见,但它是"敢不敢放心改、改了会不会悄悄坏掉"的底气来源——多一层真实测试,就多一分往前走的安全垫。

日常命令统一到一个入口:bun fx

这天还把项目的日常操作命令做了一次收敛:过去散落的 setup / start / stop 等脚本,如今统一到一个入口 bun fx <命令> 之下,直接运行 bun fx 就会打印出所有可用命令的帮助。常用的有:bun fx setup(首次装好环境)、bun fx update(只拉取主仓最新代码并同步子模块——不再顺手重装依赖或重新构建插件,职责更单一、也更快)、bun fx start(默认起网页模式)、bun fx start app(起桌面模式),以及 bun fx stop / bun fx restart。把入口收敛成一个,意味着无论在 macOS、Linux 还是 Windows,记住一个 bun fx 就够了;同时也把"更新代码"和"装环境"这两件以前容易混在一起的事各归其位——日常拉更新更轻,也更不容易误触发一次完整重装。README、开发文档与公开站的说明都已同步到这个新入口。

这一天意味着什么

这一天的关键词是"放大"。在此之前,Forge 的产能上限是"一个 agent 能干多快";有了 Team 模式,这个上限被抬到了"一支队伍能并行干多少"——这是从单兵到团队的质变,意味着越大、越能拆分的需求,越能被同时推进、更快完成。围绕这个核心,这天又把几处体验补稳:编辑器里摆的东西会一直在、成品能从界面打包带走、人离开电脑也能用手机接着指挥、聊天不再被怪格式卡死。一边把 AI 的产能从"一个"放大到"一群",一边把日常体验的每个角落收得更牢——能力的天花板和体验的地板,这一天一起往上抬了一截。
