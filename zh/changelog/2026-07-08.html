视口 Gizmo 全面优化 + Composer 图片粘贴 + Agent 人设国际化 + iOS 导出

今天落地了六项视口和 Inspector 修复：Focus 按钮触发正确的帧选择并固定俯视角；缩放 Gizmo 沿实体局部轴定向；数字字段四舍五入到 4 位小数防止显示抖动；鼠标事件限定在 canvas 范围内；Group 节点定位到子节点质心并延迟 Gizmo 刷新；重新父级时保持世界坐标和 Gizmo 世界空间同步。产品侧，Composer 支持图片粘贴，Agent 人设新增中英双语支持，iOS Xcode 项目导出新增 WKWebView 可调试构建。

视口 Gizmo 全面优化——一天六项修复

编辑器视口今天集中落地了一批修复：

  • Focus 按钮：现在触发正确的 frameSelection 并锁定到固定俯视角，一键将任意实体居中到视口。
  • 缩放 Gizmo 局部轴：缩放 Gizmo 现在沿实体的局部坐标轴方向显示，而不是世界轴，旋转后的实体缩放操作更直观。
  • Inspector 数字四舍五入：Inspector 中的数字字段现在四舍五入到 4 位小数，消除了浮点噪声导致的小数长尾视觉抖动。
  • Canvas 限定输入：鼠标和指针事件被限定在 canvas 范围内——在视口外的点击和拖拽不再触发意外的场景交互。
  • Group 质心定位：创建分组时，Group 节点会放置在其子节点的几何质心位置，并延迟刷新 Gizmo 以避免视觉跳变。
  • 重父级世界坐标保持：在 Hierarchy 中把实体拖到新的父节点下时，现在会保持其世界空间位置不变，Gizmo 在世界空间同步，操作手柄始终在预期位置。

Composer 图片粘贴

现在可以直接在 Composer 聊天输入框中粘贴图片——截图、剪贴板图片或文件——它们会作为消息附件发送。这简化了向 AI Agent 分享视觉参考的工作流。

Agent 人设双语支持

所有内置 Agent 人设（Arin、CC-Coder、Iori、Iro、Kotone、Reia、Suzu、Tsumugi、Yevi）现在同时提供英文和中文的人设文本和长期记忆，使 Agent 体验在两种语言之间保持一致。

iOS 导出：WKWebView 可调试构建

iOS Xcode 项目导出现在在 debug 构建中设置 WKWebView.isInspectable = true，允许你使用 Safari Web Inspector 连接在设备或模拟器上运行的游戏进行实时调试。
