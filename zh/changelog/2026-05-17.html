聊天里直接预览模型与图片 + @提及 pill

这天把"多 agent 协作"从后台搬到了你眼前:可以直接 @ 一个 agent 跟它对话,能力健康度铺满整个界面,素材能在聊天里就地预览、用引用 pill 带进对话。引擎同时做了一大批收敛:统一的网格渲染器、统一的截图能力、控制台依赖反转,以及一整套渲染教学示例。

让协作"看得见、点得到"

前几天平台搭好了"多 agent 后台长跑 + 事件总线"的能力,但这些都还藏在系统内部。这天的主线,是把这套能力彻底推到界面前台:你不仅能看见 agent 之间在总线上的往来,还能直接 @ 点名某个 agent、把素材就地预览出来、用引用胶囊把对象带进对话。换句话说,这天补的不是某个孤立功能,而是"让一群 agent 协作"这件事真正可被一个普通人操控的那层交互。当后台的复杂被翻译成你看得懂、点得到的界面元素,多 agent 才从"技术上能跑"变成"用起来顺手"。

直接 @ 一个 agent 跟它对话

这天多 agent 协作迈出关键一步:你可以在对话里直接用 @ 点名某个 agent,让它接住这条消息并回复,而不再是只能跟那个主控对话、由它转述给别人。配套上线了一个 agent 中枢面板,把当前这支"团队"里有哪些成员、各自在忙什么集中呈现出来。这件事改变的是协作的"指挥方式":以前你像是只能对项目经理说话,现在你可以越过项目经理,直接找那个负责美术、或负责关卡的成员把话说清楚。对"一个人带一支 AI 团队"这个核心场景来说,能点名沟通是从"群发"走向"精确指挥"的分水岭——你终于能把对的话说给对的成员听。

总线状态铺满界面:处处看得见能力健康度

承接前一天把总线接进界面,这天把"系统里有哪些能力、各自健不健康"这件事铺到了界面的各个角落。顶栏多了一排状态灯,分别对应工具、技能、agent 等几类能力,各自显示数量和健康状态;聊天面板、侧栏、总线管理面板里也到处是这种"小灯 + 计数 + 可点深链"的呈现,点一下就能跳到对应的详情。它的价值在于把"系统现在到底有什么、状态如何"这件事变成一种环境信息——你不用专门去查,扫一眼界面就知道。对一个能力越来越多、还能被插件不断扩展的系统来说,这种无处不在的健康可视化,是让人始终对"它现在是什么状态"心里有底的关键。

聊天里就地预览素材 + 引用 pill

这天还让"素材"在对话里变得可见、可引用。聊天能就地预览附件:贴一张图片直接出缩略图,丢一个模型文件会渲染成一个可看的小预览,不必先塞进游戏里跑一遍才能看到它长什么样。讨论一个角色或一张贴图时,双方看到的是同一个具体的东西,而不是各自脑补。配套的"引用胶囊"则让你在输入框里打个 @ 就能把一个 agent 或一份资源做成一枚可点的标签——记得你最近用过哪些、悬停能看说明、插入后还能点回去。这两件事合起来,把"把素材带进对话"这件以前要靠复制长路径、靠文字描述的事,变成了一拖、一点的直接操作。

引擎:统一的网格渲染器 + 材质句柄 + 默认值回退

引擎这天在渲染与组件这两层做了重要收敛。渲染上,统一成了单一的网格渲染器,并用"材质句柄"来引用材质——也就是一个物体怎么被画出来,统一由"网格 + 一个指向材质的句柄"来描述,既清楚又便于复用同一份材质。组件这边,给"创建实体"和"添加组件"补上了一条默认值回退链:当你没显式给某个字段赋值时,系统会沿着多层规则去找一个合理的默认值,而不是报错或留空。这意味着写游戏内容时可以"只写关心的部分,其余交给合理默认",大大减少样板和出错面。这类收敛不是新功能,而是让引擎在被越来越多人(和 AI)使用时,依然保持"少惊讶、好预期"的关键。

引擎:截图能力统一 + 控制台依赖反转 + 教学示例铺开

引擎这天还清理了几处"重复"与"耦合"。其一,把原本散落在多个示例里、各写一套的"截屏"逻辑统一成渲染器的一个标准能力,一处实现、处处可用,既减少重复又让视觉验证更一致。其二,对"控制台"这条调试通道做了依赖反转:它不再直接依赖具体的内部模块,而是通过一个抽象接口来工作,从而把彼此解耦——这让控制台能更独立地演进,也让插件能以统一方式接进来。其三,落地了一整套循序渐进的渲染教学示例(从最基础的三角形、纹理到输入处理),并把图像、纹理、输入这些通用能力内化进引擎本身。这些示例既是引擎能力的活文档,也是新人(和 AI)学习怎么用这套引擎的最好入口。

这一天意味着什么

这一天的两条线——界面上把多 agent 协作彻底"显形",引擎里把渲染与组件大幅"收敛"——表面无关,内里却是同一种追求:让一个正在快速变复杂的系统,始终对人保持清楚。界面这边,@ 提及、能力健康灯、素材预览、引用胶囊,合起来让"指挥一支 AI 团队"从抽象变得具体可操作;引擎这边,统一渲染器、统一截图、依赖反转、教学示例,合起来让底层在功能膨胀的同时不至于越长越乱。一个能长期演进的系统,既要往外长出能力,也要往内保持秩序——这一天,正好同时在做这两件事。
