更新2026-07-04

3D 生成修复 + 工作台国际化 + TUI 终端界面

wb-gen3d 和 wb-ai-asset 工作台获得了关键的 3D 管线修复；三个创作工作台（角色、AI 资产、3D 生成）现已全面国际化；新增 TUI 终端界面提供键盘驱动的 agent 交互；Settings API Keys 精简为仅 LiteLLM；CLI 新增 auto-inject slug 和结构化错误码；两个新游戏场景包上线（Slagdeep Hollow 可编辑场景、Rogue Encampment 地板模型）。

3D 生成管线修复

wb-gen3d（3D 模型生成）和 wb-ai-asset（AI 资产创建）工作台获得了关键的 3D 输出管线修复。之前，某些生成的模型由于材质分配问题无法在视窗中正确渲染。现已修复——生成的 3D 资产在创建后立即以正确的 PBR 纹理显示。

工作台全面国际化

三个创作工作台——wb-character、wb-ai-asset 和 wb-gen3d——现已在所有支持语言中完全国际化。面板标签、工具提示、状态消息和错误状态全部已翻译，使创作工具对非英语用户完全可用。

TUI：终端 Agent 界面

核心 agent 运行时的新终端 UI（TUI）已通过验收（F1/F2/F3）。它提供了一个键盘驱动的界面，可直接从终端与 agent 交互——适用于无头环境、SSH 会话，或偏好留在终端的开发者。

Settings API Keys 精简

Settings 中的 API Keys 部分已精简为仅 LiteLLM 配置。无需再为每个供应商（Anthropic、OpenAI、Gemini 等）单独管理密钥，现在只需配置一个 LiteLLM 代理端点即可路由到所有模型。这降低了配置复杂度，同时保持完整的模型访问能力。

CLI 改进

CLI 现在自动注入项目 slug 到工具调用中，消除了常见的"项目未找到"错误。此外，处理器错误现在返回结构化错误码而非通用消息，使插件和工具作者更容易调试。

新游戏场景包

本次发布包含两个新游戏内容包：Slagdeep Hollow 带来了可编辑场景包和启动器巢穴起始位置，Rogue Encampment 新增了地牢爬行类游戏的详细地板模型。
