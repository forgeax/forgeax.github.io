更新2026-07-12

引擎 Tier 2 运行时 + 单域编辑器清理 + Gateway 资产/组件接口 + 资产内嵌插件

编辑器完成单域迁移——所有遗留的 iframe 协议投影、VAG 遥测桥接和废弃的 EditSurface 宿主已退役，由类型化 PanelBridge 和共享 Dock 布局替代。Gateway API 获得完整的资产和组件读取接口、统一的导入/删除通道以及资产内嵌游戏插件（组件在编辑模式加载，系统在 Play 模式加载）。活跃世界的查询路由、场景资产放置以及持久化 DEV 诊断桥接也一并完善。

单域编辑器：遗留协议退役

编辑器完成单域迁移。所有此前通过遗留 iframe 投影传递的通信现在均在进程内处理：

  • 类型化 PanelBridge 替代 VAG_ASSETS_CHANGED 及所有匿名广播消息
  • 编辑运行时 VAG 遥测桥接 移除——资产变更通知现在通过类型化通道流转
  • EditSurface iframe 宿主 退役——VAG_SPAWN_ENTITY 及相关废弃的编辑预览控制接收器已移除
  • 遗留接口术语 在整个编辑器表面清理完毕
  • 共享 Dock 布局 注入所有编辑器面板，替代各面板重复的布局定义

Gateway：资产与组件读取接口

编辑器 Gateway API（AI Agent 进入编辑器的程序化入口）获得重大新能力：

  • 资产读取接口：按类型、路径和 GUID 列举和检视已目录化的资产
  • 资产导入 + 删除：统一为一个标准入口——importAsset / deleteAsset
  • 组件读取接口：describeComponent 和 listComponents——AI Agent 现可枚举和检视任意实体上的 ECS 组件
  • addSceneAssetToScene 操作：将已目录化的场景 GUID 直接放置到活跃场景中
  • 活跃世界查询路由：查询现跟随 activeWorld，Play 模式下通过 gateway 入口读取游戏世界可正常工作
  • argsSchema 强制校验：所有已定义的文档操作均强制校验参数模式，让 Agent 调度更安全
  • 查询序列化修复：variable array<T> 字段现在序列化为可枚举列表，而非计数值

资产内嵌游戏插件

插件现在可以将逻辑放在游戏资产目录内。组件在编辑模式下加载用于创作，系统在 Play 模式下加载用于运行时执行。这消除了在编辑器包中预注册所有插件逻辑的要求。

DEV 诊断桥接：在 Play 模式持续存在

进程内编辑器诊断桥接（DEV 桥接）现在在 Play 模式下持续保持活跃，游戏启动或停止时编辑器诊断不再中断。

引擎：Tier 2 运行时分解

引擎运行时拆分为三个独立子系统：

  • assets-runtime：资产加载、注册和生命周期管理从核心渲染循环中解耦
  • picking：基于 GPU 的实体拾取作为独立子系统
  • graphics-extras：后处理效果、HDR 解析和图形工具从单体渲染器中提取

引擎：组件批量 vec 折叠 + 字段级临时标记

Light、Camera、Glyph、Tilemap、Collider 等组件字段已更新：

  • 批量 vec 折叠：向量字段以紧凑数组存储和传输，降低序列化开销
  • 字段级临时标记：逐字段 transient 注解防止运行时临时状态被持久化到磁盘

Transform 序列化同样支持 vec 字段和字段级 transient。

引擎：instantiateSceneFlat

新的 instantiateSceneFlat API 可在不插入合成层级根实体的情况下打开场景，实体直接出现在场景图顶层，与编辑器中的摆放方式完全一致。

引擎：后处理 resize 修复

后处理绑定组现在以 TextureView 标识为键，而非纹理尺寸。缩放视口不再遗留上一分辨率的过期绑定组，消除窗口缩放时的后处理画面损坏。

引擎：CSM 跨世界修复

检测到跨世界相机与光源配置时，方向光级联阴影贴图（CSM）在合并层重新计算，修复分裂世界场景中的阴影渲染问题。

引擎：RHI 调试空闲快速路径

FORGEAX_ENGINE_RHI_DEBUG=1 在无捕获进行时的空闲开销现在接近零。调试插桩可以一直启用而不影响正常游戏帧率。

引擎：精灵视锥剔除修复

恢复 BUILTIN_QUAD AABB 和 M2.5 派发配对，修复精灵部分超出视锥时被错误剔除的问题。

引擎：FBX 加载器修复

fbx-wasm 包现在以包含 Emscripten 生成的 .mjs 胶水文件的 .tar.gz 形式发布，修复因缺少加载器模块导致的 FBX 导入失败。

修复

  • 视口：防止游戏创建时 render-system-no-camera 产生误报
  • 查询路由：Play 世界读取通过活跃世界 gateway 正确路由
