实时热重载预览 + 会话回放

这天把"边说边看"的体感真正闭合:改动游戏文件,中间的预览自己刷新;重开一个会话,此前的来回完整回放。配套还让着色器能跨文件组合并热更新,新建游戏自带可运行的起点,agent 也总能知道你正在做哪个游戏。

承上启下:把"边说边看"做成肌肉记忆

前两天证明了"对话能做出能跑的东西",也立起了渲染、资产、安全这些地基。这天的主题,是把这条闭环从"能跑通一次"打磨成"用起来顺手"——让改动即时可见、让历史不会丢、让 agent 不会搞错对象。这些听起来都是"理所应当"的体验,但每一项背后都是一处真实的工程缺口被补上。当这些缺口都补齐,平台才从"能演示"变成"能长时间坐下来用"。

实时热重载预览:改文件,画面自己变

这天给中间的预览接上了一座"热重载桥":当某个游戏的文件发生变化,预览会自动刷新,把最新的样子呈现出来,而不需要你手动点重载。它的工作方式是后端持续盯着该游戏目录里的文件改动,一有变化就通过实时通道通知前端,前端随即让预览重新加载。这一步看似只是"省了一次点击",实则是"边说边看"闭环里至关重要的一环:agent 一改完代码,你几乎立刻就能在画面上看到结果,对话与画面之间的延迟被压到最低。对长时间坐着做游戏的人来说,这种"所改即所见"的即时反馈,是把灵感和实现连起来的关键。

会话回放:重开一个会话,来回原样还原

和 AI 协作久了,会话历史就是你的宝贵资产——里面有你提过的需求、它做过的决定、走过的弯路。这天把会话历史落到一份持久的"账本"里,并让重新打开一个会话时能从账本完整回放此前的来回。技术上特别处理了一点:实时事件流里只带"发生了什么"的轻量记录、并不含完整文本,所以回放要从账本里把真正的内容重新组织出来,而不是简单重播事件。意义在于:你关掉再回来,上下文不会丢;一段历史可以随时翻回去看,就像它当时发生的样子。这让"长期、多轮地做一个项目"成为可能,而不是每次都从一张白纸开始。

着色器可组合 + 跨文件热更新

引擎这天给着色器加上了"可组合"的能力:着色器之间可以互相引入、共享片段、用宏定义参数化,而不必把所有代码都堆在一个文件里。更妙的是它支持跨文件的热更新——你改了被引用的那个公共片段,所有用到它的着色器都会跟着即时刷新。对做画面效果的人来说,这意味着可以像搭积木一样组织着色器代码:把通用的光照、噪声、色彩处理抽成可复用的模块,各处引用;改一处,处处生效,且立刻看到。它把"写特效"从"对着一大坨代码反复试"变成了"组合可复用的模块并实时调",是渲染表达力上的一次实打实的扩容。

引擎统一控制台:一条执行通道,处处一致

引擎这天把"控制台"这条调试/检视通道做了统一抽象:后端收敛成单一的执行通道,命令行那侧则提供更轻量的只读检视入口。统一的好处是行为一致、心智简单——无论从哪里发起一次检视或执行,走的都是同一条规整的路径,而不是各处各写一套、行为还略有出入。这类抽象上的收敛在用户那一侧往往看不见,但它决定了系统会不会随着功能变多而越来越乱。把"控制台该怎么工作"在早期就收敛成一条权威通道,等于给后面所有要接进控制台的能力定了同一套规矩。

新建游戏自带可运行起点 + agent 总知道你在做哪个游戏

这天补上两处让"新建游戏"更顺的细节。其一:新建一个游戏时,系统会放进一个可直接运行的起点(一个转动的立方体起手式),于是你一建好就能看到画面,而不是面对空白发愣再从零写起。其二:把"当前正在做哪个游戏"这个上下文显式地喂进 agent 的系统提示里,让它清楚地知道现在该往哪个游戏里写代码。后者修的是一个很要命的隐患——多个游戏并存时,如果 agent 搞不清当前对象,很容易改错地方。把"活动游戏"做成一个明确、可靠传递的上下文,等于给 agent 装了一个不会指错的指南针。

后端继续扎实:更多测试、路径脱敏、命名校验

后端这天延续了"用测试把行为钉死"的节奏,又补了一大批端到端探针和单元测试。重点有几处:把游戏与项目的命名规则用大量用例锁住(什么样的名字合法、什么样的该被拒,边界都有测试守着),把对外返回里的用户主目录路径继续做脱敏(不泄漏你机器上的真实路径),并把构造系统提示这类关键逻辑抽成纯函数、单独可测。这些都不是亮眼功能,而是"让一个能改你文件的系统值得信任"的日常功夫。值得一提的是,这天还顺手适配了另一种编码后端的事件格式,让接入更多模型驱动方式更顺——多一个选择,体验却保持一致。

这一天意味着什么

把这天的几件事连起来看,主线非常清楚:让"边说边做"这件事不只是能成,而是用起来不硌手。改动即时可见(热重载)、历史完整可回(会话回放)、特效能像搭积木一样组织(可组合着色器)、agent 不会改错对象(活动游戏上下文)、后端值得托付(测试与脱敏)——每一项都在消除一个会打断心流的小摩擦。一个工具好不好用,往往不取决于它能不能做某件大事,而取决于做日常那一百件小事时顺不顺。这一天补的,正是这一百件小事里最关键的几件。
