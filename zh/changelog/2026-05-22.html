引擎学会投影 + 新增叙事工作台

这天引擎学会了投影——方向光阴影、基于环境的天光、逐物体贴图一起到位,画面立体感真实许多。工具家族也在扩张:新增叙事工作台,角色工作台能留住生成的素材、还能上传自己的;并补上一个 UI 工坊与一批跨平台修复。

两条线并进:画质上台阶,工具家族扩张

这天清楚地分成两条线。一条是引擎的画质:前几天点亮了光照,这天补上了阴影与环境光,让画面从"被照亮"走向"有体积、有氛围"。另一条是工具家族的扩张:在前一天确立的"分屏插件"架构之上,新的工作台一个接一个住了进来——叙事、角色、UI 工坊各司其职。两条线一个往"做得好看"使劲,一个往"做得方便"使劲,合起来就是平台同时在变美和变全。这种"底层画质 + 上层工具"并行推进的节奏,正是它能既像个引擎、又像个生产力平台的原因。

引擎学会投影:方向光阴影

引擎渲染这天迈过一道关键门槛——方向光阴影。物体现在会在一束方向光(类似太阳光)下投下影子,也会接住别的物体投来的影子。阴影看似只是地上多了一片暗,实则是画面"立体感"的重要来源:人眼很大程度上靠阴影来判断物体之间的高低、远近和接触关系——没有影子,一个角色会像贴纸一样浮在地面之上;有了影子,它才真正"站"在那里。把方向光阴影做对,是从"物体被照亮"走向"物体存在于一个空间里"的关键一步,也是任何要做出真实感场景的游戏都绕不开的基础能力。

基于环境的天光 + 逐物体贴图

在方向光阴影之外,这天还补上了两块让画面更真实的能力。其一是"基于环境的天光":用一张环境贴图作为光源,让物体被四周环境柔和地照亮——暗部不再死黑,金属与光滑表面会映出环境的样子,整个场景的光感一下子自然、高级很多,这是接近真实感渲染的关键一环。其二是修好了"逐物体的材质贴图绑定":同一个场景里不同的物体现在能各自贴各自的图,不再出现"改了一个物体的贴图、结果影响到另一个"的串台问题。方向光阴影 + 环境天光 + 逐物体贴图,这三样凑齐,引擎离能渲染一个"看上去就是对"的完整场景,又近了一大步。

新增叙事工作台

工具家族这天迎来一位新成员:叙事工作台。它借着前一天确立的分屏插件架构,以嵌入式工具窗的形态住进工作台,占满主区域来组织一个游戏的剧情与文本。它解决的是一个真实的割裂——做游戏不只是写玩法代码,还要编剧情、写对白、设计分支;以前这些往往得在另外的工具里做,再想办法搬回来。现在"做玩法"和"写故事"被放进了同一个平台里推进,你不用在不同工具之间来回切换、来回复制。这也印证了那套分屏架构的价值:它让平台能像搭积木一样,把一个又一个不同职能的工作台稳稳接进来。

角色工作台:生成的素材会留住,还能上传自己的

角色工作台这天从"试着玩玩"往"真能拿来做项目"迈了一大步。最关键的是资产持久化:生成出来的立绘、素材现在会被保存下来,关掉工作台再回来它们还在,不必每次都重新生成一遍——这对一个要反复打磨角色的人是质的区别。分屏里左右两侧的内容也会保持同步,改一边另一边跟着更新,不会各说各话。你还能把自己已有的素材上传进来一起用,而不必所有东西都靠生成;并且生成可以按需路由到不同的外部服务,挑合适的那一家来出图。这些改动合起来,让这个工作台从一个有趣的演示,变成一个能真正承载日常创作的工具。

新增 UI 工坊 + 跨平台与界面打磨

这天还多了一个 UI 工坊工作台,继续扩充工具矩阵;界面则按设计稿把工具切换栏、折叠态宽度等细节对齐,让视觉更规整。底层也清理了一批东西:删掉了几个不再需要的构建期插件、把一些示例的命名空间归整统一,并修好了一个在 Windows 上路径处理出错的跨平台问题——让更多系统上的开发者都能顺利跑起来。这些改动单看零碎,但它们和前面那些大特性一样重要:大特性决定平台能做什么,这些打磨决定平台在你的机器上、你的日常里到底好不好用。两者都做扎实,产品才立得住。

这一天意味着什么

这一天把"好看"和"好用"两头都往前推了一截。引擎学会投影、补上环境天光,意味着它真正具备了渲染一个有体积、有氛围的真实场景的能力;叙事、角色、UI 几个工作台陆续住进来,意味着"做一个游戏需要的各种活儿"开始能在同一个平台里就地完成。一个游戏不止是代码,它有画面、有剧情、有角色、有界面——这一天恰好在这几个维度上同时落子,让平台离"一个人在这里就能把一个完整游戏做出来"这个目标更近了。底层画质和上层工具一起长,是这条产品路线最稳的走法。
