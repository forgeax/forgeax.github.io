项目正式对外开源 + 桌面端不再开机崩

这是一个里程碑日子:整个项目正式对外开源——每个模块都配齐了图文并茂的中英双语文档、开源许可,并支持"自带你自己的 agent 订阅";同一天还修好了打包后桌面应用一启动就崩的顽疾、把官网示例画廊改成可边看列表边实时跑的分栏,引擎也落地了资产优先启动、阴影开关合并与骨骼动画修正。

从"自己用"到"给所有人用"

这一天是一个项目生命中很特别的节点:它第一次完整地、体面地把自己交到了公众手里。开源不只是"把代码公开"这么一个动作,它意味着一整套面向陌生人的准备——别人凭什么看懂你在做什么?凭什么相信它能跑起来?凭什么愿意自己装、自己改?这一天做的所有事,都在回答这些问题:给每个模块写清楚"它是什么、怎么协作、怎么上手"的双语文档,补齐开源许可让别人能合法地使用和修改,确保下载下来的东西真能一键跑通而不是缺东少西,把桌面应用启动即崩的拦路虎清掉,把官网的示例做得能让人一眼看见"这东西能做出什么"。一个内部项目走向开源,最难的从来不是公开代码本身,而是把"只有自己人懂"的东西,重新打磨成"任何人都能上手"的样子。这一天,做的正是这件事。

项目正式对外开源:全模块双语文档 + 自带你自己的 agent 订阅

这天把对外开源所需的门面一次性磨完。最核心的一项,是给全部核心模块加上整个超级工程都配齐了图文并茂的中英双语文档,而且统一成同一种三段式结构:第一段讲"它为什么不一样"(这个平台到底特别在哪),第二段讲"一条七步的人机协作闭环"(人和 AI 是怎么一步步把一个想法变成游戏的),第三段是"各模块地图"(整个项目由哪些部分组成、各管什么)。这种统一结构让任何一个陌生人,无论先点开哪个模块,都能用同一套心智模型快速读懂。命令行那块还专门加了一节"自带你自己的 agent 订阅":你不必被绑死在某一家,而是可以接上自己已有的编码 agent 订阅或接口来驱动整个平台——四种主流方式任选其一。每个子模块也都补齐了开源许可,让别人能在清晰的授权下放心地使用、修改、再分发。对一个想被社区了解、被开发者二次开发的项目来说,这套文档和许可,就是它递给世界的第一张名片。

桌面 App 不再开机就崩

开源发布要让人"下载就能跑",而当时打包出来的桌面应用恰恰栽在这一关上:一启动就反复崩溃,后端不断报找不到某个核心运行模块。根因在于打包时漏带了那个模块及其依赖,离线运行时自然找不到。这天的修法是把所需的整个运行依赖闭包都完整打进桌面包里随包自带,确保离线环境下也一应俱全、能正常起来。同时还顺手解决了两个相关的坑:一是把桌面包改成单游戏打包,绕开了多个游戏同时存在时资源标识相互撞车的老问题;二是容忍了打包过程中复制大量文件时偶发的"文件刚刚消失"的小故障——以前这种瞬时抖动会因为严格的错误检查而把整个构建直接中断。改完之后,桌面应用能稳定地启动、正常地进入,不再开机就挂。这件事的意义,正好踩在开源发布的节骨眼上:再好的项目,如果别人下载下来连打都打不开,一切都无从谈起。

官网示例画廊:边看列表边跑 demo

配合开源,官网的示例画廊也重做成了一种"边看边跑"的分栏布局。左边是所有示例的列表,可以按类别筛选;右边是一个实时运行的预览框,你点中哪个示例,右侧就直接把它跑起来——不必下载、不必离开页面,即点即看。它还支持深链:把某个示例的网址发给别人,对方打开就能直接定位到那一个,方便分享和引用。配套还做了一个插件信息生成器,把各个插件的元数据自动抓取成结构化数据,于是画廊里的卡片不再是看不动的静态图,而是能点开弹窗看详情。对一个刚开源、想让人快速建立"这东西到底能做什么"印象的项目来说,一个能即点即玩的示例画廊,胜过千言万语的介绍——亲眼看到一个 demo 跑起来,远比读一段描述更有说服力。

引擎:资产优先启动 + 阴影开关合并 + 骨骼动画修正

引擎这天也是大日子,推进了好几项。其一是"资产优先"的启动方式落地,全部六个样例游戏一并迁过来:游戏不再靠一段开场代码把场景一件件搭出来,而是从一份结构化的资产(场景描述)出发直接实例化——这更干净、也更利于被可视化编辑器读写。其二是把投影开关简化了:以前要给方向光单独挂一个"投影"组件才能让它产生阴影,现在合并成方向光自带的一个开关,需要投影就打开,概念少了一个,用起来更直觉。其三是修了骨骼动画里一个真实存在的方向错乱 bug——旋转数据之前被错误地当成了另一种表示方式,导致从专业工具导入的带动画模型转向不对;修好后转向终于正确。此外,瓦片地图支持了"物体层"渲染(在格子地图之上,每个格子可以放置带朝向、翻转、轴心的独立物体),做 2D 关卡更灵活;底层还加固了资产注册和渲染器在出意外后的健康恢复。这些改进有的是为了更干净的架构,有的是为了修正错误,有的是为了拓展能力,但都在让引擎这块地基更扎实——恰好赶在开源、要被更多人审视和使用的时刻。

这一天意味着什么

这一天的分量,在于"对外"两个字。在此之前,平台的所有进步都是面向内部、面向自己的;而从这天起,它第一次完整地把自己摆在了公众面前——任何人都能下载、阅读、运行、修改、贡献。开源是一个项目从"一群人的作品"走向"一件公共的东西"的转折,它把这个项目放进了一个更大的、由全世界开发者共同审视和参与的语境里。值得一提的是,这一天为开源所做的努力,几乎全是"为别人着想"的:写清楚文档,是为了让陌生人看懂;补齐许可,是为了让别人放心使用;修好桌面崩溃、确保一键能跑,是为了让第一次接触它的人不被劝退;做好示例画廊,是为了让人一眼看见它的可能性。一个项目愿意花一整天,只为把自己变得"对别人更友好",这本身就说明它准备好了走向更广阔的世界。从这天起,这个用 AI 做游戏的平台,不再只属于做它的人。
