关掉浏览器,agent 照样在后台干活

这天 agent 从"陪你聊天的窗口"变成了"能在后台长跑的同事":关窗、断网都不影响它继续干,重开能接着看;多个对话标签页并发互不串台;新增本地监控面板纵览所有任务;几种编码后端共用一套协议、随时可切;引擎也补上了句柄与 GUID 资产的统一词汇。

从"关窗即停"到"后台不死"

在此之前,agent 的命跟浏览器是绑在一起的:你一关标签页,后台那个正在干活的进程就被一并结束了——做一半的长任务说没就没。这对"让 AI 替你长时间做事"是个根本性的障碍:谁敢把一个要跑几十分钟的任务交给它,然后整个过程不敢关电脑、不敢断网?这天的主线,就是把 agent 从浏览器里"解绑",让它成为一个独立、持久、可随时回来查看的后台同事。这是一个心智上的转折:从"我开着窗口看它聊天",变成"我把活交给它,然后该干嘛干嘛,回头再来看结果"。

关窗 / 断网后 agent 不死、可续看

实现这件事的核心,是把每一次任务运行(Run)都持久化成磁盘上的记录,并配一份索引。这样一来,agent 的进程不再依赖前端的连接活着——浏览器断开,只是断了"看"的那条线,干活的那条线还在后台跑。当你重新打开,前端会带着"我上次看到哪了"的标记重新连上,把你离开期间错过的输出补齐、再接上仍在飞的实时流。当天实测中,一篇一万多字、在你重新加载页面之后才生成完的长回复,能跨着这次刷新被完整渲染出来,一个字都不少。这背后是一套"可断点续传"的事件流设计:每条事件都有序号,续连时从你上次的序号往后取,既不丢也不重。

多对话标签页并发,互不串台

既然 agent 能后台长跑,自然就该能同时开好几个。这天界面支持了多对话标签页:顶部一个加号就开一个新会话,你可以让一个 agent 在这个标签里跑长任务,同时在另一个标签里跟另一个 agent 聊别的,两边互不打断。切换标签不会中断任何一个后台运行,各自的状态、各自的流都稳稳隔开。对"一个人带一支 AI 团队"这个设想来说,多标签并发是最直观的入口——它让"同时推进好几件事"从概念变成了你随手就能做的操作,也为后面真正的多 agent 协作铺了路。

本地监控面板:总览、运行、会话、用量

既然任务都在后台跑、还能多开,就需要一个地方纵览全局。这天在右上角加了一个本地监控面板,分四个视图:总览看全局态势、运行中的任务看谁还在跑、会话看历史对话、用量分析看消耗。你可以在这里取消或删除任务,也能实时盯着任意一个任务的输出流逐字滚出来。它的价值在于"掌控感"——当你把多个长任务丢在后台,你需要一个仪表盘随时知道它们各自到哪一步、有没有出问题、花了多少。把这种"运维视角"做进产品,意味着平台不只想让你"用 AI 做一件事",而是认真对待"你会同时管很多件事"这个现实。

几种编码后端,一套协议、随时可切

驱动 agent 的"编码后端"不止一家,各家的事件格式、能力、稳定性都略有差异。这天又接入了一种新的后端,并把所有后端都统一到同一套事件流协议之下——无论底层是哪一家,前端看到的都是同一种规整的事件,因此界面与流程完全一致。最实际的好处是:某一家临时不可用或者表现不佳时,你可以一键切到另一家,而界面、操作、体验都不变形。把"用哪个模型后端"做成一个可插拔、对上层透明的选择,既保护了用户不被单一供应商绑定,也让平台能从容地接入越来越多的后端,而不必每接一家就重写一遍界面。

引擎:句柄与 GUID 资产的统一词汇

引擎这天在底层"概念词汇"上做了重要的收敛。资产被赋予了全局唯一标识(GUID),并定义了一套以此寻址的磁盘存放格式——意味着任何一份资产都有一个永不混淆的身份,跨项目、跨场景都能被准确地引用到。配套把"句柄"的类型设计也理清了,用两个维度去刻画一个引用的性质,让引用既类型安全又表达清晰。引擎还把"实例化"从隐式的自动合批改成了显式声明:你明确告诉引擎"这是一批要批量绘制的同种物体",行为更可控、更可预期。这些都是看不见的底层工程,但它们决定了引擎在内容越来越多、场景越来越复杂时,能不能保持清晰不乱——给资产一个可靠的身份系统,是后面一切"导入、复用、组合"的前提。

游戏改为按项目本地存放 + 修好热更新刷新

这天还调整了游戏内容的存放方式:从"统一发布"改成"每个项目自己存一份",游戏数据就放在该实例自己的目录里。这更符合直觉——你的游戏属于你的项目,而不是被发布到某个公共池里。配套修了一个困扰已久的热更新问题:此前在某些代理转发的情况下,浏览器重新加载后预览不会真正刷新,原因出在热更新通道连错了端口;这天把它修对,让"改完即见"在各种部署路径下都稳定成立。这类调整看着琐碎,却是"边说边做"能不能始终丝滑的底层保障。

这一天意味着什么

这一天最大的转变,是 agent 的身份变了:它不再是一个"只在你看着时才存在"的聊天对象,而成了一个能独立长跑、被纵览管理、随时可回来查看的后台同事。关窗不死、多开并发、有面板可管、后端可换——这几件事合起来,把"让 AI 替你做事"从一个演示场景,推向了一个真实的工作方式。你可以同时把好几个任务丢给不同的 agent,关掉电脑去做别的,回来再逐一验收。这正是这个平台想成为的样子:不是一个你得一直盯着的玩具,而是一支你可以放心托付、然后回来收货的团队。后面真正的多 agent 协作,就建立在这天打下的"持久 + 并发 + 可观测"地基之上。
