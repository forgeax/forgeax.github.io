ForgeaX Studio v0.3.27：安装更稳、预览补齐、游戏运行时独立发布

v0.3.27 让首次安装更可靠，修复 Windows 下的插件目录链接，将材质、Mesh 与 VFX 预览补进 Studio，并让游戏宿主可以独立使用已发布的运行时包。

首次安装更顺畅

Studio 现在会在安装插件时遵循插件声明的包管理器与锁文件。Windows 下，Marketplace 插件目录会被整理为可用的目录链接，避免需要启动子进程的插件因为符号链接占位目录不能作为工作目录而失败。

宿主补齐预览与资产能力

材质、Mesh 和 VFX 预览视口现在统一通过 editor facade 注册，Studio 宿主可以获得一致的预览能力。资产导入与基于 catalog 的文件操作也统一使用规范路径映射，让编辑器路径和磁盘文件保持一致。

Game Runtime 可独立发布

Game Runtime 包及其 SDK 声明现在作为独立发布面构建。游戏宿主可以直接消费运行时包，不必引入完整的 Studio 构建。

详见 ForgeaX Studio v0.3.27 发布页。
