让你的 AI CLI 克隆并启动 ForgeaXHave your AI CLI clone & launch ForgeaX

最 AI 原生的装法:不用自己敲命令 —— 把仓库地址交给你的编程 CLI 智能体,让它自己 clone、装依赖、启动,再把本地地址告诉你。The most AI-native install: don't type the commands yourself — hand the repo to your coding-CLI agent and let it clone, install, launch, and report back the local URL.

✅ 已开源(Apache-2.0)。下面的流程对任意 AI 编程 CLI 都适用。✅ Open source (Apache-2.0). The flow below works with any AI coding CLI.

你需要什么What you need

  • 一个能跑 shell 命令的 AI 编程 CLI —— 例如 Claude Code、Codex、Cursor,或 ForgeaX 自带的 forgeax CLI;An AI coding CLI that can run shell commands — e.g. Claude Code, Codex, Cursor, or ForgeaX's own forgeax CLI;
  • 已安装 git 和 Bun(项目运行时);git and Bun (the project runtime) installed;
  • 一个 AI 模型的 API key(供工作室里的 Forge 使用)。an AI model API key (for Forge inside the studio).

一句话交给 CLIOne instruction to your CLI

在一个空目录里打开你的 CLI,把下面这段话发给它:Open your CLI in an empty folder and give it this:

克隆 https://github.com/ForgeaX-Games/forgeax-studio
(带上子模块 --recurse-submodules),
进入目录后运行 install 脚本装好依赖,
再运行 start 脚本启动它,
最后把可以打开的本地地址告诉我。Clone https://github.com/ForgeaX-Games/forgeax-studio
(with --recurse-submodules), cd into it,
run the install script to set up dependencies,
then run the start script to launch it,
and tell me the local URL I can open.

CLI 会自己执行 clone、安装、启动这几步,过程里需要的选择(比如填 API key)它会问你。完成后你会拿到一个本地地址,在浏览器打开就是工作室。The CLI runs the clone / install / launch steps itself, asking you for anything it needs along the way (such as the API key). When it's done you get a local URL — open it in the browser and you're in the studio.

手动等价命令(可选)Manual equivalent (optional)

如果你想自己来,等价的命令大致是:If you'd rather do it yourself, the equivalent is roughly:

git clone --recurse-submodules \
  https://github.com/ForgeaX-Games/forgeax-studio
cd forgeax-studio
bun fx setup     # 装依赖(+ 填 API key)install deps (+ add API key)
bun fx start     # 启动launch the studio

这套 bun fx 命令是跨平台的 —— macOS、Linux、Windows 通用,Windows 上无需 Git-Bash。启动后按提示在浏览器打开本地地址即可。These bun fx commands are cross-platform — the same on macOS, Linux and Windows, with no Git-Bash needed on Windows. Then open the local URL it prints.

接下来就去 快速开始,对 Forge 说出你的第一个游戏。Next, head to Quick start and tell Forge your first game.

为什么这样装最顺?因为 ForgeaX 本就是为 AI 设计的 —— 连"把自己装起来"这件事,也乐意交给 AI 做。Why is this the smoothest install? Because ForgeaX is built for AI in the first place — even "set itself up" is something we're happy to hand to an agent.
