快速开始:你的第一款游戏Quick start: your first game

ForgeaX 的核心用法只有一句话:把你想做的游戏描述给 Forge,剩下的交给它。ForgeaX's core workflow is one sentence: describe the game you want to Forge, and let it handle the rest.

✅ 已开源(Apache-2.0)。完整安装命令见 下载与安装;本篇讲"上手后的工作流"长什么样。✅ Open source (Apache-2.0). For full install commands see Download & install; this page covers what the workflow feels like once you’re in.

1 · 启动工作室1 · Launch the studio

装好依赖后,一条启动命令会拉起工作室,浏览器打开后你会看到两块区域:After dependencies are installed, one command brings up the studio. In the browser you'll see two areas:

  • 左边:对话区 —— 你和 Forge(主 agent)聊天的地方;Left: chat — where you talk to Forge (the main agent);
  • 右边:预览区 —— 你的游戏实时运行的画面。Right: preview — your game running live.

2 · 说出你的第一个需求2 · Say your first request

不用写任何代码,直接对 Forge 说,比如:No code needed — just tell Forge, for example:

做一个俯视角的小游戏:
一个角色在场地里跑,按空格发射子弹,
四周不断刷新敌人,打中就消失,记个分。Make a top-down game:
a character runs around an arena, space fires bullets,
enemies keep spawning, hits remove them, keep score.

Forge 会先把需求理清楚,必要时派子 agent 做规划与设计,然后自己编写引擎代码。Forge clarifies the requirement, brings in sub-agents to plan and design when needed, then writes the engine code itself.

3 · 看它跑起来3 · Watch it run

代码一写好,就会热重载到右侧预览 —— 几乎是边写边出现。你不满意就继续说:As soon as code is written it hot-reloads into the preview — almost as it's typed. Not happy? Just keep talking:

子弹再快一点,敌人血量加倍,
背景换成夜晚。Make bullets faster, double enemy health,
switch the background to night.

每一句反馈都会变成一次新的迭代。这就是 ForgeaX 的基本循环:描述 → 生成 → 游玩 → 再描述。Every bit of feedback becomes another iteration. That's the ForgeaX loop: describe → generate → play → describe again.
