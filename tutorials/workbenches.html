Generate art with the workbenches

Beyond chatting, ForgeaX has a set of "workbenches" — each a panel plus a group of tools that turn a sentence into game-ready assets. You by hand and AI by dispatch edit the same artifact.

✅ Open source (Apache-2.0). Below is an overview of the workbench system; for clone & install see the docs.

Characters · animation · VFX

  • Character editor — write a one-line brief, get a portrait plus a turnaround.
  • Animation — turn a still character into walking, attacking, four-direction, skeletal motion (even short clips) — without face drift.
  • Skill / VFX — add effects like fire, slashes and auras, auto-attached to the moment of cast.

3D modeling & generation

  • Blocky-character editor — build rigged 3D characters like snapping blocks, export standard 3D files.
  • Low-poly generator — build 3D props with a node-graph; change one parameter, regenerate the set.
  • 3D generation — text or image straight to a 3D model, plugged into several top generators, pick whichever's best.

Scenes · UI · items

  • Scene generator — assemble a whole game scene as a graph you can re-run anytime.
  • 2D scene-asset generator — batch props, textures, decorations and UI bits, auto-named and filed.
  • UI workbench — a UI set for your game type — not just images, a clickable prototype.
  • Items / icons — weapons, potions, coins as icons with their data, art and numbers in one table.

Narrative · music · look · numbers

  • Narrative workbench — from a spark to a full story and world, with the AI picking a fitting approach.
  • Music / BGM — manage background music and sound effects, sequencing a whole session's score.
  • Color / Look — unify the whole game's color mood in one click, like a filter over everything.
  • Balance — have AI play thousands of matches and report win rates with confidence intervals; let data judge the tuning.

System & author tools

  • Code — browse code, jump between files, and edit alongside the coding AI.
  • Observatory — replay every step the AI took, like a black box, to pinpoint where things went wrong.
  • Plugin author — let non-coders build their own workbench plugins.
  • Admin — the studio control panel: toggle workbenches, bind models, see which AIs are online.
Can't draw, model or compose? That's fine — describe it, and the workbenches produce assets that drop straight into your game.
