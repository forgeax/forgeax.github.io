ForgeaX Studio v0.2.0 发布ForgeaX Studio v0.2.0 is out

首个带说明的稳定版。从首次启动到把游戏做出来,这一版让上手更快、创作路径更全、对贡献者更友好。Our first documented stable release. From the very first launch to shipping a game, this one makes onboarding faster, the authoring paths fuller, and the codebase friendlier to contributors.

🟢 重点更新🟢 Highlights

  • 首启引导 —— 选好模型供应商(默认 OpenRouter),几分钟即可开始做游戏,不用先折腾 key。Guided first-run onboarding — pick a model provider (OpenRouter by default) and start building in minutes; no key wrangling to begin.
  • 在可视化编辑器里创作游戏 —— 新增 open-project 流程 + 引导式建游戏入口;编辑器直接 bootstrap 项目,并把场景资产写回磁盘。Author games in the visual editor — a new open-project flow plus a guided game-creation entry; the editor bootstraps a project and writes scene assets straight to disk.
  • 在 studio 内扩展工作台 —— 插件作者面板 + host SDK,不出应用即可写自己的可视化 workbench 插件。Extend the workbench in-studio — a plugin-author panel and host SDK to build your own visual workbench plugins without leaving the app.
  • 更大的工作室团队 —— 新增 scene-pipeline agent(director / sino / mira)加入 Forge 的子 agent 阵容。A bigger studio team — new scene-pipeline agents (director / sino / mira) join Forge's crew of specialist sub-agents.
  • 引擎升级 —— world 作用域插件构建 + handle 编解码。Latest engine — world-scoped plugin build and handle codec.

🟡 改进🟡 Improvements

  • 更干净、对贡献者友好的资产管线 —— 工作台电池/模板路径与预设资产全部 ASCII/英文化(结构路径无空格、括号或中文),跨平台 checkout 更安全。Cleaner, contributor-friendly asset pipeline — workbench battery/template paths and preset assets are now ASCII/English only (no spaces, parentheses, or CJK in structural paths), for safe cross-platform checkouts.
  • 工作台列表虚拟化(react-virtual)+ engine-plugin 接入。Virtualized workbench lists (react-virtual) and engine-plugin wiring.

⚪ 基建⚪ Infrastructure

  • CI 提速(Rust / pnpm / Bun 缓存)、提交可溯源闸门,以及公开 CI 的密钥扫描步骤。Faster CI (Rust / pnpm / Bun caching), a human-traceable-commit gate, and a secret-scan step in public CI.
ForgeaX 全部开源,Apache-2.0,各仓在 github.com/ForgeaX-Games。ForgeaX is fully open source under Apache-2.0 — every repo lives at github.com/ForgeaX-Games.
