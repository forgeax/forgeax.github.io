骨骼动画系统全链路跑通Skeletal animation, end to end

从一个 FBX 文件,到引擎里的 mesh + 骨架 + 动画 clip,再到游戏里 idle ↔ walk ↔ cast 的顺滑切换 —— Hellforge 的女巫第一次真正动了起来。From an FBX file, to mesh + skeleton + animation clips in the engine, to smooth idle ↔ walk ↔ cast in-game — Hellforge's witch finally moves for real.

骨骼动画(skeletal animation)是 ARPG 这类游戏的门槛级能力:没有它,角色就只能是个会平移的方块。这一阶段我们把整条链路打通了,而且是在很短的时间内连续合入的几个改动。Skeletal animation is table-stakes for games like ARPGs: without it, a character is just a sliding box. In this milestone we closed the whole pipeline — across a handful of changes landed in quick succession.

整条管线The pipeline

一个角色从素材到能在游戏里动起来,要经过四步:Getting a character from asset to moving in-game takes four steps:

  • ① FBX 导入 —— 解析模型文件,拆出 mesh、骨架、蒙皮权重、动画 clip 等子资产,落成引擎可读的结构化数据。① FBX import — parse the model file into sub-assets (mesh, skeleton, skin weights, animation clips) as structured, engine-readable data.
  • ② 骨架 / 蒙皮 —— 顶点跟随骨骼变形的 skin shader,修掉了节点重复变换之类的坑。② Skeleton / skinning — a skin shader that deforms vertices with the bones, fixing pitfalls like double node transforms.
  • ③ Clip 播放 —— AnimationPlayer 用列式(SoA)结构同时驱动多条动画通道。③ Clip playback — an AnimationPlayer that drives multiple channels at once with a columnar (SoA) layout.
  • ④ 过渡(crossfade) —— 在 idle / walk / cast 之间做平滑过渡,而不是硬切。④ Crossfade — smooth transitions between idle / walk / cast instead of hard cuts.

在游戏里兑现Cashed out in a game

这套能力的第一个落地对象,是一款 Diablo 风格的 ARPG demo Hellforge 里的女巫角色:The first thing this powered is the witch in Hellforge, a Diablo-style ARPG demo:

  • 2.5D 俯视视角,会放 Fire Bolt 火球法术;2.5D top-down view, casting a Fire Bolt spell;
  • 5 个动画 clip:idle / walk / run / cast / death,通过 GUID 在场景里引用;5 animation clips — idle / walk / run / cast / death — referenced by GUID in the scene;
  • 玩家 30 秒内可以体验一段完整循环:出营 → 遇怪 → 法术击杀 → 拾取战利品 → 回营。a full 30-second loop: leave camp → meet a monster → kill with a spell → grab loot → return.

对用户来说,这意味着你在 Studio 里描述一个"会放法术的女巫",拿到的不再是一个滑动的色块,而是一个有 idle 待机、跑动、施法动作的角色。For users, it means that when you describe "a witch who casts spells" in the Studio, you no longer get a sliding blob — you get a character that idles, runs and casts.

所有这些能力,最终都通过游戏的 forge.json 声明式接入 —— 指定模型与各个动画 clip 的引用,引擎负责把它们装配起来。All of it plugs in declaratively through the game's forge.json — point at the model and the clip references, and the engine assembles the rest.

下一步What's next

目前是"简单过渡"档,接下来会补:Right now it's "simple transition" grade. Next we'll add:

  • BlendTree —— 让移动速度平滑混合走/跑等动作;BlendTree — blend walk/run by movement speed;
  • Mask —— 上半身施法、下半身走路这类分区叠加;Mask — layered regions, e.g. casting with the upper body while walking;
  • IK —— 脚步贴地、手部对位等反向动力学。IK — inverse kinematics for foot planting and hand alignment.

这些补齐后,角色动画的表现力会再上一个台阶。With these in, character animation gets another notch more expressive.
