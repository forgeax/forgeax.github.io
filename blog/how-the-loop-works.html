AI 是怎么把一个功能做对的How AI gets a feature right

AI 不是靠"一次写对"的。ForgeaX 用一条可观测、可回溯的流水线,让每个功能一步步收敛到正确。AI doesn't get things right in one shot. ForgeaX uses an observable, traceable pipeline that guides each feature to a correct result, step by step.

七步闭环A seven-step loop

在引擎内部,每个功能都经过同一条流水线 —— 需求进、可用产物出,中间每一步都留下可读的记录:Inside the engine, every feature goes through the same pipeline — requirements in, a working result out, with a readable record at each step:

  1. 需求 —— 把要做什么写清楚,带验收标准。Requirements — state what to build, with acceptance criteria.
  2. 研究 —— 查历史、约束与可选方案。Research — survey history, constraints and options.
  3. 计划 —— 定策略,拆成可执行任务。Plan — set a strategy and break it into tasks.
  4. 实现 —— 写代码 + 测试。Implement — write code and tests.
  5. 验证 —— 多方独立检查,任一不过就拦下。Verify — independent checks; any red blocks the merge.
  6. 验收 —— 人来把最后一关。Judgment — a human makes the final call.
  7. 合入 —— 通过后并进主干。Finalize — merge once it passes.

编排者 + 子 agentAn orchestrator and sub-agents

一个"编排者"推进这条状态机,决定每一步派哪个子 agent、并检查它的产物;子 agent 各有角色、各自独立上下文。人类只在两个出入点注入判断:提需求和做验收。An "orchestrator" drives the state machine, deciding which sub-agent to dispatch at each step and checking its output; sub-agents are role-specialized with their own context. Humans inject judgment at just two points: stating requirements and reviewing results.

不让"看起来过了"溜过去No "looks fine" slipping through

验证步里有两道 AI 关卡:一个以 AI 用户视角静态扫文档与 API,抓"承诺了却没实现";另一个在隔离沙箱里真跑 demo、截图,再回头核对画面对不对 —— 防止"测试假绿、画面却是黑的"。Verification has two AI gates: one statically scans docs and APIs from an AI user's perspective, catching "promised but not implemented"; the other actually runs the demo in an isolated sandbox, captures screenshots, and re-checks them — guarding against "tests green, screen black."

越跑越稳It gets steadier over time

每个功能跑完,过程里遇到的痛点会沉淀成反馈,反过来升级流水线本身。下一个功能自动用上更新后的版本 —— 流水线吃自己的产物,越跑越懂。After each feature, the friction encountered along the way is captured as feedback that upgrades the pipeline itself. The next feature automatically uses the improved version — the pipeline feeds on its own output and gets smarter.

结果是:AI 写出来的不是"demo 级"代码,而是经过验证、可重放、能被人接手的功能。The result: AI produces not "demo-grade" code, but verified, replayable features a human can take over.
