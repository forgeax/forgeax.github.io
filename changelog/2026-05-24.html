你做出来的游戏现在端到端跑在自研引擎上;材质支持自定义着色器,专家 agent 也更齐了。The games you build now run end-to-end on the in-house engine; materials support custom shaders, and the roster of specialist agents grew.

游戏运行时全面换上自研引擎The game runtime moves fully to the in-house engine

这是一个分水岭:预览里实际跑你游戏的运行时,从早期借用的通用渲染方案,整体换成了自研引擎。意味着前面这些天攒起来的能力——基于物理的光照、阴影、环境天光、资产系统、2D 精灵图层——现在都收在同一套引擎里协同工作,而不是各管一摊。统一之后,渲染表现更可控、问题更好定位,后续要加的新特性也能一处实现、处处生效。从今天起,"聊出来的游戏"跑在的是我们自己的引擎上。This is a watershed: the runtime that actually runs your game in the preview switched, wholesale, from an early general-purpose rendering approach to the in-house engine. That means the capabilities built up over the past days — physically-based lighting, shadows, ambient sky light, the asset system, 2D sprite layers — now work together inside one engine instead of each living on its own. Unified, rendering is more controllable, problems are easier to pin down, and new features can be built once and take effect everywhere. From today, the "games you chat into being" run on our own engine.

材质支持自定义着色器Materials gain custom shaders

材质系统分成了"模板 + 实例"两层:既有一套开箱即用的标准物理材质,也允许某个物体挂上自己的自定义着色器去做独特的视觉效果——而引擎会按材质缓存各自的渲染管线,不会因为多了花样就拖慢。配套的示例做了一个会"脉动发光"的效果来验证这条路打通了。想要某个物体看起来与众不同,现在有了正路。The material system split into two layers — template and instance: there's a ready-to-use standard physically-based material, and any object can also carry its own custom shader for a distinctive visual effect, while the engine caches a render pipeline per material so extra variety doesn't slow things down. A demo with a "pulsing glow" effect proved the path works end-to-end. Wanting one object to look unlike the rest now has a proper route.

更多专家 agent,工具里直接挑人More specialist agents, picked right in the tool

协作阵容更齐了:新增了一批各有专长的 agent,可以按任务挑合适的来干。工具窗的顶栏还加了 agent 选择器,能直接在某个工作台里指定由哪个 agent 接手,并一键打开它的详情。让对的人做对的事,现在更顺手。The collaboration roster filled out: a batch of new agents with distinct specialties arrived, so you can pick the right one for a task. The tool window's top bar also gained an agent picker, letting you assign which agent takes over inside a given workbench and open its details in one click. Getting the right agent on the right job is now smoother.
