引擎完全自立:不再依赖外部渲染库A fully self-standing engine

一个分水岭:引擎拔掉了最后一个外部渲染库依赖,从此完全靠自己的渲染管线运行,并自带一套"像素级对齐"的基准——能自己给自己验证每一帧画得对不对,不再需要借第三方库当对照答案。这意味着引擎是一个能独立站住的成熟渲染器,后续的画质、性能、特性都掌握在自己手里,演进不受外部库牵制。A watershed: the engine removed its last external rendering-library dependency and now runs entirely on its own rendering pipeline, with a built-in "pixel-parity" benchmark — it can verify for itself that every frame is drawn correctly, no longer needing a third-party library as the reference answer. That makes it a mature renderer standing on its own, with image quality, performance and features in its own hands and free to evolve without being held back by an outside library.

更真实的材质:自发光 + 环境光遮蔽 + 多种色调映射Richer materials: emissive + ambient occlusion + tone-mapping looks

材质系统统一并升级了一档:同一套材质模型现在支持自发光(物体能自己"亮"起来,做霓虹、发光符文这类效果)、环境光遮蔽(缝隙、转角处自然变暗,立体感更强),还提供多种色调映射风格让你挑画面的整体观感。复杂材质会被串进渲染管线缓存,花样多了也不掉帧。东西看起来更"对"、更有质感。The material system was unified and stepped up a level: one material model now supports emissive surfaces (objects can glow on their own, for neon or glowing runes), ambient occlusion (crevices and corners naturally darken for stronger depth), and several tone-mapping looks to choose the overall feel of the image. Complex materials are threaded through a render-pipeline cache, so more variety doesn't cost frame rate. Things look more "right," with real texture to them.

更广的设备兼容:老设备也离"画得出"更近Wider device support: older machines get closer to rendering

浏览器里的渲染管线补齐了关键的一组底层能力,让引擎在网页中跑得更完整;对没有最新显卡能力的老设备,也补上了兜底路径——包括给缺少某些现代特性的设备做的材质兼容方案。综合下来,能正常跑起 3D 的机器范围又宽了一截。The in-browser rendering pipeline filled in a key set of low-level capabilities, so the engine runs more completely on the web; for older devices without the latest GPU features, fallback paths were added too — including a material-compatibility route for devices missing certain modern features. Net result: the range of machines that can run 3D properly widened another notch.

预览有了原生"播放器",50 行就能写个游戏A native preview player — a game in 50 lines

预览游戏现在用的是平台自己的原生运行宿主,一套清爽的游戏入口与加载器,不必再绕外部宿主。游戏模板也压缩到约 50 行——从五十行起步就能写出一个能跑的游戏。配套还做了"全程 HTTPS"和预览自动恢复:预览万一出错会自己重连,不用手动刷。The preview now uses the platform's own native runtime host — a clean game entry and loader, with no detour through an external host. The game template was trimmed to about 50 lines, so a runnable game starts from fifty lines. Alongside it came "HTTPS everywhere" and preview auto-recovery: if the preview hits an error it reconnects on its own, with no manual refresh.
