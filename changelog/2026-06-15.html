新增暗黑风格 ARPG 样例:HellforgeA new dark-fantasy ARPG sample: Hellforge

新增一个完整的暗黑风格动作角色扮演(ARPG)样例游戏 Hellforge:女巫主角是带骨骼的角色模型,自带五段动画(待机、移动、攻击等),用一个按键就能在越肩视角和 2.5 俯视视角之间切换,战斗动作由一套状态机驱动衔接自然。场景配了夜视氛围光——昏暗月光加几支营地火炬。它把前面攒下来的骨骼动画、相机、战斗、光照都串进一个真实玩法里,既是能直接玩的样例,也是做同类游戏的现成起点。A complete dark-fantasy action-RPG sample game, Hellforge, was added: the witch hero is a rigged character model with five animations (idle, move, attack and more), a single key toggles between an over-shoulder and a 2.5D top-down camera, and combat actions are driven by a state machine that blends them naturally. The scene carries night-vision atmosphere — dim moonlight plus a few camp torches. It threads the skeletal animation, cameras, combat and lighting built up over recent days into real gameplay — both a directly playable sample and a ready starting point for the genre.

编辑器更独立 + 上传模型立刻能用A more independent editor + upload a model and use it now

编辑器把前端外壳的核心框架整个吸收进来、删掉了自建的旧停靠层,从此能更彻底地独立装载,不必和主聊天界面绑在一起。更直接的好处是:试玩端补齐了完整的模型导入,覆盖模型的全部子内容(网格、材质、纹理、动画、骨骼等)——上传一个模型,马上就能在试玩里看到并使用它,编辑视图里也能预览带骨骼的角色。"拿来一个模型 → 立刻用进游戏"做成了端到端的一条线。The editor absorbed the core of the front-end shell's framework and removed its old self-built docking layer, so it can now mount independently rather than being tied to the main chat interface. The more direct benefit: the play side gained complete model import covering all of a model's sub-contents (mesh, material, texture, animation, skeleton and more) — upload a model and you can immediately see and use it in play, and preview rigged characters in the edit view too. "Bring in a model → use it in the game right away" became one end-to-end path.

可回退到任意一条历史消息 + 逐文件 diffRoll back to any past message + per-file diffs

后端加了消息级的回退点:每一步改动都有快照,你可以"软回退"到此前任意一条消息时的状态——不满意这几轮的改动,一键退回去重来,而且是可逆的、不会把后面的东西硬删掉。界面上把回退点、置灰、编辑态都呈现出来,并能看到每一步到底改了哪些文件、各改了多少的逐文件 diff。和 AI 来回试错,从此更敢放手,因为随时退得回来。The backend added message-level rollback points: every step of changes is snapshotted, and you can "soft-revert" to the state at any earlier message — unhappy with the last few rounds, roll back in one click and try again, reversibly, without hard-deleting what came after. The interface surfaces the rollback points, dimming and edit state, and shows a per-file diff of exactly which files each step changed and by how much. Trial-and-error with the AI gets bolder, because you can always come back.

引擎:接专业模型格式的准备 + 录像回放调试Engine: prep for professional model formats + record-and-replay debugging

引擎为吃下专业建模工具直出的模型格式(含动画、骨骼、物理参数)做了设计与准备,目标是省掉中间格式转换的折腾。还落了一套"录像 → 回放对比"的调试基础设施,能跨设备逐像素回看渲染,方便抓住"这台机器画得不一样"的回归问题。环境光遮蔽(让缝隙转角自然变暗)也接了进来,并修掉了一个会让自定义材质着色器在开抗锯齿时被静默失效的关键 bug。The engine designed and prepared to ingest the model formats that professional modeling tools output directly (including animation, skeleton and physics parameters), aiming to skip the hassle of intermediate format conversion. It also landed a "record → replay and compare" debugging infrastructure that can review rendering pixel-by-pixel across devices, making it easier to catch "this machine draws it differently" regressions. Ambient occlusion (naturally darkening crevices and corners) was wired in, and a critical bug where custom material shaders were silently disabled with anti-aliasing on was fixed.
