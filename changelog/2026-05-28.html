动画独立成工作台 + 工具执行实时流式显示A dedicated animation workbench + live tool streaming

把动画从角色工具里拆出来独立成工作台;工具执行过程实时滚动、结束自动收起;预览更稳,材质还能继承。Animation splits out of the character tool into its own workbench; tool execution streams live and auto-collapses when done; the preview is steadier, and materials can inherit.

动画与角色拆成专门的工作台Animation and character become focused workbenches

原先角色工作台一个人扛了"造型 + 动画 + 特效"太多职责,变得臃肿。这天把动画相关的能力(骨骼动画、视频生成等管线)整块拆出来,独立成一个专门的动画工作台;角色工作台则瘦身回归"做角色本身"。各司其职之后,两个工具都更聚焦、更好用,后面也能各自深耕。The character workbench had been carrying too much — modeling plus animation plus effects — and grown bloated. This day pulled the animation-related capabilities (skeletal animation, video generation and related pipelines) out as a whole into a dedicated animation workbench, while the character workbench slimmed back down to "making the character itself." With clearer division of labor, both tools are more focused and easier to use, and each can go deeper from here.

工具执行过程实时显示,完成自动收起Tool execution shows live, then tidies itself away

agent 调用工具时,过程现在是实时流式显示的——输出一行行滚出来,你能看着它一步步推进,而不是干等一个结果。为了不刷屏,显示采用"滚动末尾"的方式只留最新几行;当这一步执行结束,对应的工具面板会自动收起,界面立刻回归清爽。等待变得透明,看完又不碍事。When an agent calls a tool, the process now streams live — output rolls out line by line so you can watch it progress step by step instead of waiting blankly for a result. To avoid flooding the screen, the display keeps a "rolling tail" of just the latest lines; when the step finishes, its tool panel auto-collapses and the interface returns to clean at once. Waiting becomes transparent, and once you've seen it, it stays out of the way.

预览更稳,少了多余的崩溃提示A steadier preview, with less crash-prompt noise

预览的稳定性又收了一轮:加了针对渲染的崩溃防护,并把崩溃检测改成"出现第一帧画面之后才生效",避免刚加载时误报。原先那层略显多余的崩溃浮层也去掉了——真要重来,工具条上的重载按钮就够了。整体更安静,也更可信。Preview stability got another pass: crash prevention for rendering was added, and crash detection now only kicks in after the first frame appears, avoiding false alarms during load. The somewhat redundant crash overlay was removed — if you really need to start over, the reload button in the toolbar is enough. The whole thing is quieter and more trustworthy.

引擎:材质支持继承Engine: materials can inherit

引擎的材质现在可以从一个"父材质"继承属性:把共用的设置放在父材质里,子材质只覆盖需要不同的部分。一批材质要统一风格、又各有小差异时,既省事又不易出错。Engine materials can now inherit properties from a "parent" material: put shared settings on the parent, and a child material overrides only what needs to differ. When a batch of materials should share one look yet vary in small ways, it's both less work and less error-prone.
