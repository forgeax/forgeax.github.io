引擎加上物理与点选 + 界面底座换代The engine gains physics & picking + a rebuilt UI foundation

引擎一次补上物理、点选拾取、抗锯齿与性能剔除;界面换上更现代稳定的组件底座;还新增了影像工作台。The engine adds physics, click-to-pick, anti-aliasing and culling in one go; the interface moves onto a more modern, stable component foundation; and a new reel workbench arrives.

引擎大补强:物理 + 点选拾取 + 抗锯齿A big engine boost: physics + click-to-pick + anti-aliasing

引擎一口气补上了做游戏的几块硬骨头。最重磅的是接入了 2D 与 3D 物理:物体能受重力、碰撞、堆叠,做平台跳跃、打砖块、堆箱子这类玩法终于有了底层支撑。还加了"屏幕点选拾取"——鼠标点哪个物体就能精确选中它,这是编辑器交互和点击玩法的基础。画面上接入了抗锯齿,物体边缘不再有锯齿毛刺,看起来更干净。物理 + 点选 + 抗锯齿凑齐,引擎从"能渲染"迈向"能玩"。The engine knocked out several of the hard parts of making a game at once. The headline is 2D and 3D physics: objects respond to gravity, collisions and stacking, so platformers, brick-breakers and box-stacking finally have underlying support. It also gained screen picking — click an object with the mouse and you select it precisely, the basis for editor interaction and click-based gameplay. Anti-aliasing came in too, so object edges no longer show jagged stair-steps and look cleaner. With physics, picking and anti-aliasing together, the engine moves from "can render" toward "can play."

性能:大场景更流畅Performance: smoother large scenes

引擎加入了视锥剔除:摄像机看不到的物体会被自动跳过,不再白白花算力去画。场景越大、物体越多,这个优化省下来的就越多,复杂场景的帧率因此更稳。结合此前的实例化绘制,引擎扛大场景的底气更足了。The engine added frustum culling: objects the camera can't see are automatically skipped instead of wasting compute to draw them. The bigger the scene and the more objects in it, the more this saves, so frame rates hold up better in complex scenes. Combined with the earlier instanced drawing, the engine is far better equipped for large scenes.

界面底座换代:更现代、更稳的组件库A rebuilt UI foundation: more modern and stable

界面迁到了一套现代化的组件底座之上,弹窗、下拉、菜单、表单控件全部换成成熟可靠的实现,交互手感和无障碍都更好;原先一些用浏览器原生弹窗凑合的地方,也升级成统一风格的对话框。底层还加了一道"渲染错误兜底":万一某个界面组件抛错,不会再把整个启动画面卡死。整体更稳、更耐用。The interface moved onto a modern component foundation — dialogs, dropdowns, menus and form controls all switched to mature, reliable implementations, improving both feel and accessibility; places that used to make do with the browser's native popups were upgraded to consistent, styled dialogs. Underneath, a render-error safety net was added: if a UI component throws, it can no longer freeze the whole startup screen. The result is steadier and more durable.

新增影像工作台 + 选哪个游戏就激活哪个A new reel workbench + picking a game activates it

工具家族又添一位:影像工作台,用来组织过场与影像内容。另外,挑选或新建一个游戏时,系统现在会真正把它"激活"成当前工作的游戏,后台的工作目录也跟着切过去——选了哪个,接下来 agent 干活就对准哪个,不再出现"看着一个、改着另一个"的错位。Another member joined the tool family: a reel workbench for organizing cutscenes and cinematic content. Also, when you pick or create a game, the system now genuinely "activates" it as the current game, with the background working directory switching to match — whatever you choose is what the agents then work on, ending the mismatch of "looking at one game while editing another."
