聊天界面进阶:可调布局、嵌套工具调用、子 agent 卡片Chat UI grows up: resizable layout, nested tool calls, sub-agent cards

聊天与布局体验集中升级,并把实时输出与回放统一到同一条流水线。A focused upgrade to chat and layout, with live output and replay unified into one pipeline.

更顺手的聊天与布局A more usable chat and layout

工具调用现在嵌套在对应的待办项下、子任务以独立卡片呈现;侧栏 / 聊天 / 底部面板都能拖拽调整大小。长对话和多任务运行因此看得更清楚——一眼就能分辨谁在做什么、做到哪一步。Tool calls now nest under their to-do item and sub-tasks render as their own cards; the sidebar / chat / bottom panels are all resizable. Long conversations and multi-task runs read far more clearly — you can tell at a glance who's doing what, and how far along.

实时与回放统一Live and replay, unified

实时输出与历史回放现在走同一条流水线、共享同一套回调。意味着你重看一段历史,和当时实时看到的画面完全一致。Live output and history replay now run through one pipeline sharing the same callbacks. Replaying a past run looks exactly like watching it happen live.
