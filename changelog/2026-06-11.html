文字 / 图生 3D 真打通,产物直接进你的游戏Text/image-to-3D works for real — results land in your game

3D 生成工作台从"评测台"走到了"真能用":每个游戏有自己的一份 3D 资产存储,生成走云端上传的可达链路,用文字 / 图片生成 3D 模型已在真实环境跑通,工具编辑界面也重构对齐了统一风格。最关键的是产物落地——生成出来的模型会按游戏单独保存、并通过专门的资产通道发出来,直接就能接进你的游戏,而不是停在一个看看而已的展示页。"想要个模型"到"模型在我的关卡里",中间的距离一下子短了。The 3D-generation workbench went from "testbed" to "actually usable": each game has its own 3D asset storage, generation runs over a reachable cloud-upload path, generating 3D models from text or images now works in a real environment, and the tool editor UI was rebuilt to a unified style. The key part is delivery — generated models are saved per game and served through a dedicated asset channel, so they wire straight into your game instead of sitting on a look-only showcase. The distance from "I want a model" to "the model is in my level" just got much shorter.

Agent 写完自己验证再继续,不再卡着问你Agents verify their own work, instead of stalling to ask you

延续前两天的"验车线"思路,这天把 agent 的"写完→验证→继续"闭环真正收紧了。以前 agent 写完一段代码,常常既不自己跑测试、也不看构建报错,就停下来反问用户"这样对吗?"——可用户未必知道。现在它写完会自动跑一遍验证,失败就接着自己改,不再白白占用你的一个回合。配合聊天里新增的"跳到最新"浮标、以及翻看旧记录时不再被自动滚动打断,长对话也更好回看。Continuing the "build-gate" idea of the previous days, this day genuinely tightened the agent's "write → verify → continue" loop. Previously an agent would finish a chunk of code without running tests or checking build errors, then stop to ask the user "is this right?" — which the user may not know. Now it auto-runs a verification after writing and keeps fixing on failure, instead of needlessly spending one of your turns. With a new "jump to latest" marker in chat and no more auto-scroll interrupting you while reviewing old records, long conversations are easier to look back over too.

大场景冷启动大幅提速 + 新增弹幕生存样例Big scenes cold-load far faster + a new bullet-survival sample

引擎给大型场景做了一次冷启动瘦身:一个复杂室内大场景过去首次加载要读约 2GB 的网格数据,现在压成约 45MB 的一次性产物,启动快了一个数量级——严肃规模的场景终于跑得动。配套还能在一个场景里同时点亮数百盏灯、把清晰文字真正烤进画面,角色骨骼动画的数据链路也继续推进。样例方面,新增了一个"弹幕生存"风格的 3D 样例游戏:满屏小怪扑过来、自动开火清场,作为这类玩法的现成起点。The engine slimmed cold-start for large scenes: a complex indoor scene that once read about 2GB of mesh data on first load is now packed into a roughly 45MB one-time artifact, an order of magnitude faster to start — serious-scale scenes are finally runnable. Alongside it, a scene can light up hundreds of lights at once and bake crisp text into the picture, and the data chain for skeletal character animation kept advancing. On samples, a new "bullet-survival" style 3D sample game was added: swarms of little monsters rush in while you auto-fire to clear them, a ready starting point for that genre.
