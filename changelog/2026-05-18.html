打开任意目录当工作区 + 应用内版本与快捷键Open any folder as a workspace + in-app version & shortcuts

不再被强制把代码放进固定目录:挑任意文件夹就能开工;同时补上应用内版本号、更新日志和快捷键设置。No more being forced into a fixed directory — pick any folder and start; plus an in-app version badge, changelog and keyboard-shortcut settings.

打开任意目录当工作区Open any folder as a workspace

顶栏新增项目切换器,点开是一个文件浏览器,可以选磁盘上任意目录当作工作区——不再强制把代码塞进自带的某个固定目录里。最近打开过的项目会被记住,下次一键回到。选了一个空目录,系统会自动放进一个可运行的默认游戏骨架,于是"新建一个文件夹 → 立刻让 agent 在里面干活"成了一条顺畅的路。The top bar gained a project switcher that opens into a file browser, so you can pick any directory on disk as your workspace — no longer forced to drop code into one built-in folder. Recently opened projects are remembered for one-click return. Choose an empty folder and a runnable default game scaffold is dropped in for you, so "make a new folder → have an agent start working in it" becomes one smooth path.

应用内版本号、更新日志与快捷键In-app version, changelog and shortcuts

状态栏现在显示当前版本号,并且会主动刷新——切回窗口就能看到自己跑的是不是最新。设置里多了"更新日志"一栏,在产品里就能翻看更新了什么;还多了"快捷键"一栏,配合一套全局快捷键,常用操作有据可查、随手可按。The status bar now shows the running version and refreshes on its own — switch back to the window and you can tell whether you're on the latest. Settings gained a "Changelog" section so you can read what changed without leaving the product, and a "Shortcuts" section backed by a set of global keyboard shortcuts, so common actions are discoverable and one keypress away.

引擎:纹理构建期烘焙 + 模型实例化Engine: build-time texture cooking + model instancing

引擎侧,图片纹理改为在构建期就烘焙好,运行时按句柄直接取用,加载更快也更稳;glTF 模型支持实例化绘制,同一个模型成片出现时开销大幅下降。底层还补齐了完整的运行外壳与游戏主循环,为更复杂的场景打底。On the engine side, image textures are now cooked at build time and fetched by handle at runtime — faster and more reliable loading; glTF models support instanced drawing, sharply cutting the cost when the same model appears many times over. A complete runtime shell and game loop also landed underneath, laying groundwork for heavier scenes.

顺手的小改进Small ergonomics

聊天里的文字现在可以正常选中复制,输入框补上了右键菜单——把日常会碰到的小别扭一并抹平。Text in chat can now be selected and copied as expected, and the composer gained a right-click menu — smoothing the small frictions you hit every day.
