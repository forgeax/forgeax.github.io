一键整理对话 + 上下文用量看得见One-tap compaction + a visible context gauge

长对话聊久了,模型能记住的"上下文"会越来越满,接近上限时表现会变差。这天加了 /compact 命令,一键把此前的来回压缩成精炼摘要、腾出空间继续聊,而且不占用一整轮对话。输入框里还多了一个上下文用量环,直观显示"还剩多少额度",快满了一眼就知道。配合斜杠命令的自动补全,打个 / 就能看到可用命令并快速选用。In a long conversation, the "context" the model can hold fills up, and performance degrades as it nears the limit. This day added a /compact command that compresses the prior back-and-forth into a concise summary in one tap, freeing room to keep going — without burning a whole conversation turn. The composer also gained a context-usage ring that shows at a glance how much budget is left, so you can see when it's getting full. With slash-command autocomplete, typing / surfaces the available commands for quick selection.

WebGPU 软件兜底:更多机器能跑起 3DA WebGPU software fallback: 3D runs on more machines

3D 渲染依赖现代显卡能力,在一些机器或环境里硬件加速不可用,过去就直接黑屏。现在加了一层软件兜底:当硬件路径拿不到时,自动切到软件实现把画面渲出来,虽然慢一些但至少能跑、能看。还补了更清楚的诊断提示,告诉你为什么没走上硬件加速(比如非安全来源)。覆盖的机器范围因此更广了。3D rendering depends on modern GPU capabilities, and on some machines or environments hardware acceleration isn't available — which used to mean a black screen. Now there's a software fallback: when the hardware path can't be obtained, it automatically switches to a software implementation to render the picture — slower, but at least it runs and you can see it. Clearer diagnostics were added too, telling you why the hardware path wasn't taken (for example, a non-secure origin). The range of machines that work just got wider.

新游戏从干净模板起步 + 2D 精灵图集动画New games start from a clean template + 2D sprite-sheet animation

新建一个游戏时,现在会从一份结构清晰、按正规架构组织的精简模板生成——开局就是一份能直接往上加东西的好底子,而不是一堆样板代码。引擎这边还补上了 2D 精灵图集动画:把一张图集里的多帧按序播放,角色和特效的 2D 动画有了现成做法。Creating a new game now generates from a clean, well-structured template organized along a proper architecture — you start with a solid base ready to build on, not a pile of boilerplate. On the engine side, 2D sprite-sheet animation landed: play multiple frames from a sheet in sequence, giving 2D character and effect animation a ready-made approach.
