后端推倒重盖——一套能"断电恢复"的多 agent 地基A rebuilt backend that survives a crash

后端运行时从地基重浇成一套更稳的多 agent 架构。关键变化有两点:一是每个 agent 自己写一本只追加的事件日志,即使进程崩了、机器断电,重新打开也能把事件完整回放、回到崩溃前的状态——长任务终于经得起意外;二是 agent 列表改成直接盯着磁盘上的文件变化,不再依赖一份容易写歪的索引,状态更不容易跑偏。重写的同时,一大批历史包袱被整片清走,为后续能力让出空间。The backend runtime was re-poured into a sturdier multi-agent architecture. Two changes matter most: each agent now writes its own append-only event log, so even if the process crashes or the machine loses power, reopening replays every event and restores the pre-crash state — long tasks finally hold up against accidents. And the agent list now watches files on disk directly instead of leaning on an index that could drift, so state stays consistent. The rewrite also cleared out a large pile of legacy baggage to make room for what's next.

引擎第一次"点灯"——物理光照 + 投光体 + 带图的物体The engine's first real lighting

引擎渲染从一片清屏推进到了能看见真实光影。第一束基于物理的光照亮了起来,材质会按物理规律对光做出反应;紧接着补上了点光源与聚光灯,并带正确的距离衰减——离灯越远越暗,合乎直觉。色调映射也接上了,强光不再一片过曝惨白。再加上一个贴着纹理、正反面与朝向都修正过的立方体端到端跑通,从今天起引擎能把一个被多盏灯照亮、贴着图的正确物体渲染出来。Engine rendering moved from a blank cleared screen to visible, believable light. The first physically-based light switched on, with materials responding to it by physical rules; then came point lights and spotlights with correct distance falloff — farther from the light is darker, as you'd expect. Tone mapping landed too, so bright highlights no longer blow out to flat white. Add a textured cube rendered end-to-end with its faces and winding corrected, and from today the engine can render a properly lit, textured object under several lights.
