编辑器模式收官Editor mode, complete

一天之内把编辑器模式所有可实施项推完——它现在像一个真正的编辑器。Every implementable piece of editor mode landed in a single day — it now feels like a real editor.

编辑器现在像个真编辑器:面板能拖、能弹、能分组It feels like a real editor — panels dock, float, and group

接入一套可停靠面板系统:面板可以拖到任意区域、弹成独立窗口、多个标签分组(拖入成组 / 点击切换),还能一键重置回默认布局。Material / Timeline / MaterialGraph 三个新面板首次亮相,Inspector 与场景树也一并接入。A dockable-panel system landed: drag panels anywhere, pop them into separate windows, group tabs (drag-to-group / click-to-switch), and reset to the default layout in one click. Three new panels — Material / Timeline / MaterialGraph — debut alongside the Inspector and Scene Tree.

视口手柄补齐:移动 / 旋转 / 缩放Full viewport gizmos — move / rotate / scale

此前只有移动手柄,今天补上旋转与缩放,并加上 W / E / R 模式快捷键(业界通行约定)。拖动手柄时 Inspector 实时跟随更新,F 键 / 双击可让相机一键聚焦到选中对象;同时上线 History 与 Capabilities 两个面板。Previously translate-only; rotate and scale are now in, with W / E / R mode shortcuts (the standard DCC convention). The Inspector live-updates as you drag a handle, F / double-click frames the camera onto the selection, and two new panels — History and Capabilities — go live.

视口能直接看出网格的拓扑类型The viewport can show a mesh's topology

5 种基本拓扑(point / line-list / line-strip / triangle-list / triangle-strip)现在都能在视口里画出来。调资产、定位坏几何时更直观,不用再靠猜。All five primitive topologies (point / line-list / line-strip / triangle-list / triangle-strip) now render in the viewport — making it far easier to inspect assets and spot bad geometry instead of guessing.
