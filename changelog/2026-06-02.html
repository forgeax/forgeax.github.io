一条命令开桌面应用 + 节点编辑器进商店One command to launch the desktop app + a node editor joins

一条命令拉起整个桌面 Studio;可视化节点编辑器作为插件接入、插件之间互不串台;聊天更顺手,预览加了加载看门狗。One command launches the whole desktop Studio; a visual node editor joins as a plugin with plugins isolated from one another; chat got smoother, and the preview gained a load watchdog.

一条命令就能开桌面应用One command to open the desktop app

桌面端有了一键启动器:一条命令就能起开发态、打包、直接开应用、或一键收摊,配套文档把三种运行方式(网页开发态 / 桌面开发态 / 打包后的桌面应用)讲清楚。以前要记一串命令分别拉起各个服务,现在普通人一句话就能把整个桌面 Studio 跑起来。底层还改成"进程组"方式启停——退出时整组一起清理,关窗不再留下一堆僵尸进程拖慢机器。The desktop side gained a one-command launcher: a single command starts dev mode, builds a package, opens the app directly, or shuts everything down, with docs explaining the three ways to run (web dev / desktop dev / packaged desktop app). Where you used to memorize a string of commands to start each service separately, now one line brings up the whole desktop Studio. Underneath, start/stop moved to "process groups" — on exit the whole group is cleaned up together, so closing the window no longer leaves a pile of zombie processes bogging down the machine.

节点编辑器接进商店,插件互不串台A node editor joins, with plugins kept isolated

插件的启动方式从一堆写死的逻辑改成"按清单自动发现"——任何带清单的独立插件都能被自动识别、拉起。借这套机制,一个可视化节点编辑器整体作为插件接入(自带 3D 低多边形与场景生成两个工作台)。每个插件还拿到了自己独立的工程根目录,工作台之间不再共享同一个工程、互相串台;开发时插件默认开热更新,改代码即时生效。第三方工具接进来,从此既干净又即插即用。Plugin startup moved from a pile of hardcoded logic to "auto-discovery by manifest" — any standalone plugin with a manifest is automatically recognized and launched. Using this, a whole visual node editor joined as a plugin (bringing a 3D low-poly and a scene-generator workbench). Each plugin also got its own isolated project root, so workbenches no longer share one project and step on each other; in development, plugins default to hot reload so code changes take effect at once. Bringing third-party tools in is now both clean and plug-and-play.

聊天更顺手 + 预览加载看门狗Smoother chat + a preview load watchdog

对话面板加了一组好用的交互:随手切换模型、按段回看历史、顶栏的新动作入口,以及一个上下文用量环。预览也加了"初次加载看门狗"——如果首帧迟迟没出来,会自动重载直到画面真正渲染出来,不再卡在白屏干等。后端也修了几处聊天卡死、并让对话真正尊重你选的模型。整体用起来更跟手、更可靠。The conversation panel gained a set of handy interactions: switch models on the fly, replay history in segments, new action entries in the top bar, and a context-usage ring. The preview also got an "initial-load watchdog" — if the first frame is slow to appear, it auto-reloads until the picture actually renders, instead of stalling on a white screen. The backend fixed a few chat hangs too, and made conversations genuinely honor the model you pick. The whole thing feels more responsive and more reliable.
