桌面 App 硬化日:游戏不再卡 LoadingDesktop hardening: games no longer stuck on Loading

桌面应用从"能打开"逼到"打开就能用":场景兜底点亮、开关窗口与重置不再冻死、占位插件优雅隐藏。The desktop app pushed from "opens" to "opens and works": fallback lighting, window open/close and reset that no longer freeze, and placeholder plugins that hide gracefully.

桌面 App 里游戏不再卡在 "Loading game",场景终于亮了Games no longer stuck on "Loading game" in the desktop app

之前在打包后的桌面应用里点"试玩",画面常常一直黑、卡死在 "Loading game"。根因是桌面应用所用的系统网页引擎不支持基于环境的天光,场景连一盏环境光都加载不出来就死锁了。这天给场景做了兜底:相机加上天空底色,再加一盏纯色的兜底环境光把物体照亮,即使没有高级天光也能正常显示;并让所有样例游戏在这种环境下自动跳过加载不了的天光。现在这些游戏在桌面应用里都能正常进入、看得见画面。相关的底层缺口也整理成清单提交给了引擎团队。Previously, hitting "play" in the packaged desktop app often left the screen black, stuck on "Loading game." The root cause: the system web engine the desktop app uses doesn't support image-based sky lighting, so a scene deadlocked before it could even load one ambient light. This day added fallbacks: the camera got a sky base color, plus a solid-color fallback ambient light to illuminate objects, so scenes display even without advanced sky lighting; and all sample games now automatically skip the unloadable sky light in that environment. These games now enter and render properly in the desktop app. The underlying gaps were also compiled into a list and filed with the engine team.

开关窗口、重置都不再冻死:桌面可靠性硬化Opening, closing and resetting no longer freeze: desktop reliability hardening

桌面应用现在自己接管整套后端的生命周期:开窗时干净重启、关窗时彻底拆除,不再留下游离进程。一批"重置之后就炸"的坑被填平——清空会话 / 重置游戏改成异步、有界地删除,不再把界面冻住、也不再连带把窗口杀掉,重置完窗口和设置都能优雅恢复。后台还立了一套看护机制:自动看护并重启边车进程、退出时回收、健康门控,以及顶层的异常兜底与心跳防泄漏。长时间挂着用,桌面应用稳了一大截。The desktop app now owns the whole backend lifecycle itself: a clean restart on open and a full teardown on close, leaving no stray processes. A batch of "reset and it blows up" pitfalls were fixed — clearing sessions / resetting games became asynchronous and bounded, no longer freezing the interface or taking the window down with it, and the window and settings recover gracefully afterward. A supervision system was added in the background too: it watches and restarts side processes, reaps them on exit, gates on health, plus a top-level exception backstop and a leak-proof heartbeat. Left running for long stretches, the desktop app got markedly steadier.

占位插件优雅隐藏 + 状态栏日志面板 + 新增音频库工作台Placeholder plugins hide gracefully + a status-bar log panel + a new audio workbench

几个还没实现的占位工作台插件被统一隐藏,不再以"点了就 404"的死链暴露出来——所有工作台插件进入"实现了才出现"的优雅降级,并修了开发环境下插件损坏 / 缺失的自愈(这正是 404 的根因)。界面上新增了一条专业工具风格的状态栏:右侧有健康指示、可停靠的信息日志面板(点击即可复制、重复条目自动折叠),以及控制台 / 网络面板的接线,出问题时一眼能看到。另外还新增了一个音频库工作台:内置音乐与音效库,并接入了语音与音乐的合成能力,做游戏配乐和音效更顺手。Several unimplemented placeholder workbench plugins were uniformly hidden, no longer exposed as "click and get a 404" dead links — all workbench plugins entered "appears only once implemented" graceful degradation, and self-healing was added for broken or missing plugin builds in development (the very cause of the 404s). The interface gained a professional-tool-style status bar: a health indicator on the right, a dockable info-log panel (click to copy, repeated entries auto-fold), and console/network panels wired in, so problems are visible at a glance. A new audio-library workbench was also added: a built-in music and sound-effect library plus speech and music synthesis, making game scoring and sound effects easier.
