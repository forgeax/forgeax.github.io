桌面 App 立起来 + 多游戏共用一个游戏库A desktop app arrives + a shared game library

Studio 第一次能作为原生桌面应用打开;多个游戏可以共用一个游戏库;agent 能在对话里直接调宿主工具,引擎还加上了音频。Studio can now open as a native desktop app; multiple games can share one library; agents can call host tools directly in conversation, and the engine gained audio.

桌面 App 立起来:关掉浏览器也能用A desktop app: usable without a browser

这天把桌面应用的整套外壳立了起来:Studio 第一次能作为一个原生桌面窗口打开,而不只是浏览器里的一个标签页。配套做了进程保活与窗口管理,以及桌面打包时的资产寻址。意义在于——之前所有东西都跑在浏览器标签里、关掉就断;现在有了原生窗口 + 后台保活,你可以真正把它当一个"应用"长开着,关掉前台界面 agent 也照常在后台干活。This day stood up the full shell for a desktop app: Studio can open as a native desktop window for the first time, not just a browser tab. It came with process keep-alive and window management, plus asset resolution for desktop packaging. Why it matters — everything used to run in a browser tab and die when you closed it; now, with a native window and background keep-alive, you can genuinely keep it open as an "app," and agents keep working in the background even when the front-end window is closed.

多个游戏共用一个游戏库Multiple games share one library

多个游戏现在可以共用同一个游戏库:公共的资产、组件放在共享库里,各个游戏再带自己的索引去引用——不必每个游戏都把素材复制一份,系列作或多个原型之间能干净地复用。开发时,某个游戏的资产变动只会重扫"当前在做的那个游戏",改一个游戏不会拖慢整个工作区的扫描。Multiple games can now share one game library: common assets and components live in the shared library, and each game carries its own index to reference them — no need to copy materials into every game, so a series or several prototypes can cleanly reuse them. During development, an asset change in one game only rescans the game you're currently working on, so editing one game doesn't slow the whole workspace's scan.

agent 能在对话里直接调用宿主工具Agents can call host tools directly in conversation

打通了一条"白名单"通道:一个 agent 可以在自己的清单里声明它被允许调用哪些宿主工具,系统就把这些工具注入到它的对话工具列表里。于是负责剧情的 agent 直接在聊天里就能调用一整套细粒度的叙事工具来编排故事,不用再绕一个专门的工具包。授权清楚、调用直接——能力扩展更顺,也更可控。A "whitelist" channel was wired through: an agent can declare in its manifest which host tools it's allowed to call, and the system injects those tools into its conversation tool list. So the agent responsible for story can call a whole set of fine-grained narrative tools right in chat to arrange the plot, without routing through a separate tool kit. Authorization is explicit and the call is direct — extending capability is smoother and more controllable.

引擎:多通道渲染管线 + 音频 + 可切换抗锯齿Engine: a multi-pass render pipeline + audio + toggleable anti-aliasing

引擎渲染抽象升级成多通道(multi-pass)管线,后期处理这类"分几步叠加"的效果有了正规的搭建方式;抗锯齿现在能运行时开关,方便直接对比开与关的画面差别。引擎还第一次有了音频支持——游戏终于能出声了。物理的一个空转问题也修好了,之前会"冻住"的物体现在能正常受力运动。The engine's rendering abstraction grew into a multi-pass pipeline, giving "stack it up in steps" effects like post-processing a proper way to be built; anti-aliasing can now be toggled at runtime, making it easy to compare on versus off directly. The engine also got audio support for the first time — games can finally make sound. A physics idle bug was fixed too, so objects that used to "freeze" now move under forces as expected.
