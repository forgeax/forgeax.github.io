每个 agent 有了会动的头像 + 工程数据有了唯一真源Animated agent avatars + one source of truth for project data

每个 agent 有了随状态切换的动态头像;游戏工程数据收敛到唯一真源;几个渲染 bug 全修、全部样例迁到统一引擎。Each agent gets an animated avatar that shifts with its state; game-project data converges to one source of truth; rendering bugs are fixed and all samples move onto a unified engine.

每个 agent 有了会动的头像Each agent gets an animated avatar

工作台里每个 agent 不再是一张静态图片,而是一段会随状态切换的动态头像:思考、工作、空闲各有不同的动画表现。这是四个部分联动完成的——一批角色头像包、工作台里的动态头像渲染、后端的状态机驱动,以及对应的接口。多 agent 同时干活时,你扫一眼头像就能感受到"一屋子人各忙各的"的临场感,谁在动脑、谁在跑活、谁闲着,一目了然。它让"和一群 AI 协作"这件事第一次有了画面上的温度。Each agent in the workbench is no longer a static image but an animated avatar that shifts with its state: thinking, working and idle each have a different animation. This came together across four parts — a set of character avatar packs, animated avatar rendering in the workbench, a backend state machine driving it, and the matching interface. With several agents working at once, a glance at the avatars conveys the "a room full of people each busy at their own task" feeling — who's deliberating, who's running a job, who's idle — at a glance. It gives "collaborating with a team of AIs" a visual warmth for the first time.

游戏工程数据有了唯一真源Game-project data gets a single source of truth

每个游戏的工程配置文件(forge.json)此前是各个部分各自去读、各自解析、各自兜底,字段一漂谁也察觉不到。这天把它收敛成"唯一真源":整个平台读写工程数据都走同一个统一入口,格式也用一份机器可校验的规范自我说明,顺势换了更清晰的新格式(带版本号、用稳定标识引用资源)。结果是工程文件更可靠、跨各处一致,出问题也能在一处定位——相当于给整个工作台的"项目文件"立了一份权威说明书。Each game's project configuration file (forge.json) used to be read, parsed and error-handled separately by each part, so a drifting field went unnoticed. This day converged it into a "single source of truth": the whole platform reads and writes project data through one unified entry, and the format describes itself with a machine-validatable spec, taking the chance to adopt a cleaner new format (with a version number and stable identifiers for referencing resources). The result is project files that are more reliable, consistent everywhere, and diagnosable in one place — effectively an authoritative manual for the workbench's "project file."

几个渲染 bug 全修 + 全部样例迁到统一引擎Several rendering bugs fixed + all samples on a unified engine

随着工程数据统一,整个平台彻底站到了同一套引擎主线上——本地的旧副本全部拔掉。借这次集成,几个真实游戏暴露出来的引擎问题一次修干净:大场景阴影、某类数据写入、资源标识撞车、纯色环境光,四个都已确认修复。编辑器和全部六个样例游戏也一并迁到了新的引擎接口。统一之后,各处行为一致、问题更好追,后续新特性也能一次实现、处处生效。With project data unified, the whole platform now stands firmly on one engine mainline — the old local copies were all removed. Through this integration, several engine issues surfaced by real games were cleared at once: large-scene shadows, a class of data writes, resource-identifier collisions, and solid-color ambient light — all four confirmed fixed. The editor and all six sample games were migrated to the new engine interface too. Unified, behavior is consistent everywhere, problems are easier to trace, and new features can be built once and take effect across the board.
