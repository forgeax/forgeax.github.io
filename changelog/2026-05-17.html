聊天里就地预览 3D 模型与图片Inline 3D model & image previews

聊天现在能就地渲染附件:贴一张图片直接出缩略图,丢一个 .glb 模型会渲染成一个可看的 3D 预览,不用先把它塞进游戏里跑一遍。讨论某个角色、某张贴图时,大家看到的是同一个东西——"这块石头长这样吗"当场就能确认。预览区也清掉了多余留白,内容铺得更满。Chat now renders attachments in place: paste an image and you get a thumbnail; drop a .glb model and it renders as a viewable 3D preview — no need to wire it into a running game first. When you discuss a character or a texture, everyone is looking at the same thing, so "is this what the rock looks like?" gets answered on the spot. The preview area also dropped its excess padding so content fills the frame.

用 @ 提及把 agent 与资源做成引用胶囊@-mention agents and resources as pills

在输入框里打 @ 就能提及一个 agent 或一份资源,它会变成一枚 pill——可悬停看说明、记得你最近用过哪些、插入后还能点回去。需要点名让某个 agent 接手,或把一份素材带进对话,不用再复制长长的名字或路径。配套的右键菜单让在输入框里的常用操作触手可及。Type @ in the composer to mention an agent or a resource and it becomes a pill — hover for a tooltip, it remembers what you used recently, and once inserted you can click back to it. Handing a task to a specific agent, or pulling a piece of material into the conversation, no longer means copying long names or paths. A companion right-click menu puts the common composer actions within reach.

直接 @ 一个 agent 跟它对话@ an agent to talk to it directly

多 agent 协作更进一步:你可以在对话里直接 @ 某个 agent,让它接住这条消息并回复,而不是只能跟主控聊。配合可视化的 agent 总线面板(键盘上下导航、各处一键深链到对应记录),谁在做什么、该找谁,都更顺手。Multi-agent collaboration went a step further: you can @ a specific agent inside the conversation so it picks up that message and replies, instead of only talking to the lead. Together with the visible agent-bus panel (keyboard up/down navigation and one-click deep-links to the matching record), it's clearer who's doing what and who to address.
