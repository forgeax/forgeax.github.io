编辑器一波大整合:右键菜单、引用投入对话、Blender 式视口A big editor integration: context menu, reference-to-chat, Blender-style viewport

编辑器一次性补齐了一批让它"顺手"的交互。统一的右键菜单让常用操作随处可达;选中的对象可以一键"引用投入对话",让 agent 精确知道你在说哪个;多个工作区用标签页切换;视口的移动/旋转/缩放手柄与相机操作采用了大家熟悉的专业 3D 软件那一套手感,上手几乎零成本;画布上还加了错误浮层,出问题时直接在画面里提示而不是闷在控制台里。编辑器从"能用"往"好用、专业"迈了一大步。The editor filled in a batch of interactions that make it feel natural, all at once. A unified right-click menu puts common actions within reach everywhere; a selected object can be "referenced into chat" in one click, so the agent knows exactly which one you mean; multiple workspaces switch via tabs; and the viewport's move/rotate/scale handles and camera controls adopt the feel of the professional 3D software everyone already knows, so there's almost no learning curve. An error overlay was added on the canvas too, surfacing problems right in the view instead of burying them in a console. The editor took a big step from "usable" toward "pleasant and professional."

模型在编辑和试玩里都能带材质实时渲染Models render live with textures, in edit and play alike

导入的 3D 模型现在能在运行时带材质正确渲染——纹理、多级纹理细节(远处不再闪烁)、双面材质都到位;再配上基于环境的天光,模型在场景里看起来真实、有质感。更关键的是编辑态与试玩态保持一致:你在编辑器里看到的样子,就是玩起来的样子,所见即所得不再打折扣。示例射击游戏已经切到这条运行时渲染链路,编辑与试玩画面对齐。Imported 3D models now render correctly with materials at runtime — textures, mipmaps (no more shimmer in the distance) and double-sided materials are all in place; combined with image-based sky light, models look real and tactile in a scene. Crucially, edit and play stay consistent: what you see in the editor is what you get when you play, so what-you-see-is-what-you-get no longer comes with a discount. The sample shooter already moved to this runtime rendering path, with its edit and play views aligned.

动画工坊统一界面 + 抠图与标注新工具A unified animation workbench + cutout and annotation tools

动画相关的工具之前各自一套界面,图标、按钮层级、侧栏、提示风格都不一致。这天把它们一口气标准化到同一套设计:统一的图标库、清晰的按钮主次、一致的侧栏布局与提示样式、统一的完成态配色。骨骼动画管线还新增了候选选择、自动抠背景、标注模式等实用能力。对不写代码的同事来说,整个产品第一次看起来"是同一个东西"。The animation-related tools each had their own interface before — icons, button hierarchy, sidebars and toast styles all inconsistent. This day standardized them onto one design in a single pass: a unified icon set, clear button hierarchy, consistent sidebar layout and toast style, and unified completion-state colors. The skeletal-animation pipeline also gained practical abilities like candidate selection, automatic background removal and an annotation mode. For non-coding teammates, the whole product looks like "one thing" for the first time.
