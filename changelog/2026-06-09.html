游戏"验车线":构建跑不过,AI 不许说做完A game build-gate: no "done" until it actually compiles

以前 AI 在这里"造游戏"常有个毛病:改完代码就宣布"完成",结果一打开是黑屏、甚至根本编译不过。这天给游戏装了一条"验车线":后端会先跑一遍构建预检,并写死一条铁律——必须构建通过,AI 才被允许宣布做完。更关键的是,构建报错的具体内容会被实时喂回给 AI,让它照着真实的错误去改,而不是丢一句"已完成"糊弄过去。顺手还修掉了新建游戏时画面闪烁的问题。结果就是:它说"做好了",就更可信是真做好了。The AI building games here used to have a flaw: it would declare "done" after editing code, only for the result to be a black screen — or to not compile at all. This day added a build-gate: the backend runs a build preflight first, with a hard rule baked in — the AI may only declare done once the build passes. Crucially, the specific build errors are fed back to the AI in real time so it fixes against the actual error, instead of papering over it with "completed." A new-game screen-flicker bug was fixed along the way. The result: when it says "it's done," that's far more likely to be true.

引擎一日大推进:多材质模型 + 更多灯光 + 更大场景A big engine day: multi-material models + more lights + bigger scenes

引擎单日推进很猛。模型支持"多个子网格、各挂各的材质槽"——带多种材质的复杂模型(比如一个角色身上金属、布料、皮肤各不相同)终于能正确分材质渲染。灯光走向"集群光照"管线,同一场景里能容纳更多灯而不崩。底层把渲染缓冲改成按需翻倍扩容,解除了原来约一千个对象的上限,大场景能塞下更多东西。游戏入口的写法也重新分成更直觉的三层,AI 写起游戏来更顺手。新建游戏的默认模板自带 HDR 天空和一个可操控的角色。The engine pushed hard in a day. Models now support "multiple sub-meshes, each with its own material slot" — complex models with several materials (a character whose metal, cloth and skin all differ) finally render with the right material on each part. Lighting moved to a clustered pipeline, fitting more lights in one scene without breaking. Underneath, render buffers grow on demand by doubling, lifting the old roughly thousand-object cap so large scenes can hold much more. The way a game's entry point is written was also re-split into a more intuitive three layers, so the AI writes games more smoothly. The default new-game template now ships with an HDR sky and a controllable character.

编辑器显示真实几何 + 更稳的回放The editor shows real geometry + steadier replay

编辑器更"所见即所得":现在会预加载模型文件,编辑视图里直接显示真实几何,而不是一个占位方块。底层资产管线切到了引擎原生的场景包格式,编辑态也带上 HDR 天空。出错时,画面上的错误浮层会展开更详细的内层原因,方便定位。聊天回放也修了跨 agent 卡片的交错顺序,恢复历史时多个 agent 的发言能正确穿插,和当时实时看到的一致。The editor is more what-you-see-is-what-you-get: it now preloads model files so the edit view shows real geometry rather than a placeholder box. The underlying asset pipeline moved to the engine's native scene-pack format, and the edit view carries an HDR sky too. On error, the on-canvas overlay expands the more detailed underlying cause for easier diagnosis. Chat replay also fixed the interleaving order of cross-agent cards, so restoring history weaves multiple agents' messages together correctly, matching what you saw live.
