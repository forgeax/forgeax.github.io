危险操作先确认 + 引擎环境光与阴影Confirm before risky actions + engine ambient light & shadows

agent 执行高风险操作前会先弹窗征求同意;引擎补上基于环境的天光与阴影;插件还能在 app 里直接编辑、可签名建立信任。Agents now ask before running risky actions; the engine gains image-based ambient light and shadows; plugins can be edited in-app and signed for trust.

危险操作前会弹窗确认A confirmation prompt before risky actions

agent 在调用工具时多了一道安全闸:每个工具可以声明"总是确认 / 从不确认 / 仅危险操作确认"。当 agent 要执行一个被判定为危险的动作时,界面顶部会实时弹出确认条,你点了"允许"才放行,点"拒绝"就拦下——决定也会记进日志。从此不会再出现"agent 在后台悄悄把事做了,人却不知道"的情况。Agents gained a safety gate when calling tools: each tool can declare "always confirm / never confirm / confirm only when dangerous." When an agent is about to take an action judged risky, a confirmation bar pops up at the top of the interface in real time — it proceeds only if you allow, and is blocked if you deny, with the decision recorded to the log. No more "the agent quietly did something in the background and you never knew."

引擎:基于环境的天光 + 阴影 + 复杂大场景Engine: image-based ambient light + shadows + large scenes

引擎的光照再上一个台阶:加入了基于环境的天光,物体会被周围环境的光柔和地照亮、暗部不再死黑,质感一下子真实许多;配合此前的阴影,明暗关系更完整。同时引擎能把一个复杂的大型室内场景完整加载并渲染出来——这是检验渲染器实战能力的硬指标,意味着它已经不只是能转个方块,而是扛得住真正的游戏级场景。The engine's lighting took another step up: image-based ambient light was added, so objects are softly lit by their surroundings and shadowed areas no longer go dead black, making materials look far more believable; together with the existing shadows, the light-and-dark relationship is more complete. The engine can now also load and render a large, complex indoor scene in full — a hard benchmark for a renderer's real-world readiness, meaning it's no longer just spinning a cube but holding up under a genuine game-scale scene.

在 app 里直接编辑插件Edit plugins right in the app

新增一个"插件作者"工作台:左边是文件树,右边是编辑器,改完即时生效。想给某个工具调一调提示词、改一个参数,不用再退出去翻代码——在产品里就能改插件、立刻看到效果,二次开发的门槛进一步降低。A new "plugin author" workbench arrived: a file tree on the left, an editor on the right, changes taking effect immediately. To tweak a tool's prompt or adjust a parameter, you no longer have to leave and dig through code — you can edit a plugin inside the product and see the effect at once, lowering the bar for extending it further.

插件可签名、验签、建立信任名单Plugins can be signed, verified and trusted

为了让分享插件更安全,插件包导出时会做数字签名,导入时自动验签;系统维护一份信任名单,记录哪些来源可信。一旦某个签名被吊销,再全新安装该来源的插件会被直接拦下。装别人做的插件,从此心里更有底。To make sharing plugins safer, a plugin package is digitally signed on export and verified on import; the system keeps a trust list of which sources are trusted. Once a signature is revoked, a fresh install from that source is blocked outright. Installing someone else's plugin now comes with more peace of mind.
