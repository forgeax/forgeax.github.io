整个界面能切中英文 + 开发者工具齐活Full bilingual UI + complete devtools panels

整个工作室界面实现中英双语、可一键切换;开发者工具的控制台 / 网络 / 日志面板补齐;引擎方向光阴影修对。The whole studio interface goes bilingual with one-click switching; the Console / Network / log devtools panels are completed; and directional-light shadows are fixed.

整个界面能一键切中英文Switch the whole interface between English and Chinese in one click

这天做了一次彻底的国际化:先搭起一套轻量的多语言内核(以英文为基准、中文作为覆盖层、随时可切),然后把整个界面逐文件迁移——顶栏、仪表盘、聊天面板、设置抽屉、侧边栏、各种切换器、几十个面板组件全部接入。默认英文、自动跟随系统语言,还做了跨窗口实时同步:在一个窗口里切换语言,另一个窗口立刻跟着变。编辑器也同步完成了全量国际化。顺手还修了几处界面老毛病:原生表单控件之前是黑字看不清、现在用可读的主题色;弹窗与下拉的层级叠放也理顺了,不再盖错地方。This day did a thorough internationalization: first a lightweight multilingual core (English as the baseline, Chinese as an overlay, switchable anytime), then the whole interface migrated file by file — the top bar, dashboard, chat panel, settings drawer, sidebar, the various switchers and dozens of panel components all wired in. It defaults to English, follows the system language automatically, and syncs live across windows: switch the language in one window and another follows immediately. The editor completed full internationalization too. A few long-standing UI issues were fixed along the way: native form controls that used to show unreadable black text now use readable theme colors, and the stacking order of dialogs and dropdowns was straightened out so they no longer cover the wrong thing.

开发者工具面板齐活:控制台 + 网络 + 日志落盘Devtools panels completed: Console + Network + on-disk logs

开发者工具区之前有几个面板要么空着、要么是点不动的占位,这天一次补全。控制台面板接通了游戏与编辑器的完整输出流;网络面板从死占位变成真功能,能抓到正在试玩的游戏里的网络请求(普通请求、异步请求、长连接都行);控制台 / 网络 / 信息三条流还会镜像保存到本地日志文件,方便事后翻查;同时删掉了一个和监控台重复的页签。调试一个游戏时,终于能在面板里看到完整的控制台与网络情况,排错不再靠猜。The devtools area previously had panels that were either empty or unclickable placeholders; this day completed them. The Console panel wired up the full output streams of the game and editor; the Network panel went from dead placeholder to a real feature that captures network requests in the game you're play-testing (regular requests, async requests and long-lived connections alike); the console / network / info streams are also mirrored to local log files for later review; and a tab redundant with the monitoring view was removed. Debugging a game, you can finally see the full console and network picture in a panel, instead of guessing.

引擎方向光阴影修对 + ECS 系统声明式编排Directional shadows fixed + declarative system scheduling

引擎把困扰多日的方向光阴影问题修对了——多级联阴影在某些配置下失效、错位的根因一起收掉,上游一稳,下游游戏就不必再靠那种"把级联数从 4 改成 1"的临时绕法。同时游戏逻辑这层支持了"声明式系统编排":可以按条件、标签、状态来声明各个系统什么时候跑、怎么排序,游戏行为逻辑写起来更有条理。底层还加了一层故障隔离(把崩溃转成可恢复的错误并自动重试)和一个离线的渲染帧查看器,排查图形问题更顺手。The engine correctly fixed the directional-light shadow problem that had nagged for days — the root causes of cascaded shadows failing or misaligning under certain configurations were cleared together, so with the upstream stable, downstream games no longer need the stopgap of "changing the cascade count from 4 to 1." Game logic also gained "declarative system scheduling": you can declare by condition, label and state when each system runs and how it's ordered, making behavior logic more orderly to write. Underneath, a fault-isolation layer (turning a crash into a recoverable error with automatic retry) and an offline render-frame viewer were added for smoother graphics debugging.
