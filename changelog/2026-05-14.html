关窗 / 断网后,agent 不死Agents survive a closed window

以前关掉浏览器就等于结束任务;现在 agent 进程独立在后台运行,关窗或断网后重新打开能继续看输出,多个窗口 / 标签并发跑也不会串台。长任务终于可以放心挂着。Closing the browser used to kill the task; now agents run independently in the background — reopen after closing or dropping your network and you pick the output back up, and multiple windows / tabs run concurrently without crosstalk. Long tasks can finally be left running.
