把一个游戏打包成网站带走Package a game into a website you can take with you

这是面向"发布"的一大步:现在能把一个游戏整体导出成一个自包含的静态网站——不需要整套 Studio,把导出的文件夹丢到任意静态托管上就能跑起来。也就是说,你在这里聊出来的游戏,可以直接打包带走、分享给别人玩。配套还做了第一个被导出的样例 FPS 游戏 Sector Strike(自带场景与说明),并修掉了一个会让后端接口被前端路由抢走、导致内嵌页面打不开的问题。从"做出来"到"发出去",这条路通了。A big step toward shipping: you can now export a whole game as a self-contained static website — no full Studio needed, just drop the exported folder onto any static host and it runs. Which means the game you chat into being here can be packaged up, taken away, and shared for others to play. It came with a first exported sample — an FPS game, Sector Strike, with its own scene and readme — and a fix for a bug where the backend's routes were being captured by the front-end router, which had kept some embedded pages from opening. From "built it" to "shipped it," the path is now open.

天空盒 + Bloom 辉光,画面更有氛围Skybox + bloom for atmosphere

引擎这天出了两个一眼能看出来的画面特性:可见天空盒,让场景背景不再是一块纯色,而是真有天空环境;以及 Bloom 辉光,给亮部加上柔和的光晕溢出,霓虹、强光、发光体一下子有了氛围。底层还修通了层级世界变换——父子节点的位置、旋转、缩放现在能正确地传到渲染端,组合物体(比如带武器的角色、带零件的载具)摆放终于不再错位。The engine shipped two immediately visible features: a real skybox, so a scene's background is an actual sky environment instead of a flat color; and bloom, adding a soft glow spillover on bright areas, instantly giving neon, strong light and glowing objects atmosphere. Underneath, hierarchical world transforms were wired through — a parent and child's position, rotation and scale now reach the renderer correctly, so composite objects (a character with a weapon, a vehicle with parts) finally stop being misplaced.

互动叙事管线跑通完整闭环The interactive-narrative pipeline runs a full loop

面向影像叙事类游戏的剧情管线接成了端到端闭环。剧情树修好了一串问题——重号消歧、回边、长边绕行、启动即自动挂载可见,现在能正确地画出整棵故事结构;负责叙事的 agent 接上了整套管线工具,并会实时播报进度;最关键的是,整条管线跑完会自动唤回这个 agent 来做收尾总结,而不是停在半路。做一段有分支的剧情,从开始到收尾是一条顺畅、看得见的流水线。The story pipeline for narrative-driven games was wired into an end-to-end loop. The story tree got a string of fixes — de-duplicating repeated nodes, repairing back edges, routing long edges around, and auto-mounting so it's visible on start — so the whole story structure now draws correctly; the narrative agent connected to the full pipeline toolset and reports progress live; and crucially, when the pipeline finishes it automatically wakes that agent back up to do a closing summary, rather than stopping halfway. Building a branching story is now one smooth, visible flow from start to finish.
