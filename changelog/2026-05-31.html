The weightiest thing this day was filling in the "export" step: packaging a whole game into a website anyone can host and anyone can open. Meanwhile the engine added skybox and bloom for atmosphere, fixed loading under prefixed URLs for deployment flexibility, and ran the narrative pipeline into a loop. On one side "make it look better," on the other "take it away when done" — the day pushed both ends of creation: making you enjoy building, and giving your results somewhere to go.

一个游戏打包成网站带走Package a game into a website you can take with you

这是面向"发布"的一大步:现在能把一个游戏整体导出成一个自包含的静态网站——不需要带上整套 Studio,把导出的那个文件夹丢到任意一个静态托管上,它就能独立跑起来。换句话说,你在这里聊出来、做出来的游戏,可以直接打包带走、发给朋友玩、或者放到网上让所有人玩,而不被锁在这个工具里。配套出了第一个被导出的样例——一个名为 Sector Strike 的 FPS 游戏(自带场景与说明文档),用来跑通并验证整条导出链路。同时还修掉了一个关键 bug:之前后端的接口地址会被前端的路由规则错误地"抢走",导致某些内嵌页面打不开;修对之后,导出的成品能稳定地把前后端的请求各自送对地方。从"在工具里能玩"到"脱离工具也能玩",这条发布之路第一次真正打通。A big step toward shipping: you can now export a whole game as a self-contained static website — no need to bring the full Studio along; drop the exported folder onto any static host and it runs on its own. In other words, the game you chat into being and build here can be packaged up, sent to friends to play, or put online for everyone, instead of being locked inside this tool. A first exported sample came with it — an FPS game called Sector Strike (with its own scene and readme) — to run and validate the whole export chain. A key bug was also fixed: the backend's route addresses used to be wrongly "captured" by the front-end's routing rules, keeping some embedded pages from opening; once fixed, the exported product reliably routes front-end and backend requests each to the right place. From "playable inside the tool" to "playable outside it," the road to shipping is genuinely open for the first time.

天空盒 + Bloom 辉光,画面更有氛围Skybox + bloom: more atmosphere

引擎这天出了两个一眼就能看出来的画面特性。其一是可见天空盒:场景的背景不再是一块死板的纯色,而是真有一片天空环境包裹着整个场景,远处有天、有氛围,空间感立刻不一样了。其二是 Bloom 辉光:给画面里的亮部加上一层柔和的光晕溢出——霓虹灯、强光源、发光的物体周围会泛出光晕,这是营造科幻、梦幻、夜景氛围最常用的一招。这两样都是直接作用于观感的"氛围特效"。底层还修通了一件要紧事:层级世界变换。父子节点的位置、旋转、缩放现在能正确地一层层传到渲染端,意味着组合物体——比如握着武器的角色、装着零件的载具——的各个部分终于能正确地跟着主体一起摆放、移动,而不再各自错位。氛围 + 正确的层级,合起来让场景既好看又"摆得对"。The engine shipped two immediately visible features this day. One is a visible skybox: a scene's background is no longer a flat solid color but a real sky environment wrapping the whole scene, with sky and atmosphere in the distance — the sense of space changes at once. The other is bloom: a soft glow spillover on bright areas — neon signs, strong light sources and glowing objects bleed a halo — the most common move for sci-fi, dreamy or night-scene atmosphere. Both are "atmosphere effects" acting directly on look and feel. Underneath, an important thing was wired through: hierarchical world transforms. A parent and child's position, rotation and scale now propagate correctly layer by layer to the renderer, meaning the parts of a composite object — a character holding a weapon, a vehicle with attached parts — finally place and move correctly with the whole instead of being misaligned. Atmosphere plus correct hierarchy together make a scene both good-looking and "correctly arranged."

带前缀的预览也能正确加载资源Preview loads correctly under a URL prefix

这天还死磕了一条不显眼但很影响部署灵活性的链路:让预览在"带路径前缀"的地址下也能正确加载所有资源。很多真实的部署场景里,应用不是挂在网站根目录,而是挂在某个子路径下(比如某某网站下的一个子目录)——如果资源的地址没有把这个前缀算进去,加载就会找不到文件、报错。这天把从引擎到打包到资源索引的整条链路都对齐到"尊重路径前缀",并锁了回归测试防止它再次走歪;还顺手修了启动流程,确保所需的全套运行件都先正确构建好才启动。它解决的是"换个地方部署就加载失败"这类最让人头疼的环境问题。把这条链路打通,意味着导出的游戏、内嵌的预览,无论被放到什么样的网址路径下,都能稳定地把资源找对、跑起来——这正是上面"打包成网站带走"能真正可用的底层保障。This day also grappled with an unglamorous but deployment-flexibility-critical path: making the preview load all resources correctly under a "URL path prefix." In many real deployments, an app isn't at the website root but under some sub-path (a subdirectory of some site) — and if resource addresses don't account for that prefix, loading fails to find files and errors. This day aligned the whole chain, from engine to packaging to the resource index, to "respect the path prefix," and locked a regression test to keep it from going wrong again; it also fixed the startup flow to ensure the full set of needed runtime pieces is correctly built before launch. It addresses the most headache-inducing class of environment issue — "deploy it somewhere else and loading breaks." Getting this path working means exported games and embedded previews reliably find their resources and run no matter what URL path they're placed under — exactly the underlying guarantee that makes "package it into a website and take it" genuinely usable.

互动叙事管线跑通完整闭环The interactive-narrative pipeline runs a full loop

面向影像叙事类游戏的剧情管线这天接成了端到端闭环。剧情本质上是一棵会分支的"故事树",而把这棵树正确地画出来、跑起来,要解决一串棘手问题:重复编号的消歧、回头边的修复、跨度很长的连线如何绕行布置、以及启动时就自动挂载好让它一开始就可见——这些这天都修通了,整棵故事结构能正确呈现。负责叙事的那个 agent 也接上了整套管线工具,并会在跑的过程中实时播报进度。最关键的一处:整条管线跑完之后,系统会自动把这个 agent 重新唤回来做一段收尾总结,而不是跑到一半就停下、留个烂尾。这样一来,做一段有分支、有节奏的剧情,从开头到收尾就成了一条顺畅、看得见、会自己收口的流水线——叙事这条线从"有工具"真正走到了"能完整跑完一遍"。The story pipeline for narrative-driven games was wired into an end-to-end loop this day. A plot is essentially a branching "story tree," and drawing and running that tree correctly means solving a string of thorny problems: disambiguating repeated numbering, repairing back edges, routing long-span connections around, and auto-mounting on start so it's visible from the beginning — all fixed this day, so the whole story structure presents correctly. The agent responsible for narrative connected to the full pipeline toolset and reports progress live as it runs. The key piece: when the whole pipeline finishes, the system automatically wakes that agent back to do a closing summary, rather than stopping halfway and leaving a dangling end. With that, building a branching, well-paced plot becomes a smooth, visible, self-closing flow from start to finish — the narrative line moves from "has tools" to genuinely "can run all the way through once."

Before, however well-made, a game was still trapped in the tool; and "export as a website" plus "loads correctly under any path" together let your work genuinely leave here and reach others for the first time. With skybox and bloom making it better-looking and the narrative loop making it more complete, this day filled in the last link of the "create — take shape — ship" chain.
