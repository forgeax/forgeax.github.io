把 agent 总线搬进界面 + 仪表盘筛选The agent bus comes into the UI + dashboard filters

agent 之间的事件总线第一次有了可视化入口,仪表盘也能按状态筛选与搜索。The event bus between agents gets a visible surface, and the dashboard gains status filters and search.

可视化的 agent 总线A visible agent bus

agent 之间互相通信的事件总线接进了侧栏:能看到各类事件、用键盘导航、从某条记录一键深链到对应详情。多 agent 协作第一次变得"看得见"——谁在跟谁说话、传了什么,都摆在眼前。The event bus agents use to talk to each other is now in the sidebar: browse event kinds, navigate by keyboard, and deep-link from a record straight to its detail. For the first time, multi-agent collaboration is something you can watch — who is talking to whom, and what's being passed.

仪表盘更好用A more useful dashboard

运行列表加上状态分布条,任务列表支持按状态筛选与标题搜索——排查问题、回顾历史都更快。The runs list gained a status-distribution strip, and the task list now supports filtering by status and searching by title — quicker to triage problems and look back over history.
