角色真的动起来了 + 聊天更稳Characters actually animate + a steadier chat

带骨骼的角色现在能真正播放动画;聊天修掉内存泄漏、流式生成时也能继续打字;编辑器还能脱离主界面独立运行。Rigged characters now play their skeletal animation; chat fixes memory leaks and lets you keep typing during streaming; the editor can also run standalone.

角色真的动起来了:骨骼动画整条链跑通Characters actually move: the skeletal animation chain runs end to end

这是一个里程碑画面:一个带骨骼的角色模型,现在能真正播放它自带的动画——走、跑、跳的每一帧都由动画系统驱动骨骼、再带动网格变形,而不再是僵在原地的雕像。整条链路打通后,示例里能同时让多个角色一起做动作。配套的角色生成工作台也推进到能给生成出来的模型绑骨、加动作、出低模产线——"生成一个角色 → 让它动起来"这条路开始连成一条线。A milestone moment: a rigged character model can now genuinely play its built-in animation — every frame of walking, running and jumping is driven by the animation system moving the skeleton, which in turn deforms the mesh, rather than a statue frozen in place. With the chain complete, the samples can have several characters performing actions at once. The character-generation workbench also advanced to rigging generated models, adding motion and a low-poly production path — so "generate a character → make it move" starts to join into one continuous line.

聊天更稳更顺:修内存泄漏 + 流式时可输入 + 询问卡片A steadier, smoother chat: leak fixes + type-while-streaming + ask cards

聊天做了一轮稳定性与体验专项。内存泄漏被集中修掉:超长对话历史会限量、向上翻看分页加载、窗口缩放的监听器不再越积越多——挂着聊一整天也不会越用越卡。交互上,模型还在流式输出时你也能继续打字、把下一条排进队列直接发;agent 还能弹出一张"询问卡片"在需要时向你确认信息,而不是把问题埋在文字里。会话列表也按最近活跃排序、显示相对时间,找回刚才那个对话更快。Chat got a round of stability and experience work. Memory leaks were fixed in a focused pass: very long conversation history is now capped, scrolling up pages in more, and window-resize listeners no longer pile up — so keeping it open and chatting all day won't slowly bog down. Interaction-wise, you can keep typing while the model is still streaming and queue the next message to send right away; an agent can also pop up an "ask card" to confirm information with you when needed, instead of burying the question in text. The session list now sorts by recent activity and shows relative times, making it quicker to find the conversation you just had.

编辑器能独立运行 + 跨界面消息严格校验The editor can run standalone + strictly validated cross-surface messages

前端外壳被抽成一套可复用的应用框架,带几个公开接口,于是编辑器可以脱离主界面、作为独立应用单独挂载运行。这让编辑器更模块化,也更容易被嵌入或单独打开。底层还把界面各部分之间(以及跨内嵌页面)的消息全部加上了双侧严格校验:每条消息都按既定结构核对,格式不对就不放行,跨界面的状态同步因此更可靠、更不容易出现"对不上"的诡异问题。The front-end shell was extracted into a reusable application framework with a few public interfaces, so the editor can detach from the main interface and mount and run as a standalone app. That makes the editor more modular and easier to embed or open on its own. Underneath, messages between parts of the interface (and across embedded pages) now all carry strict two-sided validation: each message is checked against a defined structure and rejected if malformed, making cross-surface state sync more reliable and far less prone to weird "they don't agree" issues.
