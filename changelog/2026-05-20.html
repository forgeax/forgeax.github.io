聊天接回新后端,会话管理更顺Chat reconnects to the new backend, with cleaner sessions

前一天重浇的后端地基,这天和聊天界面接上了。新建会话有了统一入口,切换会话会自动打开对应的标签页,删除也一步到位;重新打开一个会话能完整回放此前的来回。聊天里还区分出"来信 / 出信 / 警告 / 报错"几类系统行,过程看得更清楚——出问题时一眼能看到是哪一步、哪一类。The backend re-poured the day before connected to the chat UI today. Creating a session now has one consistent entry point, switching a session automatically opens its tab, and deleting is one step; reopening a session replays the full back-and-forth. Chat also distinguishes system lines — incoming / outgoing / warning / error — so the flow reads more clearly, and when something breaks you can see at a glance which step and what kind.

在设置里直接管模型与密钥Manage models and keys right in settings

模型选择器现在读取真实的可用模型清单,选的就是会真正生效的那个;每个 agent 用哪个模型也能分别设定。密钥输入也搬进了常驻的设置面板,带一个"眼睛"按钮可以显示或隐藏内容——填 key、换模型不用再去命令行或改配置文件。The model picker now reads the real list of available models, so what you choose is what actually takes effect, and you can set which model each agent uses. Key entry moved into a persistent settings panel with an eye toggle to show or hide the value — filling in a key or switching models no longer means dropping to the command line or editing a config file.

引擎:多光源与贴图光照 + 相机漫游Engine: multi-light & textured lighting + camera roaming

引擎的光照能力继续补齐:支持贴图驱动的光照(用纹理控制物体不同部位的反光强弱)、多盏灯同时照亮同一个场景,以及点光 / 聚光等不同投光体的组合。第一人称相机的 WASD 漫游也修好了,可以在场景里自由走动观察——离能"搭一个能逛的 3D 场景"更近了一步。The engine's lighting capabilities kept filling in: texture-driven lighting (using a texture to control how strongly different parts of a surface reflect), multiple lights illuminating one scene at once, and combinations of light casters such as point and spot lights. First-person WASD camera roaming was fixed, so you can walk around and inspect a scene — a step closer to "build a 3D scene you can actually wander through."
