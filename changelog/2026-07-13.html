Daily2026-07-13

Faster project startup, stronger Play mode, and smoother onboarding

Today’s updates make heavy projects feel more responsive, improve runtime simulation and asset loading in Play, and make the first project setup easier to follow.

Faster startup for heavy projects

  • The Studio shell stays responsive while large game assets are scanned and loaded.
  • The viewport now shows clearer loading progress instead of appearing frozen.
  • Project and game onboarding cards guide the connection flow more clearly, including support for short one-character game names.
  • The model picker now exposes catalog metadata and improves request-path performance.

Stronger Play mode and asset workflows

  • Physics simulation is now more reliable in Play, including character movement and trigger sensor collision reporting.
  • Audio systems and AudioSource playback are wired into Play mode.
  • Cross-origin asset fetches and import hot-reload paths are more reliable.
  • Native OS folder picking is available for file-based workflows.

Engine and game fixes

  • Raycasts now return the entity that was actually struck.
  • Hellforge’s Belfast sunset sky is darker and no longer shows ash artifacts.
