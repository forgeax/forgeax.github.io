桌面 App 端到端跑通 + 首启引导填 keyThe desktop app runs end to end, with first-launch onboarding

桌面应用第一次从头跑到尾:后端打进安装包、引擎预览内嵌、示例游戏自动放好,连 FPS 需要的鼠标指针捕获也接上了。第一次启动会弹出一个引导层让你填 API key,填完立即生效、不用重启;端口也能用环境变量覆盖,装配前还会自愈依赖避免组装失败。从这天起,把它当一个能装、能开、能玩的桌面软件用,路是通的。The desktop app ran from start to finish for the first time: the backend is bundled in, the engine preview is embedded, sample games are seeded automatically, and even the mouse pointer capture an FPS needs is wired up. The first launch shows an onboarding overlay to enter your API key, which takes effect immediately with no restart; ports can be overridden via environment variables, and dependencies self-heal before assembly to avoid build failures. From this day, using it as an installable, openable, playable desktop application works end to end.

引擎:3D 世界里能挂清晰文字 + 更顺的关系与性能Engine: crisp in-world text, smoother relations and performance

引擎单日推进很猛。最直观的是世界空间文字渲染:现在能把清晰、缩放不糊的文字直接挂在 3D 场景里(招牌、血条上方的名字、漂浮提示都靠它)。底层把物体之间的"关系"做成双向自动同步——建立或解除父子、归属这类关联时两边自动保持一致,组合与拆解更省心;还加了一层每帧渲染状态缓存提升性能。画质上修好了两处抗锯齿问题(边缘更准、平坦区域不再偏亮)和一处贴图上下颠倒的毛病。The engine pushed hard in a single day. The most visible is world-space text rendering: you can now place crisp, scale-stable text directly in a 3D scene (signs, names above a health bar, floating tooltips all rely on it). Underneath, relationships between objects became bidirectionally auto-synced — when you create or break a parent-child or ownership link, both sides stay consistent automatically, making composition and teardown easier; and a per-frame render-state cache was added for performance. On image quality, two anti-aliasing issues were fixed (more accurate edges, no brightness shift in flat areas) and an upside-down texture bug was corrected.

新增低多边形建模助手 + 外部插件自动启动A new low-poly modeling assistant + auto-starting external plugins

协作阵容再添一员:一个专做低多边形(low-poly)3D 建模的助手 Poly,带无头渲染能力,可以帮你生成简洁风格的 3D 模型。平台这边还让外部工作台插件能随系统自动启动,装好的第三方工具开箱即用、不用手动拉起;同时修好了一个会让某些工具被报"未知工具"的同步问题,工具调用更稳。The collaboration roster gained another member: Poly, an assistant specialized in low-poly 3D modeling, with headless rendering, to help you generate clean-styled 3D models. The platform also lets external workbench plugins auto-start with the system, so installed third-party tools work out of the box without being launched manually; and a sync bug that made some tools report "unknown tool" was fixed, making tool calls more reliable.
