角色终于有影子了 + 夜晚氛围到位Characters finally cast shadows + night atmosphere

新出的暗黑风格 ARPG 样例此前有个明显问题:主角脚下没有影子,看起来像贴图浮在空中。这天把阴影投射一路捋通——角色现在能在地面投出贴脚的真实阴影,立体感和"踩在地上"的实感一下子回来了。配套调好了夜晚氛围:昏暗的月光加上几支营地火炬,营造出"夜里围着篝火清怪"的暗黑味道。期间还顺手把阴影渲染里的一个稳定性问题定位并修掉,让阴影在试玩里也能稳定显示。The new dark-fantasy ARPG sample had a glaring issue: the hero cast no shadow underfoot and looked like a texture floating in the air. This day got shadow casting working end to end — characters now drop a real, foot-anchored shadow on the ground, restoring depth and the feeling of "standing on the floor." Night atmosphere was tuned to match: dim moonlight plus a few camp torches, evoking that dark "clearing monsters around a fire at night" mood. A stability issue in shadow rendering was tracked down and fixed along the way, so shadows display reliably in play too.

编辑器能完全独立运行The editor runs fully standalone

编辑器的独立入口被整体重写成一套自包含的外壳:自带可停靠的多面板布局,编辑器需要的各个面板都在其中,不再必须挂在主聊天界面里才能跑。新机器上还有一键引导脚本,把所需的运行件自动准备好,开箱即编。意义在于:编辑器真正成了一个可以单独打开、单独使用的应用,也为把它嵌进别处、或单独分发铺平了路。The editor's standalone entry was rewritten into a self-contained shell: it brings its own dockable multi-panel layout with every panel the editor needs, and no longer has to run inside the main chat interface. On a fresh machine, a one-click bootstrap script prepares the needed runtime pieces automatically, so it's ready to edit out of the box. The upshot: the editor is genuinely an application you can open and use on its own, which also paves the way to embedding it elsewhere or distributing it separately.

角色动作平滑过渡 + 接入专业模型格式Smooth animation blending + ingesting professional model formats

角色动画更自然了:动作之间现在能平滑交叉过渡——从走切到跑、从待机切到攻击,不再是生硬的瞬切,而是顺滑衔接,可同时混合多段动作。引擎还正式接入了专业建模工具直出的模型格式(含动画、骨骼、物理参数),省去中间格式转换的折腾,意味着用专业工具做好的资产能更原汁原味地搬进来。配套还加了一个即时调试绘制工具,方便在画面上直接画出辅助线、包围盒等,排查问题更直观。Character animation got more natural: actions now cross-fade smoothly between each other — walk to run, idle to attack — no longer hard cuts but smooth transitions, and several clips can blend at once. The engine also formally ingests the model formats that professional modeling tools output directly (including animation, skeleton and physics parameters), skipping intermediate conversion, which means assets built in professional tools come in more faithfully. An immediate debug-draw tool was added too, for drawing helper lines and bounding boxes right on the picture to diagnose issues more visually.
