从零到「对话生成一个旋转立方体」From zero to a chat-made spinning cube

24 小时内打通端到端闭环:对它说一句话,它改代码,浏览器立刻热更出结果。In 24 hours the end-to-end loop came alive — say a sentence, it writes the code, and the browser hot-reloads the result.

首个端到端闭环The first end-to-end loop

从"零起点 → 在一台干净机器上跑出一个旋转立方体"的整条闭环跑通并自动验证:在 Studio 里用对话说"做一个旋转立方体",它写代码,引擎热重载,浏览器立即看到结果。这一天验证了整个产品最核心的假设——用对话就能做出能跑的东西。The whole loop — from a clean machine to a spinning cube — runs and self-verifies: in the Studio you say "make a spinning cube", it writes the code, the engine hot-reloads, and you see it immediately. This day proved the product's core bet — that you can build something runnable just by talking to it.

Studio 三栏界面成形The three-column Studio takes shape

界面端一口气加上文件面板、实时预览、控制台、会话、项目、市场与游戏切换器,Studio 的基本骨架立了起来——左侧管理、中间预览、右侧对话的格局就此定下。The interface gained a files panel, live preview, console, sessions, projects, a marketplace and a game switcher — the basic Studio skeleton stood up, settling the manage-left / preview-center / chat-right layout.

可替换的三层 + 一键启动Three replaceable layers + one-command start

引擎 / 运行时 / 界面三层正式跑通,并扁平化为零构建的开发模式:克隆后一条命令直接跑源码,几分钟就能在浏览器里上手。The engine / runtime / interface layers came together, flattened into a zero-build dev setup: clone, run one command straight from source, and you're hands-on in the browser within minutes.
