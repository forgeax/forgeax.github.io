焕新界面 + 可嵌入工具窗的工作台A refreshed interface + an embeddable workbench

一套统一的设计系统、新图标与动效;更干净的仪表盘;工作台第一次能装下一个完整的嵌入式工具窗。A unified design system with new icons and motion, a cleaner dashboard, and a workbench that can host a full embedded tool for the first time.

焕新的界面:统一设计系统 + 图标 + 动效A refreshed interface: unified design system, icons, motion

界面做了一次系统级焕新。底层换上一套三层设计令牌(颜色、边框、间距统一收口),全站视觉因此一致、好维护;一整套清爽的线性图标接入了工作台与各处工具条;还加了一层动效,侧栏内容切换、面板进出都有平滑过渡而不是硬跳。预览区也重排成左侧细导航栏 + 紧凑聊天框架的新外壳,整体更像一个成型的产品而不是拼装的原型。The interface got a system-level refresh. Underneath sits a three-layer design-token system (color, border, spacing all unified), so the whole app looks consistent and stays maintainable; a clean set of line icons was wired into the workbench and toolbars; and a motion layer was added, so sidebar content and panels transition smoothly instead of snapping. The preview area was re-laid-out into a new shell with a slim left rail and compact chat chrome — it feels more like a finished product than an assembled prototype.

更干净的仪表盘,聊天不再串流A cleaner dashboard, and chat that doesn't cross streams

仪表盘做了一次以会话为中心的重写,收敛成总览 / 会话 / 分析三个清楚的视图,打开不再蹦红字错误。聊天也修掉了一个恼人的老问题:每个对话标签页现在严格绑定自己的会话,切换会话或从仪表盘跳回来,不会再串到上一条对话的输出流上。版本号也常驻可见、切回窗口会自动刷新。The dashboard got a session-centric rewrite, narrowed to three clear views — Overview / Sessions / Analytics — and no longer throws red errors on open. Chat fixed an old annoyance too: each conversation tab is now strictly bound to its own session, so switching sessions or coming back from the dashboard won't bleed into the previous conversation's output stream. The version number is also always visible and refreshes when you return to the window.

工作台能装下一个完整的嵌入式工具窗The workbench can host a full embedded tool

工作台升级成"分屏插件"架构:一个工具既能在侧栏放它的控件,也能接管主区域铺开一个完整的工作界面——于是像角色生成这类需要大画布的工具,第一次能以嵌入式工具窗的形态住进工作台,而不是挤在一个小面板里。聊天里也加了 /tool 命令,可以直接调用某个工具的能力。The workbench gained a "split-surface plugin" architecture: a tool can put its controls in the sidebar and also take over the main area to lay out a full working surface — so something like character generation, which needs a big canvas, can live in the workbench as an embedded tool window for the first time instead of being crammed into a small panel. Chat also gained a /tool command to invoke a tool's capability directly.

引擎 2D 精灵图层 + 更简单的启停Engine 2D sprite layers + simpler start/stop

引擎新增了 2D 精灵图层:精灵可以分层、按顺序正确叠放,做 2D 内容有了底座。安装与启停也更省事——一条命令起、一条命令停,后台只跑一个常驻服务,不再依赖容器环境,新机器开箱即用。The engine added a 2D sprite layer: sprites can be layered and sorted so they stack in the right order, giving 2D content a foundation. Setup and start/stop got simpler too — one command up, one command down, with a single long-running background service and no container dependency, so a fresh machine works out of the box.
