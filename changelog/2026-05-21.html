焕新界面 + 可嵌入工具窗的工作台A refreshed interface + an embeddable workbench

这天界面做了一次系统级焕新:统一设计系统、整套图标、平滑动效、全新的预览外壳。工作台升级成"分屏插件"架构,第一次能装下一个完整的嵌入式工具窗;仪表盘以会话为中心重写、聊天不再串流;引擎补上 2D 精灵图层与一整套光照样例,安装启停也简化成一条命令。This day the interface got a system-level refresh: a unified design system, a full icon set, smooth motion, a new preview shell. The workbench grew a "split-surface plugin" architecture, hosting a full embedded tool window for the first time; the dashboard was rewritten session-centric and chat stopped crossing streams; the engine added 2D sprite layers and a full set of lighting examples, and start/stop was simplified to one command.

从原型感走向产品感From prototype feel to product feel

The through-line was systematically pushing the interface from a prototype assembled from features toward something that looks — and feels — like a finished product: a unified design language, consistent icons, smooth motion, and a clearer overall layout. At the same time, the workbench, dashboard and engine each advanced. Together they signal that this thing is no longer content with "can demo" but starts taking seriously the look and order of "being opened and used every day, long-term." Pushing both — good-looking and usable — at once is the key leap from usable to pleasant.

焕新的界面:统一设计系统 + 图标 + 动效A refreshed interface: unified design system, icons, motion

界面这天做了一次系统级焕新。底层换上一套三层结构的设计令牌——把颜色、边框、间距这些基础视觉变量统一收口管理,而不是各处各写一套硬编码的样式;这样全站视觉天然一致,改一处主题就能处处生效,维护成本大幅下降。一整套清爽的线性图标接进了工作台与各处工具条,让原本靠表情符号或文字凑合的地方变得专业、统一。还加了一层动效:侧栏内容切换、面板进出都有平滑过渡,而不是生硬地瞬间跳变,视觉上的连续感让操作不那么割裂。顶部结构也做了升级。这些改动单看都不是"功能",但合起来决定了你打开它的第一眼,会觉得这是个玩具,还是个工具。The interface got a system-level refresh this day. Underneath went a three-layer design-token structure — unifying base visual variables like color, border and spacing under one management rather than hardcoded styles scattered everywhere; this makes the whole app visually consistent by nature, so changing a theme in one place takes effect everywhere and maintenance cost drops sharply. A clean set of line icons was wired into the workbench and toolbars, making places that had made do with emoji or text professional and uniform. A motion layer was added: sidebar content and panels transition smoothly instead of snapping instantly, and the visual continuity makes interaction feel less jarring. The top structure was upgraded too. None of these is a "feature" on its own, but together they decide whether, on first opening it, you think it's a toy or a tool.

工作台能装下完整的嵌入式工具窗The workbench can host a full embedded tool window

工作台这天升级成"分屏插件"架构:一个工具既能在侧栏放它的控件,也能接管整个主区域、铺开一个完整的工作界面。这解决了一个真实的局促——像"角色生成"这类需要大画布的工具,以前只能挤在一个小面板里施展不开;现在它能以嵌入式工具窗的形态住进工作台,占满主区域,像一个专业软件那样工作。第一个按这套架构迁移的就是角色生成工作台,它从此以独立的嵌入页面运行。聊天里还加了一个 /tool 命令,可以直接调用某个工具的能力,而不必每次都用自然语言描述一遍。这套架构的意义远不止"窗口变大":它定义了"第三方工具怎么以一等公民的身份接进工作台",是平台走向"可被插件无限扩展"的关键一步。The workbench upgraded to a "split-surface plugin" architecture this day: a tool can put its controls in the sidebar and also take over the entire main area to lay out a full working surface. This solves a real cramping — a tool needing a big canvas, like "character generation," used to be squeezed into a small panel with no room to work; now it can live in the workbench as an embedded tool window filling the main area, working like professional software. The first tool migrated onto this architecture was the character-generation workbench, which now runs as its own embedded page. Chat also gained a /tool command to invoke a tool's capability directly, rather than describing it in natural language each time. The architecture's significance goes well beyond "bigger windows": it defines "how a third-party tool plugs into the workbench as a first-class citizen," a key step toward a platform extensible without limit by plugins.

更干净的仪表盘,聊天不再串流A cleaner dashboard, chat that doesn't cross streams

仪表盘这天做了一次以会话为中心的重写,收敛成总览、会话、分析三个清楚的视图,把一些重复、过时的旧页面下线。最直接的好处是:打开它不再蹦出一堆红字错误,而是干净、可信地呈现当前状态。聊天这边也修掉了一个恼人的老问题——每个对话标签页现在严格绑定它自己的会话,切换会话、或从仪表盘跳回聊天时,不会再串到上一条对话还在飞的输出流上;打断按钮也和后端的真实运行状态对齐,点了就真的停。版本号则常驻可见、切回窗口自动刷新。这些都是"日常用着不添堵"的基本盘,这天把它们一一补齐。The dashboard got a session-centric rewrite this day, narrowed to three clear views — overview, sessions, analytics — and retired some duplicate, outdated old pages. The most direct benefit: opening it no longer throws a pile of red errors but presents the current state cleanly and trustworthily. Chat also fixed an old annoyance — each conversation tab is now strictly bound to its own session, so switching sessions or jumping back from the dashboard won't bleed into the previous conversation's still-flowing output stream; the stop button is aligned with the backend's real run state, so clicking it actually stops. The version number is always visible and refreshes on returning to the window. These are the basics of "not getting in your way day to day," filled in one by one this day.

引擎:2D 精灵图层 + 一整套光照样例Engine: 2D sprite layers + a full set of lighting examples

引擎这天在 2D 和光照两头都有推进。2D 方面,新增了精灵图层:精灵可以分层、按正确的顺序叠放,做 2D 内容(背景、角色、UI 元素的前后关系)终于有了规整的底座,不必再靠手工 hack 控制谁压在谁上面。光照方面,把一整套循序渐进的光照样例铺完了——从基础着色、材质,到贴图光照、投光体、多光源同场,一系列章节都做成了可运行的引擎 demo。这些样例既是引擎光照能力的活文档,也是任何人(包括 AI)学习"怎么用这套引擎布光"的现成教材。2D 与 3D 两条线一起往前,意味着引擎不偏科,既能做平面也能做立体。The engine advanced on both 2D and lighting this day. On 2D, a sprite layer was added: sprites can be layered and stacked in the correct order, finally giving 2D content (the front-to-back relationship of backgrounds, characters and UI elements) a proper foundation, no longer relying on manual hacks to control what sits on top of what. On lighting, a full progressive set of lighting examples was completed — from basic shading and materials to textured lighting, light casters and multiple lights in one scene, a series of chapters all made into runnable engine demos. These examples are both living documentation of the engine's lighting and ready teaching material for anyone (including AI) to learn "how to light a scene with this engine." Advancing 2D and 3D together means the engine isn't lopsided — it can do flat as well as dimensional.

更简单的安装与启停Simpler install and start/stop

这天把安装与启停彻底简化了。现在一条命令就能把整套服务起起来,一条命令干净地停掉;后台只跑一个常驻的核心服务,不再像以前那样依赖容器环境、要先装一堆东西才能跑。一个曾经在某些系统上因为容器安装失败而卡住新人的坑,也随之被绕开。对想上手的人来说,"从克隆到跑起来"这条路被压到最短——这是降低使用门槛最实在的一环。一个再强的平台,如果第一步安装就劝退一半人,那它的能力也传递不出去;把入口修得足够平,本身就是产品力的一部分。This day thoroughly simplified install and start/stop. Now one command brings up the whole set of services, and one command stops it cleanly; the background runs a single long-running core service, no longer depending on a container environment or requiring a pile of installs first as before. A pitfall that once stalled newcomers on certain systems due to a failed container install was sidestepped along the way. For anyone getting started, the road "from clone to running" is squeezed to its shortest — the most concrete part of lowering the bar to use. However strong a platform, if the very first install step turns away half the people, its capability never gets through; paving the entrance flat is itself part of product strength.

这一天意味着什么What this day means

这一天是产品"长相"和"骨架"同时升级的一天。视觉焕新让它看起来像个成型产品,分屏工作台让第三方工具能真正住进来,干净的仪表盘和不串流的聊天让日常用着不添堵,引擎的 2D 图层与光照样例让能力更全面,简化的安装让更多人迈得进门。这些改动跨越了"好看、好用、好扩展、好上手"四个不同维度,却指向同一件事:让这个平台配得上被当成一个正经工具长期使用。一个产品从"能跑的原型"到"愿意每天打开的工具",中间隔的往往不是某个杀手级功能,而正是这样一整天、在多个维度上同时把粗糙磨成精致的功夫。This was a day of upgrading the product's "looks" and "skeleton" at once. The visual refresh makes it look like a finished product, the split-surface workbench lets third-party tools genuinely move in, the clean dashboard and non-crossing chat keep daily use unobstructed, the engine's 2D layers and lighting examples make capability more complete, and the simplified install lets more people through the door. These changes span four different dimensions — good-looking, usable, extensible, approachable — yet point at one thing: making the platform worthy of being used long-term as a proper tool. Between "a runnable prototype" and "a tool you're glad to open every day" lies, often, not some killer feature but exactly this kind of full day of polishing roughness into refinement across many dimensions at once.
