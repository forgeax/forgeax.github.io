骨骼动画 + 场景工作台与观测台Skeletal animation + scene & observatory workbenches

角色能播放骨骼动画了;新增"场景"与"观测台"两个工作台,叙事工具也补上了真正能用的能力。Characters can now play skeletal animation; new scene and observatory workbenches arrive, and the narrative tools gain real capability.

引擎:角色骨骼蒙皮动画Engine: skinned skeletal animation

引擎补上了游戏里最关键的一块——骨骼蒙皮动画。带骨架的角色模型现在能真正动起来:走、跑、挥手这类动作随骨骼驱动网格自然变形,而不是僵在原地。这是从"渲染一个静态物体"迈向"渲染一个活的角色"的关键一步,有了它,角色扮演、动作类游戏才谈得上做。The engine added one of the most essential pieces for games — skinned skeletal animation. Rigged character models can now genuinely move: walking, running, waving all deform the mesh naturally as the skeleton drives it, instead of standing frozen. This is the key step from "rendering a static object" to "rendering a living character" — and only with it do role-playing and action games become possible.

新增"场景"工作台 + 一个工程多个游戏A new scene workbench + multiple games in one project

工具家族再添一位:场景工作台,用来搭建和组织游戏里的场景。同时平台开始支持在一个工程里管理多个游戏——做系列、做关卡分支、或并行试几个想法,不必每次都新开一摊。从一个项目里挑要跑的游戏,变成了顺手的事。Another member joined the tool family: a scene workbench for building and organizing a game's scenes. At the same time, the platform began supporting multiple games within one project — make a series, branch levels, or try several ideas in parallel without spinning up a separate setup each time. Picking which game to run from inside a project became a casual act.

新增"观测台":实时看 agent 在做什么A new observatory: watch what agents are doing, live

新增一个"观测台"工作台,把 agent 的活动实时摊开:谁在跑、在调哪个工具、产出了什么事件,一目了然。多 agent 同时干活时,这是你掌控全局的窗口——既能放心让它们自己跑,又能随时看清进展、及时介入。A new "observatory" workbench lays out agent activity in real time: who's running, which tool they're calling, what events they've produced — all at a glance. When several agents work at once, this is your window onto the whole picture — you can let them run with confidence yet always see progress clearly and step in when needed.

叙事工具补上真本事 + 聊天界面更清爽Narrative tools get teeth + a cleaner chat

叙事工作台接上了一组真正能用的工具,让 agent 能实际参与剧情与文本的编排,而不只是有个空壳。聊天界面也做了一轮精简:去掉多余的发光与模糊、统一边框,装了很多 agent 时列表会自动分页、悬停高度也更稳——长时间盯着看更省眼。The narrative workbench wired in a set of genuinely usable tools, so an agent can actually take part in arranging story and text rather than facing an empty shell. The chat interface also got a pass of simplification: redundant glow and blur removed, borders unified, the list paginates when many agents are installed, and hover heights are steadier — easier on the eyes over a long session.
