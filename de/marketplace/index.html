Es stimmen keine Plugins überein.

Wie es geladen wird · wie Sie es erweitern

Zur Laufzeit geladen

Die CLI stellt Plugins bei Bedarf bereit; Die Persona eines Agenten wird nur geladen, wenn sie entsandt wird, wobei gemeinsame Teile sowohl dem Orchestrator als auch dem Worker zugeordnet sind.

Was Sie tun können

Aktivieren Sie im Admin-Bereich Workbenches, ordnen Sie sie neu an und wechseln Sie Backends. Oder verwenden Sie den Plugin-Autoren-Assistenten, um Ihr erstes Plugin zu schreiben.
