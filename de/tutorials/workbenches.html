Schaffen Sie Kunst mit den Werkbänken

Über das Chatten hinaus verfügt ForgeaX über eine Reihe von „Workbenches“ – jeweils ein Panel und eine Gruppe von Tools, die einen Satz in spielbereite Assets umwandeln. Sie bearbeiten das gleiche Artefakt per Hand und per KI.

✅ Open Source (Apache-2.0). Nachfolgend finden Sie eine Übersicht über das Workbench-System. Informationen zum Klonen und Installieren finden Sie imDokumente.

Charaktere · Animation · VFX

  • Charaktereditor– Schreiben Sie ein einzeiliges Briefing, erhalten Sie ein Porträt und eine Bearbeitung.
  • Animation– Verwandeln Sie einen stillstehenden Charakter in eine gehende, angreifende Skelettbewegung in vier Richtungen (sogar kurze Clips) – ohne Gesichtsveränderung.
  • Fertigkeit / VFX– Fügen Sie Effekte wie Feuer, Hiebe und Auren hinzu, die automatisch an den Moment des Wirkens angepasst werden.

3D-Modellierung und -Generierung

  • Editor für Blockzeichen– Erstellen Sie manipulierte 3D-Charaktere wie Schnappblöcke und exportieren Sie Standard-3D-Dateien.
  • Low-Poly-Generator— 3D-Requisiten mit einem Knotendiagramm erstellen; Ändern Sie einen Parameter und generieren Sie den Satz neu.
  • 3D-Generierung– Text oder Bild direkt in ein 3D-Modell, angeschlossen an mehrere Top-Generatoren, wählen Sie den besten aus.

Szenen · Benutzeroberfläche · Elemente

  • Szenengenerator– Stellen Sie eine ganze Spielszene als Diagramm zusammen, das Sie jederzeit erneut ausführen können.
  • 2D-Szenen-Asset-Generator– Batch-Requisiten, Texturen, Dekorationen und UI-Bits, automatisch benannt und abgelegt.
  • UI-Workbench– ein UI-Set für Ihren Spieltyp – nicht nur Bilder, ein anklickbarer Prototyp.
  • Elemente / Symbole— Waffen, Tränke, Münzen als Symbole mit ihren Daten, Grafiken und Zahlen in einer Tabelle.

Erzählung · Musik · Aussehen · Zahlen

  • Narrative Werkbank– von einem Funken zu einer vollständigen Geschichte und Welt, wobei die KI einen passenden Ansatz wählt.
  • Musik / Hintergrundmusik— Hintergrundmusik und Soundeffekte verwalten und die Partitur einer ganzen Sitzung sequenzieren.
  • Farbe / Aussehen— Vereinheitlichen Sie die Farbstimmung des gesamten Spiels mit einem Klick, wie ein Filter über alles.
  • Gleichgewicht— Lassen Sie die KI Tausende von Spielen spielen und Siegquoten mit Konfidenzintervallen melden; Lassen Sie die Daten die Abstimmung beurteilen.

System- und Autorentools

  • Code– Durchsuchen Sie den Code, springen Sie zwischen Dateien und bearbeiten Sie ihn zusammen mit der Codierungs-KI.
  • Observatorium– Wiederholen Sie jeden Schritt der KI wie eine Blackbox, um herauszufinden, wo etwas schief gelaufen ist.
  • Plugin-Autor– Lassen Sie Nicht-Programmierer ihre eigenen Workbench-Plugins erstellen.
  • Admin– das Studio-Kontrollfeld: Werkbänke umschalten, Modelle binden, sehen, welche KIs online sind.
Sie können nicht zeichnen, modellieren oder komponieren? Das ist in Ordnung – beschreiben Sie es und die Werkbänke produzieren Assets, die direkt in Ihr Spiel einfließen.
