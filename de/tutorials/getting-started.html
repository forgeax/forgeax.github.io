Schnellstart: Ihr erstes Spiel

Der Kernworkflow von ForgeaX besteht aus einem Satz:Beschreiben Sie das Spiel, das Sie schmieden möchten, und lassen Sie es den Rest erledigen.

✅ Open Source (Apache-2.0). Vollständige Installationsbefehle finden Sie unterHerunterladen und installieren; Auf dieser Seite erfahren Sie, wie sich der Arbeitsablauf anfühlt, wenn Sie erst einmal dabei sind.

1 · Starten Sie das Studio

Nachdem die Abhängigkeiten installiert wurden, ruft ein Befehl das Studio auf. Im Browser sehen Sie zwei Bereiche:

  • Links: Chat– wo Sie mit Forge (dem Hauptagenten) sprechen;
  • Rechts: Vorschau– Ihr Spiel läuft live.

2 · Sagen Sie Ihre erste Bitte

Kein Code erforderlich – teilen Sie Forge einfach mit, zum Beispiel:

Machen Sie ein Top-Down-Spiel: Ein Charakter rennt durch eine Arena, der Weltraum feuert Kugeln ab, Feinde spawnen weiter, Treffer entfernen sie und zählen den Punktestand.

Forge klärt die Anforderungen und zieht dann bei Bedarf Unteragenten zur Planung und Gestaltung hinzuschreibt den Motorcode selbst.

3 · Schauen Sie zu, wie es läuft

Sobald der Code geschrieben istHot-Reloadsin die Vorschau – fast so, wie es geschrieben wurde. Nicht glücklich? Reden Sie einfach weiter:

Machen Sie Kugeln schneller, verdoppeln Sie die Gesundheit des Feindes und stellen Sie den Hintergrund auf Nacht um.

Jedes bisschen Feedback wird zu einer weiteren Iteration. Das ist die ForgeaX-Schleife:beschreiben → generieren → abspielen → erneut beschreiben.

4 · Weiter

  • den Charakteren Bewegung und Fähigkeiten hinzufügen (Animation, Zaubersprüche);
  • Generieren Sie Kunst mit den Werkbänken (Porträts, 3D, VFX, Musik);
  • Bauen Sie mehrere Ebenen und gleichen Sie die Zahlen aus.
