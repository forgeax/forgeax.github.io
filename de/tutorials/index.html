Tutorials

Schritt für Schritt vom Satz zum spielbaren Spiel. Weiteres wird folgen.

Anfänger

Lassen Sie Ihre KI-CLI klonen und starten

Übergeben Sie das Repo an die CLI von Claude Code / Codex / Cursor / forgeax und lassen Sie es klonen, installieren und starten.
Anfänger

Schnellstart · Ihr erstes Spiel

Lernen Sie das Studio kennen, geben Sie Forge Ihre erste Anfrage, sehen Sie zu, wie es plant, programmiert und live ausführt.
Bald

Fügen Sie einem Charakter Bewegung und Fähigkeiten hinzu

Erstellen

Lernen Sie die Arbeitsbereiche für die Erstellung kennen – Charaktere, Animation, 3D, VFX, UI, Musik – von einem Satz bis hin zu spielbereiten Assets.
