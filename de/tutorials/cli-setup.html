Lassen Sie Ihre KI-CLI ForgeaX klonen und starten

Die KI-nativste Installation: Geben Sie die Befehle nicht selbst ein – übergeben Sie das Repo an Ihren Coding-CLI-Agenten und lassen Sie ihn klonen, installieren, starten und die lokale URL zurückmelden.

✅ Open Source (Apache-2.0). Der folgende Ablauf funktioniert mit jeder KI-Codierungs-CLI.

Was Sie brauchen

  • Eine KI-Codierungs-CLI, die Shell-Befehle ausführen kann – z. B.Claude Code,Kodex,Cursor, oder ForgeaXs eigenesSchmiedeaxtCLI;
  • IdiotUndBrötchen(die Projektlaufzeit) installiert;
  • ein KI-Modell-API-Schlüssel (für Forge im Studio).

Eine Anweisung an Ihre CLI

Öffnen Sie Ihre CLI in einem leeren Ordner und geben Sie Folgendes ein:

Klonen Sie https://github.com/ForgeaX-Games/forgeax-studio (mit --recurse-submodules), cd hinein, führen Sie das Installationsskript aus, um Abhängigkeiten einzurichten, führen Sie dann das Startskript aus, um es zu starten, und teilen Sie mir die lokale URL mit, die ich öffnen kann.

Die CLI führt die Klon-/Installations-/Startschritte selbst aus und fragt Sie dabei nach allem, was sie benötigt (z. B. den API-Schlüssel). Wenn es fertig ist, erhalten Sie eine lokale URL – öffnen Sie sie im Browser und schon sind Sie im Studio.

Manuelles Äquivalent (optional)

Wenn Sie es lieber selbst machen möchten, ist das Äquivalent ungefähr:

git clone --recurse-submodules \
  https://github.com/ForgeaX-Games/forgeax-studio
CD Forgeax-Studio
bun fx setup # deps installieren (+ API-Schlüssel hinzufügen)
bun fx start # Starten Sie das Studio

DieseBrötchen fxBefehle sind plattformübergreifend – das Gleiche unter macOS, Linux und Windows, ohne dass Git-Bash unter Windows erforderlich ist. Öffnen Sie dann die lokale URL, die gedruckt wird.

Als nächstes gehen Sie zuSchnellstartund erzähle Forge von deinem ersten Spiel.

Warum ist dies die reibungsloseste Installation? Da ForgeaX in erster Linie für KI entwickelt wurde, überlassen wir es gerne einem Agenten, sich selbst einzurichten.
