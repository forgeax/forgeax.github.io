Tonpersonnelstudio de jeux.

ForgeaX est un studio de développement de jeux natif d'IA : transformez vos idées en jeux jouables pendant que l'IA écrit le code du moteur, rechargeant à chaud en direct dans votre navigateur. Plus inhabituel :le moteur et la plateforme eux-mêmes sont écrits presque entièrement par l'IA, ligne par ligne, dans une boucle de développement autonome- et son auto-construction quotidienne est enregistrée dans lejournal des modifications, une sorte de mémoire de développement à long terme pour l’IA.

De nombreuses façons de créer

Chat, éditeur visuel et saisie d'images/vidéos plus tard : exprimez vos idées comme bon vous semble.

Agent par conception

Les agents planifient, conçoivent et rédigent le code du moteur ; vous définissez les exigences et examinez.

Rechargement à chaud en direct

Chaque changement apparaît instantanément dans l’aperçu : ce que vous dites est ce que vous jouez.

Véritable moteur ECS

Un véritable moteur entité-composant-système avec rendu double RHI, dans un studio de navigation.

Un gameplay natif de l'IA

Il ne s’agit pas seulement de créer des jeux avec l’IA, mais également d’intégrer l’IA dans le jeu lui-même : des PNJ intelligents, du contenu génératif, des expériences interactives d’IA.

Boucle de développement auto-évolutive

La boucle fermée ForgeaX - un pipeline d'exigences → construction → vérification qui apprend de ses propres commentaires et se développe de manière plus stable au fil du temps.

S'exécute dans le navigateur

Alimenté par WebGPU, Web et ordinateur de bureau sur une seule pile, opérationnel en une minute.

Source ouverte

Apache 2.0 — libre de créer, d'utiliser, d'expédier et de construire commercialement.

Utilisez l'IA pour laquelle vous payez déjà.

Forge fonctionne avec l'abonnement à l'agent de codage que vous avez déjà – pas de deuxième facture d'IA. Connectez l'outil que vous utilisez déjà, ou apportez simplement une clé API.

Claude Code

Conduisez Forge avec votreClaude Pro/Maxabonnement – ​​ou une clé API Anthropic.

OpenAI Codex

Connectez-vous avec votreChatGPT Plus / Proplan – ou une clé API OpenAI.

Cursor

Connectez votreCurseur Proabonnement via la CLI Cursor Agent.

Pas de dépendance vis-à-vis d'un fournisseur : utilisez l'agent qui vous convient et changez à tout moment.
