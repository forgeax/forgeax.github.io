Démarrage rapide : votre premier jeu

Le flux de travail principal de ForgeaX tient en une phrase :décrivez le jeu que vous souhaitez forger et laissez-le s'occuper du reste.

✅Open source (Apache-2.0). Pour les commandes d'installation complète, voirTélécharger et installer; cette page explique à quoi ressemble le flux de travail une fois que vous y êtes.

1 · Lancer le studio

Une fois les dépendances installées, une commande ouvre le studio. Dans le navigateur, vous verrez deux zones :

  • À gauche : discuter— où vous parlez à Forge (l'agent principal) ;
  • À droite : aperçu- votre jeu en direct.

2 · Dites votre première demande

Aucun code n'est nécessaire — dites simplement à Forge, par exemple :

Créez un jeu de haut en bas : un personnage court dans une arène, l'espace tire des balles, les ennemis continuent d'apparaître, les coups les suppriment, comptent les scores.

Forge clarifie les exigences, fait appel à des sous-agents pour planifier et concevoir si nécessaire, puisécrit lui-même le code moteur.

3 · Regardez-le fonctionner

Dès que le code est écritrecharges à chauddans l’aperçu – presque au moment où il est saisi. Pas content ? Continuez simplement à parler :

Rendez les balles plus rapides, doublez la santé de l'ennemi, changez l'arrière-plan en nuit.

Chaque retour d’information devient une autre itération. C'est la boucle ForgeaX :décrire → générer → jouer → décrire à nouveau.

4 · Suivant

  • ajouter du mouvement et des compétences aux personnages (animation, sorts) ;
  • générer de l'art avec les établis (portraits, 3D, VFX, musique) ;
  • construisez plusieurs niveaux et équilibrez les chiffres.

Ceux-ci viennent dans des didacticiels ultérieurs. Pour l'instant, consultez levitrinepour ce que le même flux a produit.
