Demandez à votre AI CLI de cloner et lancez ForgeaX

L'installation la plus native pour l'IA : ne tapez pas les commandes vous-même : remettez le dépôt à votre agent de codage-CLI et laissez-le cloner, installer, lancer et renvoyer l'URL locale.

✅Open source (Apache-2.0). Le flux ci-dessous fonctionne avec n’importe quelle CLI de codage AI.

Ce dont vous avez besoin

  • Une CLI de codage d'IA qui peut exécuter des commandes shell - par ex.Claude Code,Manuscrit,Curseur, ou celui de ForgeaXforgeronCLI ;
  • gitetChignon(le runtime du projet) installé ;
  • une clé API de modèle d'IA (pour Forge à l'intérieur du studio).

Une instruction à votre CLI

Ouvrez votre CLI dans un dossier vide et donnez-lui ceci :

Clonez https://github.com/ForgeaX-Games/forgeax-studio (avec --recurse-submodules), cd-y, exécutez le script d'installation pour configurer les dépendances, puis exécutez le script de démarrage pour le lancer et dites-moi l'URL locale que je peux ouvrir.

La CLI exécute elle-même les étapes de clonage/installation/lancement, vous demandant tout ce dont elle a besoin en cours de route (comme la clé API). Une fois terminé, vous obtenez une URL locale : ouvrez-la dans le navigateur et vous êtes dans le studio.

Equivalent manuel (facultatif)

Si vous préférez le faire vous-même, l'équivalent est grosso modo :

git clone --recurse-submodules \
  https://github.com/ForgeaX-Games/forgeax-studio
cd forgeax-studio
bun fx setup # install deps (+ ajouter une clé API)
bun fx start # lancer le studio

Ceschignon fxles commandes sont multiplateformes – les mêmes sur macOS, Linux et Windows, sans Git-Bash nécessaire sous Windows. Ensuite, ouvrez l'URL locale qu'il imprime.

Ensuite, dirigez-vous versDémarrage rapideet racontez à Forge votre premier jeu.

Pourquoi est-ce l’installation la plus fluide ? Parce que ForgeaX est conçu en premier lieu pour l'IA - même « s'auto-configurer » est quelque chose que nous sommes heureux de confier à un agent.
