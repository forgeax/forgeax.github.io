Tous les jours2026-07-04

Corrections de génération 3D + i18n workbench + terminal TUI agent

Les workbenches wb-gen3d et wb-ai-asset ont reçu des corrections critiques du pipeline 3D ; les trois workbenches de création (personnage, actif IA, génération 3D) sont désormais entièrement internationalisés ; une nouvelle TUI (Terminal UI) fournit une interface agent pilotée au clavier ; les API Keys de Settings sont simplifiées à LiteLLM uniquement ; CLI gagne l'auto-inject slug et des codes d'erreur structurés ; et deux nouveaux packs de scènes de jeu sont livrés (scènes éditables Slagdeep Hollow, modèle de sol Rogue Encampment).

Corrections du pipeline de génération 3D

Les workbenches wb-gen3d (génération de modèles 3D) et wb-ai-asset (création d'actifs IA) ont reçu des corrections critiques de leurs pipelines de sortie 3D. Auparavant, certains modèles générés pouvaient ne pas s'afficher correctement dans le viewport en raison de problèmes d'assignation de matériaux. Résolu — les actifs 3D générés s'affichent avec les textures PBR correctes immédiatement après création.

Internationalisation complète des workbenches

Les trois workbenches de création — wb-character, wb-ai-asset et wb-gen3d — sont désormais entièrement internationalisés dans toutes les langues supportées. Labels de panneaux, infobulles, messages d'état et états d'erreur sont tous traduits.

TUI : Interface agent terminal

Une nouvelle TUI (Terminal UI) a été validée pour le runtime agent core (acceptation F1/F2/F3). Elle fournit une interface pilotée au clavier pour interagir avec l'agent directement depuis un terminal.

API Keys Settings simplifiées

La section API Keys dans Settings a été simplifiée à une configuration LiteLLM uniquement. Au lieu de gérer des clés individuelles pour chaque fournisseur, vous configurez maintenant un seul endpoint proxy LiteLLM qui route vers tous vos modèles.

Améliorations CLI

Le CLI injecte maintenant automatiquement le slug du projet dans les appels d'outils, éliminant les erreurs courantes « projet non trouvé ». De plus, les erreurs de handlers retournent maintenant des codes d'erreur structurés.

Nouveaux packs de scènes de jeu

Deux nouveaux packs de contenu : Slagdeep Hollow (scènes éditables + position de départ launcher den) et Rogue Encampment (modèle de sol pour jeux style dungeon-crawler).
