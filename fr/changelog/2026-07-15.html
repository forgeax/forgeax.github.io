Contrôle d'entrée Play, UI matériaux MeshRenderer et sélection de personnage Hellforge

Aujourd'hui arrive un modèle de propriété d'entrée pour Play, une UI d'édition de matériaux dans l'Inspector et l'écran de sélection de personnage Hellforge avec aperçus 3 classes, ombres de contact et BGM.

Contrôle d'entrée Play

  • Le viewport utilise un lease de contrôle de jeu explicite : le jeu actif capture clavier et souris ; Escape rend le contrôle à l'éditeur.
  • L'édition en direct pendant Play est restaurée — les propriétés de la scène sont modifiables pendant l'exécution.
  • Les raccourcis clavier (ex. Escape pour quitter Play) fonctionnent à nouveau aux frontières de l'éditeur.
  • Un nouveau CI guard (game-input-contract) garantit que les jeux utilisent le système d'entrée du moteur sans listeners DOM globaux.

Inspector de matériaux MeshRenderer

  • Nouvelle section Materials dans l'Inspector MeshRenderer pour voir/éditer les slots, assigner des textures et ajuster les paramètres de shader.
  • addComponent gère correctement les champs shared<T> — l'ajout de composants avec des assets référencés ne provoque plus d'erreurs.

Sélection de personnage et visuels Hellforge

  • Écran de sélection 3 classes avec aperçu d'animation idle et rotation 360°.
  • Ombres de contact douces via un passe ShadowCaster statique.
  • BGM de scène pour le camp et l'antre avec réglage du volume F10.
  • Ciel de lune de sang HDR, gradation fumée/cendre avec brume, horizon élargi avec silhouettes de cônes de lave.
  • Tokens de thème UI gothique « ClaudeCraft forge-gold », polices Song/serif, orbes HP/MP métalliques sans thrashing GPU.

Moteur : audio, ECS et rendu

  • Les clips audio se chargent par GUID d'asset.
  • SystemSet scheduling style Bevy pour grouper et ordonner les systèmes.
  • Les couches de tilemap utilisent des entités de rendu enfants pour l'ordre de dessin correct.
  • Les slots SSBO d'ombres sont alignés sur l'ordre de dessin, corrigeant les artefacts dans les scènes multi-ombres.
  • Les entrées du catalogue se résolvent depuis le pack index, corrigeant les assets manquants dans les builds packagés.

Workbench vidéo de jeu

  • Éditeur QTE / règlement d'options pour les overlays vidéo interactifs.
  • Schémas d'overlay UI libre avec édition copy-on-write par nœud.

Autres améliorations

  • Les panneaux de l'éditeur se rafraîchissent automatiquement lors de changements d'assets sur disque.
  • Paramètres : URL de snapshot copiable après upload, liens d'aide visibles.
  • Les sessions CLI ont un tracker de tour en direct avec abonnement WebSocket et anneau de reprise.
  • Les assets de jeu sont livrés via les pack indexes pour des démarrages à froid plus rapides.
