Mise à jour2026-07-16

Caméra vol style UE5, projection d'actions de jeu et stabilité du viewport

Aujourd'hui, navigation vol UE5 (clic droit + WASD) dans le viewport, les jeux peuvent projeter leurs propres actions Play dans l'éditeur, et plusieurs problèmes de stabilité du viewport et du panneau d'assets sont corrigés.

Navigation caméra style UE5

  • Le viewport supporte maintenant le mode vol UE5 : maintenir clic droit + WASD pour naviguer librement dans la scène, avec logging diagnostique.

Projection d'actions de jeu

  • Les jeux peuvent définir des actions Play personnalisées via le bootstrap context ; le gateway de l'éditeur les projette comme opérations disponibles pendant Play.

Stabilité du viewport et des panneaux

  • Le panneau Assets n'apparaît plus vide — les racines du catalogue sont correctement injectées.
  • Le viewport se recharge automatiquement quand les assets changent sur disque pendant Play.
  • Les glissements dans la Hierarchy et la navigation d'assets partagés sont stabilisés.

Corrections moteur et démos

  • Les packs de polices émettent maintenant des assets sampler, corrigeant le rendu de glyphes manquants.
  • Nouveaux démos de référence Bevy : spotlight, vue orthographique, texture, parenting et free-camera controller.

Workbench vidéo de jeu

  • Lecture vidéo et gestion de sessions améliorées pour les overlays interactifs.
