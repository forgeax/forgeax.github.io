Mise à jour2026-07-17

AnimationPlayer automatique sur modèles skinnés, priors visuels génératifs et upload de workspace

Aujourd'hui, AnimationPlayer est monté automatiquement sur les entités skinnées (FBX inclus), des priors de source visuelle générative sont ajoutés au viewport, et l'upload de workspace tar.gz avec dédup par hash est disponible depuis le CLI.

AnimationPlayer automatique sur modèles skinnés

  • L'import de modèles skinnés (dont FBX) attache automatiquement un composant AnimationPlayer — aucune configuration manuelle pour jouer les animations.

Priors visuels génératifs

  • Le viewport gagne des priors de source visuelle générative, fournissant des références de construction de scène assistées par IA directement dans l'éditeur.
  • Brokers FluxRT et Reactor côté serveur pour les visuels génératifs en temps réel.

Upload de snapshot workspace

  • Le CLI peut uploader l'intégralité du workspace en archive tar.gz avec déduplication par hash de contenu.
  • Un token d'upload partagé intégré est fourni par défaut — aucune configuration supplémentaire requise.

Corrections du mode Play

  • Les imports de jeux Play embarqués se résolvent correctement depuis le workspace de l'éditeur.
  • L'évaluation headless utilise un renderer null-RHI de repli avec polyfill React Refresh (scénarios CI et aperçu corrigés).

Moteur : bruit Perlin et nouveaux démos

  • noise.perlin1d disponible dans le namespace mathématique pour la génération procédurale.
  • Nouveaux démos de référence Bevy : grille de matériaux PBR, éclairage, screen-shake 2D, clear-color, capture d'écran et redimensionnement de fenêtre.

Workbench vidéo de jeu

  • Stage d'overlay vidéo intégré dans GraphStudio.
  • Gestion de la limite de durée vidéo pour les overlays interactifs.

Correction du Content Browser

  • Suppression d'un slash initial erroné dans le packPath des assets empêchant le chargement de certains assets.
