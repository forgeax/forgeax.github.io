Tous les jours2026-07-14

Overlay de débogage de colliders, assets plus sûrs et import d'assets IA dans le jeu

Aujourd'hui, un overlay de débogage de colliders en temps réel apparaît dans le viewport, la sauvegarde protège contre la perte de données, le CRUD d'assets externes est ajouté, et les assets 3D générés par IA peuvent être importés directement dans le jeu.

Overlay de débogage de colliders

  • Sélectionner une entité avec un composant Collider projette un wireframe en temps réel dans le viewport, facilitant le réglage des formes physiques.
  • Les matériaux du gizmo ne projettent plus d'ombres, gardant le viewport propre.

Gestion d'assets plus sûre

  • Les assets externes stockés hors du projet sont gérables via le CRUD du Content Browser, appuyé par des fichiers .meta.json.
  • L'enregistrement d'une scène fusionne automatiquement les assets inline orphelins, évitant la perte de données.
  • L'annulation de la suppression d'une entité restaure correctement les matériaux associés via le round-trip de GUID des assets de scène.
  • Les duplications imbriquées dans les transactions sont traitées de manière fiable.
  • Le Content Browser actualise son catalogue au rechargement pour afficher immédiatement les assets montés tardivement.

Import d'assets IA dans le jeu

  • Les workbenches Gen3D et AI Asset proposent l'action « Import to Game », permettant d'exporter des modèles 3D générés par IA comme personnages jouables directement dans le projet.

Améliorations du moteur

  • Les colliders physiques synchronisent leur pose depuis le composant Transform, corrigeant la dérive entre formes visuelles et physiques.
  • Un nouvel espace de noms easing fournit smoothstep et smootherstep.
  • decodeImageBytes est exposé au runtime pour charger des textures depuis des buffers de bytes bruts.
  • Les imports FBX hydratent leur décodeur WASM automatiquement à l'installation du package.
  • Les mount-overrides de composants et les round-trips de références partagées sont désormais entièrement fiables.

CLI et permissions

  • Les erreurs qui disparaissaient en réponses UI vides sont maintenant synthétisées en messages lisibles.
  • Un trust-gate unifié settings.permissions remplace les vérifications ad-hoc dans les trois noyaux.

Corrections

  • Studio sous Windows utilise tasklist pour vérifier la survie des processus enfants, corrigeant un blocage au démarrage sur certaines machines.
  • La sélection de scènes du launcher utilise le GUID au lieu de l'index, évitant les erreurs après réorganisation.
  • Cow Survivor : erreurs de configuration physique du joueur réduites et visuels de gameplay instanciés par GUID.
