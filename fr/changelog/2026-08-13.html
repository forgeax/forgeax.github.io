ForgeaX Studio v0.3.27 : configuration plus fiable, prévisualisations enrichies et packages Game Runtime indépendants

La version v0.3.27 fiabilise la première installation, répare les liens du marketplace sous Windows, ajoute les prévisualisations de matériaux, de meshes et de VFX dans Studio et permet aux hôtes de jeux d'utiliser des packages runtime publiés séparément.

Une première installation plus fluide

Studio suit désormais, lors de l'installation, le gestionnaire de paquets et le fichier lock déclarés par chaque extension. Sous Windows, les répertoires des plugins du marketplace sont normalisés en liens de répertoire utilisables, ce qui évite les échecs des plugins qui lancent des processus enfants lorsque le placeholder d'un lien symbolique ne peut pas servir de répertoire de travail.

Les prévisualisations et les assets rejoignent l'hôte

Les viewports de prévisualisation des matériaux, des meshes et des VFX sont maintenant enregistrés via la façade de l'éditeur, afin que les hôtes Studio proposent les mêmes capacités. Les imports d'assets et les opérations de fichiers fondées sur le catalogue utilisent un mappage de chemins canonique pour garder les chemins de l'éditeur alignés sur les fichiers du disque.

Un Game Runtime publiable séparément

Les packages Game Runtime et leurs déclarations SDK sont construits comme une surface de publication indépendante. Les hôtes de jeux peuvent utiliser le runtime sans adopter l'intégralité du build Studio.

Voir la release ForgeaX Studio v0.3.27.
