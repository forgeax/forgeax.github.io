Início rápido: seu primeiro jogo

O fluxo de trabalho principal do ForgeaX é uma frase:descreva o jogo que você deseja forjar e deixe que ele cuide do resto.

✅ Código aberto (Apache-2.0). Para comandos de instalação completos, consulteBaixe e instale; esta página aborda como é o fluxo de trabalho quando você entra.

1 · Lançar o estúdio

Após a instalação das dependências, um comando abre o estúdio. No navegador você verá duas áreas:

  • Esquerda: bate-papo— onde você fala com Forge (o agente principal);
  • À direita: visualização- seu jogo rodando ao vivo.

2 · Diga seu primeiro pedido

Nenhum código é necessário - basta dizer ao Forge, por exemplo:

Faça um jogo de cima para baixo: um personagem corre ao redor de uma arena, o espaço dispara balas, os inimigos continuam surgindo, os golpes os removem, marca a pontuação.

Forge esclarece o requisito, traz subagentes para planejar e projetar quando necessário e, em seguida,escreve o próprio código do motor.

3 · Observe correr

Assim que o código for escrito, elerecargas a quentena visualização - quase enquanto é digitado. Não está feliz? Continue falando:

Torne as balas mais rápidas, duplique a saúde do inimigo, mude o fundo para noite.

Cada feedback se torna outra iteração. Esse é o loop ForgeaX:descrever → gerar → reproduzir → descrever novamente.

4 · Próximo

  • adicionar movimento e habilidades aos personagens (animação, feitiços);
  • gerar arte com as bancadas (retratos, 3D, VFX, música);
  • construa vários níveis e equilibre os números.
