Faça seu clone AI CLI e inicie o ForgeaX

A instalação mais nativa de IA: não digite os comandos você mesmo – entregue o repositório ao seu agente CLI de codificação e deixe-o clonar, instalar, iniciar e reportar o URL local.

✅ Código aberto (Apache-2.0). O fluxo abaixo funciona com qualquer CLI de codificação de IA.

O que você precisa

  • Uma CLI de codificação de IA que pode executar comandos shell – por exemplo.Código Claude,Códice,Cursor, ou o próprio ForgeaXforjaCLI;
  • idiotaePão(o tempo de execução do projeto) instalado;
  • uma chave de API do modelo AI (para Forge dentro do estúdio).

Uma instrução para sua CLI

Abra sua CLI em uma pasta vazia e dê o seguinte:

Clone https://github.com/ForgeaX-Games/forgeax-studio (com --recurse-submodules), faça cd nele, execute o script de instalação para configurar dependências e, em seguida, execute o script de início para iniciá-lo e diga-me o URL local que posso abrir.

A CLI executa as etapas de clonagem/instalação/lançamento, solicitando tudo o que for necessário ao longo do caminho (como a chave da API). Quando terminar, você receberá um URL local – abra-o no navegador e você estará no estúdio.

Equivalente manual (opcional)

Se você preferir fazer isso sozinho, o equivalente é aproximadamente:

git clone --recurse-submodules \
  https://github.com/ForgeaX-Games/forgeax-studio
cd forgeax-studio
bun fx setup # install deps (+ adicionar chave API)
bun fx start # lança o estúdio

Essescoque fxos comandos são multiplataforma – os mesmos no macOS, Linux e Windows, sem necessidade de Git-Bash no Windows. Em seguida, abra o URL local impresso.

A seguir, vá paraInício rápidoe conte ao Forge seu primeiro jogo.

Por que esta é a instalação mais suave? Porque o ForgeaX foi desenvolvido para IA em primeiro lugar - até mesmo "configurar-se" é algo que temos prazer em entregar a um agente.
