Atualização2026-07-04

Correções de geração 3D + i18n de workbench + terminal TUI do agente

Os workbenches wb-gen3d e wb-ai-asset receberam correções críticas no pipeline 3D; os três workbenches de criação (personagem, ativo IA, geração 3D) estão agora totalmente internacionalizados; uma nova TUI (Terminal UI) fornece uma interface de agente controlada por teclado; as API Keys de Settings foram simplificadas para apenas LiteLLM; CLI ganha auto-inject slug e códigos de erro estruturados; e dois novos pacotes de cenas de jogo são enviados (cenas editáveis Slagdeep Hollow, modelo de piso Rogue Encampment).

Correções do pipeline de geração 3D

Os workbenches wb-gen3d (geração de modelos 3D) e wb-ai-asset (criação de ativos IA) receberam correções críticas em seus pipelines de saída 3D. Anteriormente, certos modelos gerados podiam falhar ao renderizar corretamente no viewport devido a problemas de atribuição de material. Resolvido — ativos 3D gerados são exibidos com texturas PBR corretas imediatamente após a criação.

Internacionalização completa dos workbenches

Os três workbenches de criação — wb-character, wb-ai-asset e wb-gen3d — estão agora completamente internacionalizados em todos os idiomas suportados. Labels de painéis, tooltips, mensagens de status e estados de erro estão todos traduzidos.

TUI: Interface de agente terminal

Uma nova TUI (Terminal UI) foi validada para o runtime do agente core (aceitação F1/F2/F3). Ela fornece uma interface controlada por teclado para interagir com o agente diretamente de um terminal.

API Keys de Settings simplificadas

A seção API Keys em Settings foi simplificada para configuração apenas-LiteLLM. Em vez de gerenciar chaves individuais para cada provedor, agora você configura um único endpoint proxy LiteLLM que roteia para todos os seus modelos.

Melhorias no CLI

O CLI agora auto-injeta o slug do projeto nas chamadas de ferramentas, eliminando erros comuns de "projeto não encontrado". Além disso, erros de handlers agora retornam códigos de erro estruturados.

Novos pacotes de cenas de jogo

Dois novos pacotes de conteúdo: Slagdeep Hollow (cenas editáveis + posição inicial launcher den) e Rogue Encampment (modelo de piso para jogos estilo dungeon-crawler).
