ForgeaX Studio v0.3.27: configuração mais estável, mais pré-visualizações e pacotes Game Runtime independentes

A versão v0.3.27 torna a configuração inicial mais confiável, corrige os links do marketplace no Windows, adiciona pré-visualizações de materiais, meshes e VFX ao Studio e permite que hosts de jogos consumam pacotes de runtime publicados de forma independente.

Uma primeira configuração mais tranquila

O Studio agora segue o gerenciador de pacotes e o lockfile declarados por cada extensão durante a configuração. No Windows, os diretórios dos plugins do marketplace são normalizados como links de diretório utilizáveis, evitando falhas em plugins com processos filhos quando um placeholder de link simbólico não pode ser usado como diretório de trabalho.

Pré-visualizações e assets chegam ao host

As viewports de pré-visualização de materiais, meshes e VFX agora são registradas pela fachada do editor, para que os hosts do Studio ofereçam as mesmas capacidades. As importações de assets e as operações de arquivo baseadas no catálogo usam um mapeamento de caminhos canônico, mantendo os caminhos do editor alinhados aos arquivos no disco.

Game Runtime com publicação independente

Os pacotes Game Runtime e suas declarações de SDK são compilados como uma superfície de publicação independente. Hosts de jogos podem consumir o runtime sem assumir todo o build do Studio.
