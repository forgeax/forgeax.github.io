## What is ForgeaX?

ForgeaX is an AI-native game development studio. Our goal is simple: **let smaller
teams — even one person — make games that used to require a much larger team.** You
describe a game; an AI lead plans it, designs it, and writes the ECS engine code
itself, hot-reloading the result into a live browser preview — what you say is what you play.

- 🎮 **Many ways to create** — chat, a visual editor, and (soon) images / video
- 🤖 **Agentic** — agents plan, design, and write the engine code for you
- ⚡ **Live hot-reload** — see every change the moment it lands
- 🧩 **Real ECS engine** — dual-RHI (WebGPU) rendering, physics, skeletal animation
- 🧠 **AI-native gameplay** — build AI into the play itself: intelligent NPCs, generative content
- ♻️ **Self-evolving loop** — the ForgeaX closed loop learns from its own feedback
- 📖 **Open source** — Apache License 2.0
